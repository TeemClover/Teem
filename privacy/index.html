🔐 ข้อมูลส่วนบุคคล

ข้อมูลของคุณ อยู่กับเราแบบไหน

บ้านนี้เก็บข้อมูลน้อยที่สุดเท่าที่จำเป็น และบอกตรง ๆ ว่าเก็บอะไรไปทำอะไร — อ่านหน้านี้จบใน 2 นาที ไม่มีตัวหนังสือเล็ก ๆ ซ่อนไว้

ปรับปรุงล่าสุด: 9 สิงหาคม 2569

1🏠 ใครเป็นคนเก็บ

myclover.com ดูแลโดยเจ้าของบ้านเป็นการส่วนตัว ติดต่อได้ที่ team@myclover.com — ทุกอีเมลที่เขียนมาถึงคนจริง ไม่ใช่ระบบตอบอัตโนมัติ

2📦 เราเก็บอะไรบ้าง

ถ้าคุณเลือกสร้างบัญชีหรือสมัครรับการ์ดประจำตัว เราเก็บข้อมูลที่จำเป็นต่อสิ่งที่คุณเลือกใช้:

ชื่อ / ชื่อเล่นไว้เรียกคุณให้ถูก และพิมพ์ลงบนการ์ดประจำตัวของคุณ
อีเมลใช้เป็นชื่อบัญชีสำหรับ Login และเรียก Progress คืน; เราจะส่งประกาศของบ้านต่อเมื่อคุณเลือกช่องรับข่าวสารแยกต่างหาก
สายที่คุณเลือกไว้ส่งเรื่องที่คุณสนใจจริง ๆ แทนที่จะส่งทุกอย่างให้ทุกคน
ตราประจำตัวเช่น ศิษย์เก่า ผู้ค้นพบ ชาวกิลด์ — ไว้แสดงบนการ์ดของคุณ
ยุคที่คุณรู้จักบ้านนี้ช่วงปีกว้าง ๆ ที่คุณเลือกเอง ไม่ได้พิมพ์ลงการ์ด — ไว้ดูว่าคนที่กลับมามาจากยุคไหนบ้าง
เลขสมาชิกเลขประจำการ์ดของคุณ เช่น MY-2026-0001
Progressรายการบทที่อ่าน เควสที่จบ ตรา การ์ด และของที่ปลดล็อก เพื่อเรียกคืนเมื่อ Login บนเครื่องใหม่
ข้อมูลเข้าสู่ระบบรหัสผ่านถูกแปลงเป็นค่า Hash พร้อม Salt ก่อนเก็บ เราไม่เก็บรหัสผ่านตัวจริง; ถ้าใช้ Google หรือ LINE เราเก็บรหัสอ้างอิงบัญชีจากผู้ให้บริการ
Sessionคุกกี้สำหรับจำว่าคุณ Login อยู่ มีอายุ 30 วัน และตั้งค่าไม่ให้ JavaScript อ่านค่าได้
วันเวลาที่คุณกดยินยอมไว้เป็นหลักฐานว่าคุณอนุญาตให้เก็บบัญชี, Progress หรือรับอีเมลในส่วนที่คุณเลือกเมื่อไหร่
คุณเพิ่มเพื่อน LINE แล้วหรือยังไว้ไม่ให้เราชวนซ้ำจนน่ารำคาญ
⚠️ สิ่งที่เราไม่เก็บเด็ดขาด
  • เบอร์โทรศัพท์
  • ที่อยู่
  • วันเกิด
  • น้ำหนัก ส่วนสูง หรือข้อมูลสุขภาพใด ๆ ทั้งสิ้น

แม้แต่ในส่วนที่คุยเรื่องสุขภาพ เราก็ไม่มีช่องให้กรอกข้อมูลพวกนี้ตั้งแต่แรก

3🖼️ รูปที่คุณใส่ในการ์ด ไม่ได้ถูกส่งมาหาเรา

เครื่องมือทำการ์ดประจำตัวทำงานในเครื่องของคุณเองทั้งหมด

รูปที่คุณเลือกใส่การ์ดถูกวาดขึ้นในเบราว์เซอร์ของคุณ ไม่ถูกอัปโหลดมาที่เซิร์ฟเวอร์ และไม่รวมอยู่ใน Cloud Save แม้คุณจะสร้างบัญชีก็ตาม ชื่อเล่นและประโยคบนการ์ดยังอยู่ในเครื่องนี้เช่นเดิม

ถ้าไม่สร้างบัญชี Progress จะอยู่ใน localStorage ของเครื่องนี้เท่านั้น ล้างข้อมูลเบราว์เซอร์เมื่อไหร่ก็หายไป; ถ้าสร้างบัญชี ระบบจะสำรองเฉพาะสถานะการเล่นและของที่ปลดล็อกเพื่อเรียกคืนตอน Login

4🎯 เราเอาไปทำอะไร

  • ส่งอีเมลประกาศของบ้าน — คลาสใหม่ ของฟรีชิ้นใหม่ กิจกรรมที่จะถึง
  • ส่งเรื่องที่ตรงกับสายที่คุณเลือก แทนที่จะส่งทุกอย่างให้ทุกคน
  • ออกเลขสมาชิกและตราบนการ์ดประจำตัวของคุณ
  • สำรองและรวม Progress ระหว่างเครื่องเมื่อคุณเลือกสร้างบัญชี

เราไม่ขาย ไม่แลก ไม่ให้เช่า ไม่ส่งต่อรายชื่อของคุณให้ใครทั้งนั้น ไม่ว่าจะเป็นบริษัท พันธมิตร หรือคนรู้จัก

และเราไม่เอารายชื่อจากที่นี่ไปทักชวนเรื่องธุรกิจโดยที่คุณไม่ได้เริ่มถามก่อน — เรื่องธุรกิจคุยกันเฉพาะในพื้นที่ของมันเอง หรือตอนที่คุณทักมาถามเองเท่านั้น

5⏳ เก็บไว้นานแค่ไหน

เก็บไว้จนกว่าคุณจะบอกให้ลบ หรือจนกว่าบ้านหลังนี้จะปิดตัว อย่างใดอย่างหนึ่งมาถึงก่อน ถ้าคุณกดยกเลิกรับอีเมล เราจะหยุดส่งทันที และถ้าคุณขอให้ลบ เราจะลบออกจริง ๆ

6✋ สิทธิของคุณ

ตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลของไทย (PDPA) คุณมีสิทธิเหล่านี้ และใช้ได้จริงโดยส่งอีเมลมาบอกคำเดียว:

  • ขอดู — ขอให้เราบอกว่าเรามีข้อมูลอะไรของคุณอยู่บ้าง
  • ขอแก้ — ชื่อผิด อีเมลเปลี่ยน เปลี่ยนสาย บอกได้ตลอด
  • ขอลบ — ให้ลบออกทั้งหมด เราลบให้แล้วยืนยันกลับ
  • ขอหยุดส่ง — ยกเลิกรับอีเมลได้ทุกเมื่อ ทุกฉบับมีลิงก์ยกเลิกอยู่ท้ายอีเมล
  • ถอนความยินยอม — ถอนได้ตลอดเวลา และไม่กระทบสิ่งที่เกิดขึ้นไปแล้วก่อนหน้านั้น

ความรู้และเครื่องมือฟรีทุกอย่างในบ้านนี้ยังเป็นของคุณเหมือนเดิม ต่อให้คุณขอลบข้อมูลออกไปแล้วก็ตาม

7🍪 คุกกี้และการติดตาม

เว็บนี้ไม่ใช้คุกกี้เพื่อโฆษณา และไม่มีตัวติดตามของบริษัทโฆษณาใด ๆ สิ่งที่เว็บเก็บไว้ในเบราว์เซอร์ของคุณเองคือค่าที่ทำให้เว็บใช้งานได้เท่านั้น เช่น สายที่คุณเลือก ชื่อบนการ์ด ความคืบหน้าการอ่าน และการที่คุณผ่านประตูบ้านมาแล้ว

เรานับจำนวนคนเข้าเว็บ เพื่อจะได้รู้ว่าควรทำอะไรเพิ่มให้คุณ

Cloudflare Web Analytics — นับว่าหน้าไหนมีคนเปิดกี่ครั้ง มาจากทางไหน ใช้เครื่องอะไรเปิด ตัวนี้ไม่วางคุกกี้ ไม่เก็บเลข IP และไม่ตามรอยข้ามเว็บ

Google Analytics (GA4) — ตัวเลขจาก Cloudflare หยาบเกินกว่าจะรู้ว่าคนอ่านการ์ตูนไปถึงตอนไหนแล้วหยุด เราเลยเพิ่มตัวนี้เข้ามา พูดกันตรง ๆ ว่า ตัวนี้วางคุกกี้ในเบราว์เซอร์ของคุณ เพื่อแยกว่าเป็นคนเดิมที่กลับมาหรือคนใหม่ เราปิดฟีเจอร์ฝั่งโฆษณาของมันทั้งหมด (ไม่ทำโฆษณาเจาะกลุ่ม ไม่ส่งข้อมูลไปให้ระบบโฆษณาของ Google) และตัดเลข IP ให้ไม่ครบก่อนบันทึก แต่เราจะไม่บอกว่ามันไม่แตะต้องอะไรเลย เพราะมันไม่จริง

นอกจากนับหน้า เรายังนับด้วยว่าปุ่มไหนถูกกดบ้าง เช่น มีคนกดเปิดส่วนไหนของหน้าแรก เลือกสายอะไร บันทึกการ์ดกี่คน — event เหล่านี้ไม่ส่งชื่อหรืออีเมลที่กรอกในแบบฟอร์ม แต่ระบบ analytics อาจใช้รหัสเบราว์เซอร์เพื่อแยกการเข้าชมแต่ละครั้ง

Microsoft Clarity — ตัวนี้แรงที่สุดในสามตัว และเราจะบอกให้ครบว่ามันทำอะไร มันบันทึกการเคลื่อนไหวบนหน้าจอของคุณ — เมาส์ไปทางไหน แตะตรงไหน เลื่อนถึงไหนแล้วหยุด แล้วเอามาทำเป็นภาพความร้อนว่าคนส่วนใหญ่กดตรงไหน และเปิดดูย้อนหลังเป็นคลิปได้ว่าคนใช้หน้านี้ยังไง เราใช้มันเพื่อดูว่าตรงไหนที่คนงงแล้วไปต่อไม่ถูก จะได้แก้ให้ถูกจุด ตัวนี้วางคุกกี้เหมือนกัน และตั้งค่าไว้ให้ปิดบังตัวหนังสือที่คุณพิมพ์ในช่องกรอก — สิ่งที่คุณพิมพ์ในฟอร์มลงทะเบียนจึงไม่ถูกบันทึกเป็นตัวอักษร

ข้อมูล analytics ไม่ได้ถูกผูกกับชื่อหรืออีเมลในทะเบียนสมาชิกของเราโดยตรง แต่ผู้ให้บริการ analytics อาจประมวลผลข้อมูลอุปกรณ์และการเข้าชมตามนโยบายของแต่ละบริษัท

ถ้าไม่อยากให้เว็บนับการเข้าชม คุณใช้โหมดไม่ระบุตัวตนหรือเครื่องมือบล็อก analytics ในเบราว์เซอร์ได้ เว็บยังใช้งานส่วนเนื้อหาและเครื่องมือหลักได้เหมือนเดิม ไม่มีบทเรียนถูกล็อกเพราะคุณบล็อกตัวนับ

เว็บนี้เรียกฟอนต์จาก Google Fonts เพื่อให้ตัวหนังสือไทยอ่านสวย ซึ่งทำให้ Google เห็นการเรียกไฟล์ฟอนต์ตามปกติของการโหลดหน้าเว็บ

8🔄 ถ้ามีการเปลี่ยนแปลง

ถ้าวันหนึ่งเราเก็บข้อมูลเพิ่มหรือเปลี่ยนวิธีใช้ เราจะแก้หน้านี้พร้อมลงวันที่ และถ้าเป็นเรื่องใหญ่ เราจะส่งอีเมลบอกคุณก่อน ไม่เปลี่ยนเงียบ ๆ

✉️ อยากขอดู ขอแก้ หรือขอลบข้อมูล?

เขียนมาบรรทัดเดียวก็พอครับ ไม่ต้องมีแบบฟอร์ม ไม่ต้องอธิบายเหตุผล เราจัดการให้ภายใน 30 วัน และส่วนใหญ่เร็วกว่านั้นมาก
