HRV · RHR

Baseline ของคุณ
สำคัญกว่าค่าเฉลี่ยของคนอื่น

HRV

อ่านเทียบ baseline ของตัวเองและดูแนวโน้มหลายคืน ไม่ควรใช้ HRV คืนเดียววินิจฉัยสุขภาพหรือเปรียบเทียบว่าใคร “แข็งแรงกว่า” ใคร

เส้นกลาง = baseline จำลอง · แถบ = ช่วงแนวโน้มตัวอย่าง

RHR

Resting Heart Rate ใช้ประกอบภาพ recovery และ trend เช่นเดียวกัน ถ้าค่าผิดปกติหรือมีอาการร่วม ควรใช้ผู้เชี่ยวชาญสุขภาพเป็นคนประเมิน ไม่ใช่หน้าเว็บ

อ่านแนวโน้ม ไม่ฟันธงจากจุดเดียว
GH Window

ถ้ามีการแสดง GH Window ใน UI ให้เล่าเป็น “ช่วงเวลานอนที่เอื้อต่อการฟื้นตัว” ไม่ควรสื่อว่าเป็นนาฬิกาฮอร์โมนตายตัวเหมือนกันทุกคน
