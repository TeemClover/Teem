# Xircle landing-page asset sources

Prepared on 2026-11-09 from the brand assets and app captures supplied for this landing-page update. Files here are optimized presentation copies; the downloaded Drive originals are retained separately in the delivery archive.

The Xircle and Routine X wordmarks use the supplied transparent logos. The Band, Scale, Routine X and HabiX product images use supplied product artwork, with format conversion and sizing for the web.

## Real app screens and food images

`home-ui.webp`, `sleep-ui.webp` and `move-ui.webp` come from the corresponding `XIRCLE UI - หน้าแรก.jpg`, `XIRCLE UI - Sleep Performance.jpg` and `XIRCLE UI - Move Performance.jpg` files in the UI folder. Crops remove the device status bar, account/avatar header and operating-system navigation where present. The displayed interface is captured from the real app. Its example values describe the interface and are not measurements of the visitor.

`food-bowl.png`, `food-rice.png` and `food-salad.png` are food-photo crops from the supplied `IMG_2404.PNG`, `IMG_2396.PNG` and `IMG_2343.PNG` screenshots. Only the food-photo areas are used; the original personal screenshots are not included in this public asset directory.

## Real scan recordings and posters

- `scan-demo-full.mp4`: [XIRCLE UI - AI Scan.mp4](https://drive.google.com/file/d/1tk0B2QOPBHg5v4iY6mKC_rQCsZBT1Efr/view), about 27.38 seconds.
- `scan-demo-short.mp4`: [XIRCLE UI - AI Scan 2.mp4](https://drive.google.com/file/d/1lV2q-26LK1OWLU9KEL-GFD3sm9aN4QEN/view), about 7.17 seconds.

Both recordings are cropped to 444 × 780 to remove the device status bar, account-points pill and Android navigation. Audio is removed, and the videos are encoded as H.264 with the playback metadata at the start for prompt web playback. The app background behind the result sheet was already blurred in the source recordings. `scan-poster.jpg` and `scan-short-poster.jpg` are frames from these processed recordings.

The separate interactive food demonstration on the page presents a guided example of the capture → ingredient review → nutrition flow. The real recordings remain available as explicitly labelled app footage.

## Generated hero scene

`band-hero.webp` is an optimized version of a Higgsfield-generated product presentation scene. Generation job: `a5b28c61-541b-48e0-91ea-9fa7d06a3528`; model: `gpt_image_2_6`; requested aspect ratio: 16:9, high quality, 2K. The supplied `XIRCLE_Band 03.JPEG` was used as the product reference for a warm ivory studio setting. The rendered original is 2688 × 1520, with an optimized web copy of about 287 KB.

The hero is an AI-generated presentation scene, not a documentary product photograph. The page identifies it as a simulated product scene. The phone interface shown beside it is a separate real-app capture; no generated health measurements or generated app screens are presented as actual app output.
