# myClover Home — บ้านจริง เปิดให้สำรวจ

เว็บตัวอย่างอสังหาริมทรัพย์สำหรับใช้สอนสร้างประสบการณ์ 3D จากแปลนและภาพอ้างอิง เส้นทาง `/showcase/house/` ใน repo Teem แยกจากระบบสมาชิกและเว็บส่วนอื่น

## ใช้งาน

ต้องมี Node.js ที่รองรับ ES modules (ตรวจด้วย Node 26.8.2 ในรอบนี้)

```sh
cd showcase/house
npm ci
npm run build
npm run dev
```

เปิด `http://127.0.0.1:4317/showcase/house/` ตัวเซิร์ฟเวอร์ bind เฉพาะเครื่องนี้ ไฟล์เว็บที่ build แล้วอยู่ `index.html`, `assets/`, `media/`, `downloads/` ใช้ relative URLs รองรับเส้นทางย่อยและ static hosting ของ repo เดิม

## สิ่งที่มี

- โมเดล Three.js จริง แปลน 2 ชั้น, 31 พื้นที่, 37 แนวผนังที่มีช่องเปิด
- ลากหมุน ซูม แพน เลือกชั้น เปิดผนัง หลบผนังตามกล้อง แยกชั้น เลือกห้อง คืนมุมเดิม
- หลังคาปั้นหยาสีดินเผาและแผงโซลาร์อ้างอิงลักษณะจากภาพโดรน; สัดส่วนแนวตั้งยังประมาณ
- โมเดลและแปลนใช้รหัสห้องเดียวกัน มีแปลนขยาย/เลื่อนและรายการห้องสำหรับคีย์บอร์ด
- ภาพจริง 21 ภาพใน 8 ชุด รวมภาพโดรนที่ครอบบ้านหลัก; ภาพไม่ได้ใช้เป็นพื้นผิวหลอก 3D
- ทัวร์เลือกเดินเอง, รายละเอียดที่มา, โหมดฝ้าห้องนั่งเล่น, WebGL failure fallback เป็นแปลน/ภาพ
- แปลน SVG 2 ชั้น, starter 2D, โค้ดเว็บ 3D ฉบับเต็มที่ไม่มีภาพถ่าย และคู่มือดัดแปลงงานลูกค้า

## โครงสร้าง

- `app/main.js` — หน้าจอ การเลือกห้อง แกลเลอรี แปลน และทัวร์
- `app/state.js` — สถานะเดียวกันระหว่างโมเดล/แปลน/ภาพ
- `app/scene.js`, `app/scene/` — กล้อง geometry ผนัง ช่องเปิด เฟอร์นิเจอร์ วัสดุ
- `app/data/house.js` — canonical rooms/walls/openings พร้อมระดับความเชื่อมั่น
- `app/data/photos.js` — allowlist ของภาพย่อและรูปเว็บ ไม่มีชื่อไฟล์ต้นฉบับ
- `app/validate.js` — ตรวจ polygon, overlap, opening, mapping และ export
- `tools/` — build, local preview, validation, public audit, ชุดเรียนรู้
- `tests/` — meaningful state/geometry tests
- `reports/` — ผลตรวจจริง; screenshots เก็บในเครื่องและไม่ commit
- `LEARN.md` — คู่มือนักเรียนและการปรับเป็นงานลูกค้า

ใช้ vanilla ES modules + Three.js แทน React/R3F เพื่อให้เข้ากับ repo static เดิม ไม่เพิ่มระบบ build ที่ root และไม่แก้ routing ส่วนอื่น esbuild ใช้เฉพาะรวมแพ็กเกจของตัวอย่างนี้; dependency versions ล็อกใน package-lock

## ตรวจงาน

```sh
npm test
npm run typecheck
npm run validate:house
npm run audit:public
```

`typecheck` ในโปรเจกต์ JavaScript นี้เป็น syntax checking (`node --check`) ไม่ใช่ TypeScript type analysis การทดสอบ browser ทำผ่านหน้าเว็บจริงและบันทึกใน `reports/QA.md` ไม่รวมผลโทรศัพท์จริงที่ยังไม่ได้ทดสอบ

## ที่มาและข้อจำกัด

ผังสองชั้นถอดจากสแกนและปรับแนวภาพแยกกัน ระยะ grid และผลต่างระดับพื้นหลัก 3.29 m อ้างอิงแบบ ค่า residual ของการ fit สแกนไม่ได้หมายถึงความแม่นยำหน้างาน ทุก calibration/geometry ยังระบุ draft; ไม่มีคำรับรองแบบก่อสร้าง

ภาพ 6 กลุ่มยังเป็น candidate ของห้องบนแปลน อีก 2 กลุ่มเป็นบริบทภายนอก ไม่มี confirmed photo pin UI บอกสถานะนี้และไม่แสดงภาพห้องอื่นแทนห้องที่ยังไม่มีภาพ รายละเอียดเฟอร์นิเจอร์ของแต่ละพื้นที่เป็นภาพประกอบเพื่อจำลอง ไม่ยืนยัน as-built

ความหนาผนัง slab ความสูงช่องเปิด ฝ้า รูปทรง/ความสูงหลังคา จำนวนและตำแหน่งแผงโซลาร์ จำนวนขั้นบันได และพื้นที่สวนเป็นค่าประมาณ/รูปแบบการนำเสนอ แยกชั้นเปลี่ยนเฉพาะ display transform ไม่แก้ระดับกายภาพ

เจ้าของโครงการระบุให้ใช้บ้านและแปลนเป็นตัวอย่างที่นักเรียนคัดลอกได้ เว็บและประสบการณ์โดย Teem / myClover ไม่อ้างว่าเป็นผู้ออกแบบสถาปัตยกรรม/ผู้ถ่ายภาพต้นฉบับ ข้อมูลเครดิตเจ้าของผลงานต้นทางยังไม่ยืนยัน ไม่ได้มอบลิขสิทธิ์ภาพถ่ายหรือสแกนให้ใช้ขายต่อ

ต้นฉบับ, PDF, EXIF/GPS, ที่อยู่, ชื่อไฟล์ส่วนตัว และภาพบุคคลที่ตัดออก ไม่อยู่ใน public route นี้ ต้นทางและ ledger รายละเอียดเก็บนอก repo ชุดภาพเว็บผ่านการครอบ/ปิดข้อมูลที่มองเห็นเพื่อเตรียมตัวอย่าง แต่การตรวจอัตโนมัติไม่ใช้แทนการยืนยันสิทธิ์ภาพ

## สถานะ

ตัวอย่างสำหรับตรวจผลงานและเรียนรู้ มีข้อมูลที่ยังรอยืนยันตามด้านบน ไม่ใช่โมเดล BIM หรือแบบก่อสร้าง งานนี้เตรียมสาขาเฉพาะและ draft pull request เพื่อ review ก่อนรวมเข้าหน้าเว็บหลัก ไม่มีการแก้ billing/auth หรือสั่ง production deployment
