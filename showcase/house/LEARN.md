# Home Explorer — คู่มือทำเว็บไซต์บ้านสำหรับลูกค้าอสังหาริมทรัพย์

ชุดนี้ใช้บ้านตัวอย่างเป็นโจทย์เรียนรู้การเชื่อมแปลน โมเดล และข้อมูลห้อง นักเรียนสามารถคัดลอกโค้ดต้นแบบและโครงสร้างข้อมูลไปดัดแปลงเป็นผลงานของตนเองหรือโครงการลูกค้าได้ โดยเปลี่ยนข้อมูลให้ตรงกับบ้านของลูกค้าจริง

แปลนที่วาดใหม่เป็นภาพอ้างอิงเพื่อศึกษาและทดลองทำเว็บไซต์ ไม่ใช่แบบก่อสร้างหรือแบบรับรองโดยสถาปนิก/วิศวกร ระดับความสูงผนัง หลังคา และรายละเอียดบางส่วนเป็นค่าประมาณ ห้ามนำพิกัดตัวอย่างไปอ้างว่าเป็นขนาดสำรวจจริง ผู้ถ่ายภาพและผู้ออกแบบแปลนต้นฉบับยังไม่มีข้อมูลเครดิตยืนยัน ชุดดาวน์โหลดจึงไม่มีภาพถ่ายหรือสแกนต้นฉบับ และไม่ได้ให้สิทธิ์นำผลงานของบุคคลอื่นไปขายต่อ

## เริ่มต้นภายในเครื่อง

มีชุดดาวน์โหลด 2 ระดับ: `home-explorer-starter.zip` เป็นตัวอย่างแปลน 2D สำหรับเริ่มเรียน ส่วน `home-explorer-3d-source.zip` มีโค้ดเว็บ 3D ฉบับเต็ม เฟอร์นิเจอร์ กล้อง การแยกชั้น และชุดทดสอบ พร้อมไฟล์ล็อก dependencies แต่ไม่มีภาพถ่ายบ้านจริง ให้เพิ่มภาพที่ลูกค้าอนุญาตใน `app/data/photos.js` ตามคู่มือใน ZIP สำหรับชุด 3D ให้รัน `npm ci` → `npm run build` → `npm run dev` แล้วเปิด `http://127.0.0.1:4317/showcase/house/`

ติดตั้ง Node.js รุ่นที่รองรับ ES modules หากมีอยู่แล้วให้ใช้รุ่นนั้น แตก ZIP เข้าโฟลเดอร์ใหม่ แล้วเปิด Terminal ในโฟลเดอร์นั้น:

```sh
npm start
```

เปิด `http://127.0.0.1:4173` ตามข้อความที่แสดง ตัวอย่างอ่าน JSON ผ่านเว็บเซิร์ฟเวอร์ จึงควรเปิดด้วยวิธีนี้แทนการดับเบิลคลิก HTML หากพอร์ตถูกใช้งานอยู่ ใช้ `PORT=4174 npm start` แล้วเปิดพอร์ตใหม่

เลือกชั้นจากแถบด้านบน คลิกห้องบนแปลนหรือในรายการ ชื่อห้องและรหัสที่เลือกต้องตรงกัน ลองแก้ชื่อห้องหนึ่งใน `house-data.json` แล้วรีเฟรช จากนั้นลองเปลี่ยน polygon ของห้องเล็ก 1 ห้องเพื่อเห็นผลของข้อมูลต่อหน้าจอ

## ข้อมูลบ้านทำงานอย่างไร

ใช้ `id` เป็นตัวเชื่อมข้อมูล ไม่ใช้ชื่อห้อง เพราะชื่อแสดงผลเปลี่ยนได้ ตัวอย่างรหัส `f1-g01-living` หมายถึงพื้นที่หนึ่งในชั้น `f1` รหัสในชุดนี้เป็นรหัสสำหรับเว็บ ไม่ใช่ข้อมูลทะเบียนบ้าน

| ข้อมูล | ความหมาย |
|---|---|
| `floors[].elevation` | ระดับพื้นหลักในหน่วยเมตร ชั้น 1 เป็น 0 และชั้น 2 เป็น 3.29 สำหรับบ้านตัวอย่างนี้ |
| `rooms[].polygon` | จุดล้อมพื้นที่ห้องในรูป `[x,z]` เรียงรอบขอบห้อง ไม่มีเส้นตัดกัน |
| `rooms[].levelOffset` | ระดับพื้นที่ย่อยเทียบกับพื้นหลักของชั้น |
| `rooms[].planLabel` | รหัสที่อ่านจากแปลน ถ้าไม่มีให้ใช้ `null` |
| `rooms[].evidenceStatus` | สถานะของหลักฐาน เช่น `derived` หรือ `assumed` ไม่ได้แปลว่าตรวจวัดหน้างานแล้ว |
| `walls[].a`, `walls[].b` | จุดเริ่มและจุดปลายแนวผนัง หนึ่งแนวร่วมใช้ผนังเดียว |
| `walls[].openings` | ช่องประตู/หน้าต่าง: `offset` นับจากจุดเริ่มผนังถึงขอบช่อง, `width`, `height`, `sill` เป็นเมตร |
| `stair.holePolygon` | ช่องบันไดที่ต้องหักออกจากพื้นชั้นบน ไม่ใช่พื้นที่กระจกเดินได้ |

แกน X เพิ่มไปทางขวาเมื่อมองจากหน้าบ้าน แกน Y คือความสูง ส่วน Z เพิ่มไปด้านหน้าบ้าน ดังนั้นด้านหลังมีค่า Z ติดลบ แปลน SVG ใช้ข้อมูล X/Z เดียวกับโมเดล จุดอ้างอิงไม่ใช่พิกัดภูมิศาสตร์

สถานะหน้าเว็บแยก `view` (ทั้งหลัง/ชั้น/แยกชั้น), `activeFloor`, `selectedRoomId`, `lens` (โมเดล/แปลน/ภาพ), และตัวเลือกการแสดงผล เปลี่ยนภาพในแกลเลอรีไม่ควรย้ายกล้อง เมื่อสลับชั้นต้องล้างห้องที่อยู่คนละชั้น และการแยกชั้นเป็นเพียงระยะเลื่อนเพื่อแสดงผล ห้ามแก้ `elevation` ของข้อมูลต้นทาง

## ลำดับทำงานกับบ้านลูกค้า

1. รับโจทย์และขอบเขตการใช้งาน: บ้านที่ขาย สิ่งที่ต้องให้ผู้ชมเข้าใจ ช่องทางติดต่อ และอุปกรณ์ที่ต้องรองรับ
2. ขอแปลนและภาพที่ลูกค้ามีสิทธิ์อนุญาตใช้ บันทึกผู้ให้ข้อมูล วันที่ และขอบเขตการเผยแพร่ แยกไฟล์ต้นฉบับจากไฟล์สำหรับเว็บ
3. เทียบทิศหน้าบ้านกับภาพจริงก่อนวาด เลือกแนวมิติที่อ่านได้เพื่อตั้งสเกล ตรวจผลรวมมิติและตำแหน่งบันไดทั้ง 2 ชั้น อย่าเดาขนาดที่มองไม่ชัดแล้วเรียกว่าค่าวัดจริง
4. สร้างข้อมูลห้องและแนวผนังด้วยรหัสคงที่ ตรวจ polygon ไม่ตัดกัน ห้องไม่ซ้อน ช่องเปิดไม่เกินแนวผนัง และระดับพื้นไม่เปลี่ยนเมื่อสลับการแสดงผล
5. ทำหน้าแปลนที่เลือกห้องได้ก่อน เชื่อมรายการห้องกับรหัสเดียวกัน แล้วใช้ข้อมูลชุดเดิมสร้างพื้นและผนังในโมเดล 3D
6. จัดกลุ่มภาพตามพื้นที่ที่เห็น แยกสถานะ `unmapped`, `candidate`, `confirmed` ภาพที่ยังไม่ทราบห้องให้ดูในแกลเลอรีรวมได้ แต่ห้ามปักลงห้องโดยเดา ให้ลูกค้าหรือผู้ตรวจที่ระบุชื่อยืนยันด้วยหลักฐานก่อนใช้สถานะ `confirmed`
7. ตรวจข้อมูลขายกับลูกค้าอีกครั้ง โดยเฉพาะราคา พื้นที่ใช้สอย สภาพบ้าน และอุปกรณ์ที่รวมในการขาย ห้ามคำนวณพื้นที่ขายจาก polygon ตัวอย่างแล้วนำไปโฆษณา
8. ทดลองให้คนที่ไม่เคยเห็นเว็บทำ 3 งาน: เปิดชั้นล่าง หาภาพครัว และกลับชั้นบน บันทึกปัญหาที่เกิดขึ้นจริงแล้วแก้ก่อนส่งมอบ
9. เตรียมภาพสำหรับเว็บที่ลดขนาดและลบข้อมูลส่วนตัวแล้ว ตรวจเลขบ้าน ทะเบียนรถ ใบหน้า บ้านข้างเคียง และข้อมูลแฝงของไฟล์ตามบริบท ขออนุมัติชุดที่จะเผยแพร่ แล้วจึงนำขึ้นระบบจริง

## แบบฝึกหัดที่ตรวจผลได้

**บทที่ 1 — ข้อมูลกับหน้าจอ:** เปลี่ยนชื่อห้อง 2 ห้องและเพิ่มคำอธิบาย ชื่อที่เห็นในแปลน รายการ และแผงรายละเอียดต้องตรงกันทั้งหมด

**บทที่ 2 — ห้องจากหลายมุม:** เพิ่มชุดภาพที่ได้รับสิทธิ์มาแล้ว 1 ชุด ระบุห้องที่ยืนยันได้และห้องที่ยังไม่ยืนยัน ทดสอบให้ห้องไม่มีภาพแสดงข้อความว่างอย่างถูกต้อง

**บทที่ 3 — แบบบ้านของลูกค้า:** เปลี่ยนแปลนตัวอย่างเป็นแปลนที่ได้รับอนุญาตของบ้านอีกหลัง ตรวจทิศหน้าอาคารและบันไดด้วยภาพอ้างอิง อย่าใช้จำนวนห้องหรือระดับความสูงจากบ้านตัวอย่างโดยอัตโนมัติ

**บทที่ 4 — ข้อเสนอผลงาน:** อธิบายว่าผู้ซื้อบ้านหาข้อมูลอะไรได้ง่ายขึ้น พร้อมระบุสิ่งที่ทำแล้ว สิ่งที่เป็นค่าประมาณ และสิ่งที่ลูกค้าต้องยืนยัน แนบภาพจากเว็บที่รันจริง

## ตรวจงานก่อนส่งมอบ

- เลือกห้องจากแปลนและรายการแล้วได้ `id` เดียวกัน สลับชั้นแล้วไม่มีภาพห้องเดิมค้าง
- เปิดบ้านทั้งหลัง เปิดชั้น 1/2 และคืนมุมเดิมได้จากทุกสถานะ
- ห้องที่ไม่มีภาพไม่ยืมภาพห้องอื่น แผนผังที่ยังรอตรวจแสดงสถานะตามจริง
- ช่องประตูและหน้าต่างเป็นช่องจริงใน 3D และบันไดไม่ทะลุพื้นชั้นบน
- ลองจอ 360 px, คีย์บอร์ด, การขยายข้อความ และโหมดลดการเคลื่อนไหว
- ทดสอบเมื่อภาพโหลดไม่สำเร็จและเมื่ออุปกรณ์เปิด 3D ไม่ได้ ยังดูแปลนและรายการห้องได้
- รายงานว่าใช้เครื่องจริงหรือจำลอง viewport อย่าเรียกผลจำลองว่าได้ทดสอบโทรศัพท์จริงแล้ว
- ตรวจไฟล์ที่จะเผยแพร่และสิทธิ์การใช้ภาพ/แบบ ตรวจช่องทางติดต่อและข้อมูลขายกับลูกค้า

## ขอบเขตการนำไปใช้

เจ้าของโครงการตั้งใจให้โค้ดต้นแบบและโครงสร้างข้อมูลนี้ใช้เรียนรู้ คัดลอก และดัดแปลงทำโครงการลูกค้าได้ ควรเปลี่ยนแบรนด์และเนื้อหาให้เป็นของตนเอง พร้อมเก็บบันทึกที่มาของข้อมูล ไม่ควรอ้างว่าเป็นงานออกแบบสถาปัตยกรรมของตนเองเพียงเพราะคัดลอกตัวอย่างเว็บ

การใช้แปลนวาดใหม่ในชุดนี้มีไว้ศึกษาโครงสร้างเว็บและทำผลงานตัวอย่าง ไม่ได้ยืนยันสิทธิ์ในแบบต้นฉบับแทนผู้ออกแบบ และไม่ใช่ใบอนุญาตก่อสร้าง การใช้แปลนหรือภาพจริงของบ้านอื่นในงานเชิงพาณิชย์ต้องมีสิทธิ์และเครดิตที่เหมาะสมจากเจ้าของผลงานนั้น
