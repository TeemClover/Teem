CONTROL PLANE

8 ระบบที่อาณาจักรต้องมี

หน้า Command Center ไม่ควรเป็น source of truth เอง — มันต้องอ่านโลกและสั่งงานโลก

01 · IDENTITYProject Manifest

ทุก project พูด schema เดียวกัน: ชื่อ stage owner route source release population

02 · DIRECTIONCurrent Goal + Next Action

แต่ละ project มีทิศเดียวที่ active และรู้สิ่งถัดไปจริง ๆ

03 · KNOWLEDGESource Graph

เห็น mother/child source, canon, consumer และ dependency ก่อนแก้

04 · MOTIONWork Queue

Teem → AI → Keen → Review → Merge → Live; รู้ทันทีว่างานค้างที่ใคร

05 · LABORAgent Registry

ใครทำอะไร อ่านอะไรได้ และบริเวณไหนห้ามแตะ

06 · DEFENSEHealth / Repo Warden

test, deploy, cron, dead route, stale source และ drift แบบ read-only ก่อน

07 · MEMORYDecision Memory

จำว่าล็อกอะไรไว้ เพราะอะไร เพื่อไม่ให้ AI รุ่นถัดไปช่วยแก้ผิดเรื่อง

08 · PEOPLEPopulation Command

คนเข้า คนทำ first action คนกลับ คนเห็นกัน และ bottleneck ของเมือง
