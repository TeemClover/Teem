# XTY Card Personalities

These files are the quiet, persistent voice canon for the launch animal
cards. A card keeps the same `personalityId` across Avatar, Lead and NPC
roles. Live-party use is intentionally sparse: party start, a meaningful
milestone, an unusual event, or the ending only.

Do not turn these into always-on chatbots and do not comment on every
Commit. Art, personality and Ending voice must describe the same animal.
