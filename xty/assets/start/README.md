## ลายเส้นที่ต้องตรงกัน

ยึดตาม `xty/assets/ending/ending-hero-7days.webp` เป็นตัวอ้างอิง:

- หน้ากระดาษสมุดฉีก มีรูเจาะด้านซ้าย ขอบกระดาษขาดเป็นริ้ว
- กระดาษครีมมีเส้นบรรทัดจาง ๆ
- ลายเส้นสีไม้ / สีเทียน มีเนื้อกระดาษ เส้นไม่เนี้ยบ วาดมือ
- สัตว์น่ารักแบบพรีเมียม ผูกผ้าพันคอ (แมวส้ม = ฟ้า, ปอมขาว = เขียว)
- ของประกอบ: เทปวาชิลายสก็อตฟ้า สติกเกอร์ใบไม้/ดอกไม้ ดินสอสีวางกระจาย
- โทนอุ่น ครีม–เขียวใบไม้

## ห้ามมีทุกภาพ

- ตัวหนังสือในภาพ
- หน้าจอ UI หรือกล่องแชต
- ภาพเหมือนจริง / 3D render
- โทนมืด หรืออารมณ์แข่งขัน
- สัญลักษณ์หุ่นยนต์หรือ AI

## Brief เต็ม

อยู่ในหน้า `/xty/start/` เอง — เปิดหน้านั้นแล้วจะเห็น brief แต่ละภาพอยู่ในกรอบ
ของตัวเอง พร้อมขนาดและ path ปลายทาง
