ทำไมรอบนี้ไม่เหมือนครั้งก่อน

เราเคยทำช่องลดน้ำหนักแล้วหยุดที่ 10 ตอน — เราเรียนรู้จากมันแล้ว และรอบนี้โครงสร้างต่างระดับ DNA

  • 1แรงจูงใจจริง ไม่ผูกกับยอดวิว คีนอยากลดเพื่อตัวเอง ไม่ว่าคลิปดังหรือไม่ การเดินทางก็เดินต่อ — คอนเทนต์คือ "ผลพลอยได้" ของชีวิตจริง ไม่ใช่ภาระที่ต้องฝืนทำ
  • 2อยู่บ้านเดียวกัน = ความต่อเนื่องเชิงโครงสร้าง ไม่ต้องนัดคิว ไม่ต้องเดินทาง กล้องอยู่ในบ้าน — จุดที่เคยทำให้ทุกช่องของเราหยุด ถูกถอดออกจากสมการ
  • 3ฟอร์แมตซีซัน 28 วัน = ตรงกับ RoutineX เป๊ะ 1 ซีซัน = 1 รอบ RoutineX = 4 ครั้งชั่งน้ำหนัก + คลิปสั้นรายวัน มีจุดเริ่ม-จุดจบชัดเจน ไม่ burnout และตัวสินค้าคือโครงเรื่องโดยธรรมชาติ
  • 4ดาราของเรื่องคือ "ตัวเลข" ไม่ใช่คน คีนไม่ต้องหล่อ ไม่ต้องมีเสน่ห์ดารา — จุดพีคของทุกตอนคือขึ้นตาชั่ง เลขจริงจาก Xircle Scale นี่คือ "ยุคที่ 3 Data-Driven" ของพี่ทอมในรูปแบบคอนเทนต์
  • 5ล้มได้ = ยิ่งจริง สัปดาห์ไหนน้ำหนักขึ้น เราไม่ตัดทิ้ง เราเล่ามัน — ความไม่สมบูรณ์แบบคือสิ่งที่ทำให้คนเชื่อและเอาใจช่วย (และไม่ผิดกฎ เพราะเราไม่เคยการันตีผลลัพธ์)

มูลค่าธุรกิจ 4 ชั้น จากเรื่องเดียว

🧾

1. หลักฐานมีชีวิตของสินค้า

RoutineX 28 วัน ถูกใช้จริง วัดจริง โชว์จริง — น่าเชื่อกว่าโฆษณาทุกชิ้น (ภายใต้กรอบ "ผลลัพธ์เฉพาะบุคคล")

🧲

2. แม่เหล็กรับสมัครตัวแทน

คนที่ติดตามคีนคือคนที่อยากลดเอง = ลูกค้า และบางส่วนอยากช่วยคนอื่นลด = ว่าที่ X-Visor เดินเข้าฟันเนลเอง

🎓

3. คีนโตเป็น X-Visor ตัวจริง

จบภารกิจ คีนคือ "ที่ปรึกษาที่ทำเองมาแล้วทั้งตัว" — เส้นทางอาชีพของน้อง และเคสสำเร็จที่จับต้องได้ที่สุดของบริษัท

♻️

4. ฟอร์แมตต้นแบบให้ทั้งกองทัพ

นี่คือชั้นที่มีค่าที่สุด: "โปรเจกต์ลดของตัวเอง 28 วัน" กลายเป็นสูตรที่ตัวแทนทุกคนก็อปได้ — ทุกตัวแทนคือเคสจริงของตัวเอง = กลไก Duplication ยุคใหม่

กรอบความปลอดภัย: แสดงผลเป็น "ผลลัพธ์เฉพาะบุคคล" เสมอ · ไม่การันตีตัวเลข · ควบคู่การคุมอาหารและออกกำลังกาย · มีการปรึกษาผู้เชี่ยวชาญด้านสุขภาพ · ไม่ผูกเคลมสินค้ากับเป้าน้ำหนัก · เผยแพร่เรื่องราวโดยความยินยอมของคีน — ตรงตามแนวจรรยาบรรณ สคบ. ที่ร่างไว้แล้ว

Partnership Models — รูปแบบความร่วมมือ

3 ทางเลือก เปิดคุยตรงไปตรงมา

เราเสนอโครงไว้ 3 แบบ — ตัวเลขจริงคุยกันในวงปิด สิ่งเดียวที่เราขอคือความชัดเจนตั้งแต่วันแรก เพื่อให้ทำงานกันยาวๆ ได้สบายใจทั้งสองฝั่ง

MODEL A

Studio Partner

Sanchuan เป็นสตูดิโอคู่สัญญา — ค่าบริการรายเดือน (Retainer) + โบนัสตามผลงาน
เหมาะเมื่อ: HQ อยากคุมทุกอย่างเอง จ้างเราผลิต

MODEL B

Media-first X-Gen

Sanchuan ถือสถานะ X-Gen "สังกัดสื่อ" ตามกติกา X-Commerce ที่มีอยู่แล้ว — ใช้คอนเทนต์และฟันเนลสร้างสังกัดของตัวเอง รับค่าบริหาร 5% ตามระบบ + ปั้น X-Lead/X-Visor ด้วยเครื่องมือของเรา
เหมาะเพราะ: ไม่ต้องออกกติกาใหม่ ใช้โครงพี่ทอมเดิม แรงจูงใจ align กันอัตโนมัติ — เราขายดี เราได้ HQ ได้

MODEL C

Hybrid

Retainer ขนาดเล็ก (คุ้มต้นทุนขั้นต่ำ) + สถานะสังกัดสื่อ + ส่วนแบ่งจากระบบที่เราสร้างให้ส่วนกลาง
เหมาะเมื่อ: ทั้งสองฝั่งอยากผูกระยะยาวแบบ win-win เต็มรูปแบบ

เริ่มได้ใน 7 วัน เห็นผลใน 90 วัน

จับมือ + วางราก

  • Content OS v1 พร้อมใช้ (ดัดแปลงจาก Studio OS)

ยิงกระสุนนัดแรก

  • Keen ซีซัน 1 (28 วัน) จบ + คลิปเปิดผล weigh-in ใหญ่

ขยายผล + วัดจริง

วันที่ 46–90
  • Keen ซีซัน 2–3 + เปิดฟอร์แมต "โปรเจกต์ลดของตัวเอง" ให้ตัวแทนรุ่นแรกทำตาม
  • สเกลคลังคอนเทนต์เป็น 100+ ชิ้น จัดหมวดตามสินค้า/สถานการณ์ขาย
  • รายงานดาต้าฉบับเต็ม: อะไรเวิร์ก อะไรไม่เวิร์ก → ปรับโมเดลรอบถัดไป

  2. ไทม์ไลน์จริงของสินค้า/แอป Xircle/Band/Scale — อะไรพร้อมขายวันนี้ อะไรคือแผนอนาคต (เราจะได้สื่อสารไม่เกินจริง)
  3. รูปแบบความร่วมมือ (Model A/B/C) และตัวเลขส่วนแบ่ง — เขียนเป็นลายลักษณ์อักษรตั้งแต่วันแรก
  4. การใช้เรื่องราวคีนกับแบรนด์ HabitX/RoutineX — กรอบการสื่อสารที่ทั้งสองฝั่งสบายใจและถูกกฎหมาย
  5. งบเริ่มต้นที่ HQ พร้อมสนับสนุน (สินค้าตัวอย่าง, ค่าโฆษณานำร่อง, อุปกรณ์) — เพื่อกำหนดสโคป 90 วันแรกให้ตรงความจริง
