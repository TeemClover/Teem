# แผนธุรกิจ CLOVER X (Compensation Plan)

แผนธุรกิจของ CLOVER X ถูกออกแบบมาเพื่อสร้างรายได้ที่มั่นคงและยั่งยืนให้กับตัวแทนจำหน่ายในทุกระดับ โดยแบ่งโครงสร้างรายได้ออกเป็น 3 ตำแหน่งหลัก ได้แก่ **XVisor**, **XLead** และ **XGen** ซึ่งแต่ละตำแหน่งจะมีโครงสร้างการรับรายได้ที่แตกต่างกันไปตามยอดขายส่วนตัวและการบริหารทีมงาน

## 1. โครงสร้างรายได้ตามตำแหน่ง

### 1.1 ตำแหน่ง XVisor (ตัวแทนจำหน่าย)
XVisor เป็นตำแหน่งเริ่มต้นที่เน้นการสร้างยอดขายส่วนตัว โดยจะได้รับรายได้จากคอมมิชชั่น (Commission) ตามขั้นบันได (Tier) ของยอดขายส่วนตัวในแต่ละเดือน ดังนี้:

*   **ระดับ Bronze (BR):** ยอดขาย 0 - 40,000 บาท ได้รับคอมมิชชั่น **20%**
*   **ระดับ Silver (SL):** ยอดขาย 40,001 - 100,000 บาท ได้รับคอมมิชชั่น **23%**
*   **ระดับ Gold (GOL):** ยอดขาย 100,001 บาทขึ้นไป ได้รับคอมมิชชั่น **25%**

*(หมายเหตุ: โครงสร้าง Fix Rate จะคิดจากฐาน 20% เป็นหลัก โดย 20% = 4%, 23% = 4.6%, 25% = 5%)*

### 1.2 ตำแหน่ง XLead (ผู้นำทีม)
XLead คือผู้ที่เริ่มสร้างและบริหารทีมงานของตนเอง โดยรายได้ของ XLead จะมาจาก 2 ส่วนหลัก:

1.  **รายได้จากยอดขายส่วนตัว:** รับคอมมิชชั่นแบบ Tier (20% - 25%) เหมือนตำแหน่ง XVisor
2.  **รายได้จากการบริหารทีม (Team Commission):** ได้รับ **4% - 5%** จากยอดขายรวมของทีม XVisor ที่ตนเองเป็นผู้แนะนำโดยตรง (Frontline XVisor)

### 1.3 ตำแหน่ง XGen (ผู้บริหารระดับสูง)
XGen คือตำแหน่งสูงสุดที่ดูแลภาพรวมขององค์กรขนาดใหญ่ โดยรายได้ของ XGen จะมาจาก 3 ส่วนหลัก:

1.  **รายได้จากยอดขายส่วนตัว:** รับคอมมิชชั่นแบบ Tier (20% - 25%) เหมือนตำแหน่ง XVisor
2.  **รายได้จากการแนะนำตรง:** ได้รับ **5%** จากยอดขายรวมของ XVisor ที่ตนเองแนะนำโดยตรง
3.  **รายได้จากการบริหารองค์กร (Generation Commission):** ได้รับ **1.75%** จากยอดขายรวมทั้งหมดของทั้งทีม ซึ่งรวมถึงยอดขายของ XLead และ XVisor ทุกคนภายใต้สายงานของตนเอง

## 2. ตัวอย่างการคำนวณรายได้ (Case Study)

เพื่อให้เห็นภาพที่ชัดเจนขึ้น ขอยกตัวอย่างโครงสร้างทีมขายทีมหนึ่งที่มี **ยอดขายรวมทั้งทีม 3,000,000 บาท** โดยสมมติโครงสร้างดังนี้:

*   **คุณ A (ตำแหน่ง XGen):** มียอดขายส่วนตัว 150,000 บาท
*   **ทีมงานภายใต้คุณ A:** มียอดขายรวม 2,850,000 บาท (รวมเป็น 3,000,000 บาท)
    *   *ในทีมประกอบด้วย XLead และ XVisor หลายคน*
*   **คุณ B (ตำแหน่ง XLead ภายใต้คุณ A):** มียอดขายส่วนตัว 50,000 บาท และมียอดขายรวมจากทีม XVisor ของตนเอง 500,000 บาท
*   **คุณ C (ตำแหน่ง XVisor ภายใต้คุณ B):** มียอดขายส่วนตัว 80,000 บาท

### การคำนวณรายได้ของคุณ C (XVisor)
คุณ C มียอดขายส่วนตัว 80,000 บาท ซึ่งตกอยู่ใน Tier ระดับ Silver (40,001 - 100,000 บาท) จะได้รับคอมมิชชั่น 23%
*   **รายได้ของคุณ C:** 80,000 x 23% = **18,400 บาท**

### การคำนวณรายได้ของคุณ B (XLead)
รายได้ของคุณ B มาจาก 2 ส่วน:
1.  **ยอดขายส่วนตัว:** 50,000 บาท (Tier Silver 23%) = 50,000 x 23% = 11,500 บาท
2.  **รายได้จากทีม XVisor:** 500,000 บาท (สมมติได้รับ 5%) = 500,000 x 5% = 25,000 บาท
*   **รวมรายได้ของคุณ B:** 11,500 + 25,000 = **36,500 บาท**

### การคำนวณรายได้ของคุณ A (XGen)
รายได้ของคุณ A มาจาก 3 ส่วน:
1.  **ยอดขายส่วนตัว:** 150,000 บาท (Tier Gold 25%) = 150,000 x 25% = 37,500 บาท
2.  **รายได้จาก XVisor ที่แนะนำตรง:** สมมติมี 1 คน ยอดขาย 100,000 บาท (ได้ 5%) = 100,000 x 5% = 5,000 บาท
3.  **รายได้จากยอดรวมทั้งทีม (1.75%):** ยอดรวมทั้งทีมคือ 3,000,000 บาท หักยอดส่วนตัว 150,000 และยอดแนะนำตรง 100,000 เหลือยอดทีมใต้สายงาน 2,750,000 บาท
    *   รายได้ 1.75% จากยอดทีม: 2,750,000 x 1.75% = 48,125 บาท
*   **รวมรายได้ของคุณ A:** 37,500 + 5,000 + 48,125 = **90,625 บาท**

*(หมายเหตุ: ตัวเลขนี้เป็นการคำนวณเบื้องต้นเพื่อให้เห็นภาพโครงสร้างรายได้เท่านั้น การคำนวณจริงอาจมีรายละเอียดเพิ่มเติมตามเงื่อนไขของบริษัท)*

## 3. สรุปจุดเด่นของแผนธุรกิจ CLOVER X

1.  **ยุติธรรมและยืดหยุ่น:** จ่ายผลตอบแทนตามความพยายามจริง ยิ่งขายมาก ยิ่งได้เปอร์เซ็นต์สูง (สูงสุด 25%)
2.  **สนับสนุนการสร้างทีม:** มีรายได้จากการบริหารทีม (4-5% สำหรับ XLead) กระตุ้นให้เกิดการสอนงานและดูแลทีม
3.  **ผลตอบแทนระยะยาว:** ตำแหน่ง XGen ได้รับผลตอบแทนจากยอดรวมทั้งองค์กร (1.75%) สร้าง Passive Income จากการบริหารทีมขนาดใหญ่
