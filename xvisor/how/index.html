วิธีใช้ บทเรียน เล่นเกม

วิธีใช้ทีละขั้น

มี 2 วิธี เริ่มจากวิธีแรกก่อนได้เลย ถ้าชอบค่อยทำวิธีที่สอง

ก · ใช้ทันทีไม่ต้องตั้งค่า ข · ติดตั้งไว้ใช้ซ้ำทำครั้งเดียว เปิดลิงก์ไม่ได้ใช้ไฟล์แทน
ก · ใช้ทันที

คัดลอก วาง แล้วตอบ

  1. กดปุ่มสีเขียว
    ระบบคัดลอกข้อความเริ่มงานให้ ไม่ต้องพิมพ์เอง
  2. เปิด Claude เริ่มแชตใหม่
    ถ้าข้างล่างมีปุ่ม "เปิด Claude" แตะได้เลย
  3. วางข้อความในช่องพิมพ์ แล้วกดส่ง
    แตะค้างที่ช่องพิมพ์ เลือก "วาง" ถ้าอยากเริ่มด้วยโจทย์ของพี่ เพิ่มต่อท้ายได้ เช่น "พี่มีรูปเครื่องชั่ง ไม่อยากออกกล้อง"
  4. ตอบ ก ข ค หรือ ง
    Claude ถามทีละเรื่อง ง คือพิมพ์เอง ส่งรูปหรือวิดีโอที่มีได้เลย

วิธีนี้ Claude อ่านชุดความรู้ได้เฉพาะแชตนั้น เริ่มแชตใหม่ต้องวางอีกครั้ง ถ้าอยากไม่ต้องวางทุกครั้ง ใช้วิธี ข

ดูข้อความที่จะถูกคัดลอก
ข · ติดตั้งไว้ใช้ซ้ำ

เพิ่มชุดสกิลใน Claude ครั้งเดียว

ทำบน Claude เว็บ (claude.ai) หรือแอปบนคอมพิวเตอร์ ตามเอกสารทางการของ Claude หลังติดตั้ง ไม่ต้องวางข้อความเริ่มงานทุกครั้ง ขั้นตอนนี้ยังไม่ได้ยืนยันว่าอัปโหลดจากแอปมือถือได้ ถ้าใช้มือถืออย่างเดียว ให้ใช้วิธี ก ต่อไป

  1. ดาวน์โหลดไฟล์ชุดสกิล
    ไม่ต้องแตกไฟล์ zip
    ดาวน์โหลด xvisor-skill.zip
  2. เปิด Claude แล้วไปที่ Customize > Skills
    กดอัปโหลด แล้วเลือกไฟล์ zip ที่เพิ่งโหลด
  3. เปิดสวิตช์สกิลชื่อ xvisor
    ถ้าสวิตช์เป็นสีเทาหรือกดไม่ได้ ดูหัวข้อ "ไม่เห็นเมนูหรือกดไม่ได้" ข้างล่าง
  4. ตรวจว่าติดตั้งสำเร็จ
    เริ่มแชตใหม่ พิมพ์แค่ "ช่วยพี่ทำคลิปแรก" โดยไม่วางข้อความอะไรเลย ถ้า Claude ถามเป็นข้อ ก ข ค ง แปลว่าใช้สกิลอยู่แล้ว ถ้าตอบทั่วไปไม่มี ก ข ค ง ให้กลับไปตรวจว่าสวิตช์เปิดอยู่
ไม่เห็นเมนูหรือกดไม่ได้
  • เปิด "Code execution and file creation" ที่ Settings > Capabilities ก่อน สกิลต้องใช้ตัวนี้
  • บัญชี Team หรือ Enterprise: เจ้าของระบบต้องเปิดในหน้า Organization settings > Plugins & skills
  • ไม่เห็นเมนู Skills เลย แปลว่าบัญชีหรือแอปนี้ยังไม่รองรับ ใช้วิธี ก ได้ผลเหมือนกัน
  • ชื่อเมนูอาจเปลี่ยนตามเวอร์ชันแอป ดูเอกสารทางการ: Use skills in Claude
ใช้ Claude Code อยู่แล้ว

เปิดลิงก์ไม่ได้

ใช้ไฟล์เริ่มต้นแทน

ถ้า Claude บอกว่าเปิดลิงก์ไม่ได้ ไม่ต้องกังวล ไฟล์เดียวนี้มีซอสพอทำคลิปแรกได้โดยไม่ต้องเปิดลิงก์อื่น

  1. กดคัดลอกเนื้อหาไฟล์ทั้งหมด
  2. วางในแชต Claude แล้วพิมพ์ต่อ
    "ช่วยพี่ทำคลิปแรกจากข้อความนี้" หรือกดดาวน์โหลดไฟล์ไปแนบในแชตก็ได้
    ดาวน์โหลดไฟล์เริ่มต้น
ไปบทเรียน3 บทสั้น จบแล้วมีชิ้นงาน กลับหน้าแรกเริ่มทำคลิปแรก
