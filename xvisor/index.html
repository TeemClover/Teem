ทำคลิปแรกของพี่
ด้วย Claude

ไม่ต้องติดตั้งอะไร ไม่ต้องออกกล้อง มีรูปหรือวิดีโอในมือถือก็พอ ได้บทพูด ลำดับช็อต ข้อความบนจอ และแคปชันพร้อมถ่าย

ทำแค่ 3 ขั้น: คัดลอก · เปิด Claude แล้ววาง · ตอบ ก ข ค

ดูข้อความที่จะถูกคัดลอก

3 ขั้น ใช้ได้เลย

  1. กดปุ่มสีเขียวข้างบน
    ข้อความเริ่มงานจะถูกคัดลอกให้ พร้อมลิงก์ชุดสกิลแล้ว ไม่ต้องพิมพ์เอง
  2. เปิด Claude เริ่มแชตใหม่
    แตะที่ช่องพิมพ์ค้างไว้ เลือก "วาง" แล้วกดส่ง
  3. ตอบ ก ข ค หรือ ง
    Claude จะถามทีละเรื่อง ง คือพิมพ์เอง จะส่งรูปหรือวิดีโอที่มีเข้าไปด้วยก็ได้

สุดท้ายพี่จะได้อะไร

ตัวอย่างจากโจทย์ "มีรูปเครื่องชั่ง ไม่อยากออกกล้อง" ถามไม่เกิน 2 ข้อก็ได้ชุดพร้อมถ่าย

พี่พิมพ์มีรูปเครื่องชั่งที่ถ่ายไว้เมื่อเช้า อยากทำคลิป แต่ไม่อยากออกกล้อง
Claude ถามคลิปนี้อยากให้ใครดูคะ
  • ก คนที่ชั่งแล้วเห็นเลขขึ้นลงแล้วสับสน (แนะนำ)
  • ข คนที่ยังไม่มีเครื่องชั่ง
  • ค ลูกค้าที่มีเครื่องชั่ง XIRCLE อยู่แล้ว
  • ง พิมพ์เอง

ชุดพร้อมถ่าย (ตัวอย่างบางส่วน)
ชื่อคลิป

Hook 3 วินาทีแรก

แคปชัน
ชั่งแล้วเลขขึ้น ไม่ได้แปลว่าแย่เสมอไป ลองดูเป็นแนวโน้มหลายวัน แล้วเลือกลองเรื่องเล็ก ๆ หนึ่งอย่าง
ตรวจคำเสี่ยง
ผ่าน ไม่มีคำรักษา รับประกัน หรือตัวเลขผลลัพธ์

นี่คือตัวอย่างที่เขียนไว้ให้ดูว่างานหน้าตาแบบไหน ไม่ใช่ภาพหน้าจอจริงของ Claude ผลที่พี่ได้จะเปลี่ยนตามรูปและคำตอบของพี่

อยากเริ่มจากเรื่องไหน

กดปุ่มไหนก็ได้ ข้อความที่คัดลอกจะบอก Claude ให้เริ่มจากเรื่องนั้นเลย ไม่ต้องตอบคำถามเดิมซ้ำ

ทำคลิป จากรูปหรือวิดีโอในมือถือ ไม่ต้องออกกล้อง
วางแผนช่อง ได้แผน 1 หน้า กับตารางสัปดาห์แรก
หาข้อมูลสินค้า ข้อมูลที่อนุมัติแล้ว พร้อมลิงก์ให้ตรวจ
หาโลโก้และภาพ โลโก้ ภาพสินค้า ลิงก์ตรงให้โหลด
ฝึกใช้ AI บทเรียนสั้น 3 บท จบแล้วมีชิ้นงาน

ทำครั้งเดียวบนเว็บหรือแอปคอมพิวเตอร์ แล้วครั้งต่อไปไม่ต้องวางข้อความอีก ขั้นตอนอ่านได้ที่หน้าวิธีใช้

Claude เปิดลิงก์ไม่ได้ ทำยังไง

บางแอปหรือบางบัญชีเปิดลิงก์ GitHub ไม่ได้ Claude จะบอกพี่เองว่าอ่านไม่ได้ ให้ใช้ไฟล์เริ่มต้นแทน ไฟล์เดียวมีทุกอย่างที่ต้องใช้ทำคลิปแรก

แล้วเปิด Claude วางในแชตใหม่ และพิมพ์ต่อว่า "ช่วยพี่ทำคลิปแรกจากข้อความนี้"
