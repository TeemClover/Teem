ข้อมูลของคุณ

เก็บเท่าที่สมุดต้องใช้

TeamBook ใช้บัญชีและข้อมูลของตัวเอง ข้อมูลในบริการอื่นจะไม่ถูกนำมาเชื่อมโดยอัตโนมัติ

ข้อมูลในเครื่อง

ชื่อในสมุด ตัวละคร สมุดที่เข้าร่วม token สำหรับเปิดสมุด และ Progress บางส่วนเก็บใน browser ของอุปกรณ์นี้ก่อน คุณใช้ TeamBook แบบไม่สมัครบัญชีได้ แต่ข้อมูลอาจหายเมื่อเคลียร์ browser หรือเปลี่ยนเครื่อง

ข้อมูลบนระบบ

เมื่อเปิดหรือเข้าร่วมสมุด ระบบเก็บสมาชิก ข้อความ การลงชื่อ ปฏิกิริยา การ์ด และสถานะของสมุดในฐานข้อมูล TeamBook โดยเฉพาะ หากอัปโหลดภาพ ไฟล์ภาพจะเก็บใน Vercel Blob

สถิติการใช้งานเพื่อพัฒนา TeamBook

ระบบเก็บสถิติแบบ first-party เช่น หน้าที่เปิด จำนวนครั้งที่กลับมา session เวลาใช้งานขณะหน้า active ระดับการเลื่อนอ่าน และการเดินไปหน้าถัดไป เพื่อนำไปดูว่าคนใช้จริงติดตรงไหนและควรพัฒนาส่วนใด ข้อมูลนี้ไม่เก็บ query string, invite code หรือ IP address และไม่ส่งให้เครือข่ายโฆษณาภายนอก หากมีบัญชีหรือโปรไฟล์ TeamBook ระบบอาจผูกสถิติกับรหัสภายในเพื่อดูพฤติกรรมต่อเนื่อง เช่น การกลับมาใช้ซ้ำ จำนวนข้อความ และจำนวนครั้งที่ลงชื่อ

บัญชีและการสำรอง Progress

ถ้าคุณสมัครบัญชี ระบบจะเก็บอีเมล ชื่อที่ให้เรียก ข้อมูลเข้าสู่ระบบที่ผ่านการเข้ารหัส และ Progress เพื่อเรียกคืนภายหลัง อีเมลรหัสยืนยันส่งผ่าน Resend ส่วน LINE หรือ Google จะใช้เฉพาะเมื่อเปิดการเชื่อมต่อไว้

เพื่อนร่วมทาง AI

เมื่อเปิดใช้เพื่อนร่วมทางที่ตอบด้วย AI ข้อความและภาพที่เกี่ยวข้องในบันทึกสมุดอาจถูกส่งไปยัง Groq เพื่อสร้างคำตอบ ระบบใช้ข้อมูลนั้นเพื่อการสนทนาในสมุด ไม่ใช้เพื่อโฆษณา
