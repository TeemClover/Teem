# สมองสัตว์ประจำตี้ TeamBook

แยกเป็นสามชั้น เพื่อให้ **กติกาใหม่แก้ที่เดียว** และ **สัตว์ใหม่เพิ่มไฟล์เดียว**

```
constitution.js   กติกากลาง — ทุกตัวใช้ร่วมกัน (คิดยังไง พูดเมื่อไหร่ ห้ามอะไร)
sauce/<ตัว>.js    บุคลิกรายตัว — ตอบคำถามเดียว: "ฟังดูเป็นใคร"
compose.js        เอาสองอย่างมาต่อกันเป็น prompt
../pet-brain.js   คุยกับโมเดล อ่านรูป กรองผลลัพธ์ กันพูดซ้ำ
```

## ลำดับการคิดของสัตว์ (บังคับด้วย JSON schema)

โมเดลตอบกลับมาเป็น 6 ช่อง และต้องกรอกตามลำดับนี้:

| ช่อง | คือ | มีบุคลิกไหม |
| --- | --- | --- |
| `situation` | เกิดอะไรขึ้นจริงในตี้ | ไม่มี |
| `behavior` | เลือกทำอะไร (QUIET/REACT/ACK/CALLBACK/ANSWER/TEASE/REMIND/ASK) | ไม่มี |
| `focus` | fact ที่ทำให้เลือกแบบนั้น | ไม่มี |
| `open_threads` | เรื่องที่ยังค้าง | ไม่มี |
| `intent` | ตั้งใจจะสื่ออะไร เขียนกลาง ๆ | ไม่มี |
| `bubbles` | `intent` เดิมที่แต่งเป็นเสียงของตัวเองแล้ว | **มี** |

บุคลิกจึงเป็นชั้นบาง ๆ ที่ทาทับ *หลัง* ตัดสินใจเสร็จ ไม่ใช่สิ่งที่ครอบความคิด
ตั้งแต่ต้น — และเพราะ `intent` ถูกบันทึกแยก เราตรวจได้ว่าเสียงที่ออกมาตรงกับ
สิ่งที่ตั้งใจจะสื่อหรือเปล่า

## เพิ่มกติกาใหม่

แก้ `constitution.js` ไฟล์เดียว สัตว์ทุกตัวได้พร้อมกัน ห้ามเขียนกติกาลงไฟล์ซอส —
มีเทสต์ (`pet-v1-standard.test.mjs`) คอยจับไว้

## เพิ่มสัตว์ใหม่

1. สร้าง `sauce/<ตัว>.js` — ใส่เฉพาะ `role / character / voice / whenEngaging /
   heavyMode / ending` เท่าที่มี
2. ต่อ import ใน `sauce/index.js` หนึ่งบรรทัด

ไม่ต้องแตะ `constitution.js`, `compose.js` หรือ `pet-brain.js` เลย
สัตว์ที่ยังไม่มีไฟล์ซอสก็ยังพูดได้ แค่เสียงจะกลาง ๆ (ดูที่ `sauceFor`)

## ตัวแปรที่คุมพฤติกรรมจาก env

| ตัวแปร | ผล |
| --- | --- |
| `TEAMBOOK_PET_AI=on` + `GROQ_API_KEY` | เปิดสมอง ถ้าไม่ตั้ง สัตว์จะเงียบสนิท |
| `TEAMBOOK_PET_VISION=on` | เปิดให้ดูรูปที่แนบในตี้ (ส่งรูปออกไปที่ผู้ให้บริการโมเดล) |
| `TEAMBOOK_PET_TEXT_MODEL` / `TEAMBOOK_PET_VISION_MODEL` | เปลี่ยนรุ่นโมเดลโดยไม่ต้อง deploy |
