ก่อนเข้ามา

Guild X รองรับการเข้ามาแบบใช้นามแฝงและ avatar เพราะจุดสำคัญไม่ใช่ชื่อจริง แต่คือสิ่งที่มึงเอาเข้ามาเชื่อมกับระบบ คนที่พูดน้อยในโลกจริงอาจกลายเป็นคนที่ปล่อย source ดีที่สุดใน Guild ก็ได้

หน้านี้เลยใช้ภาพ avatar PNG จริงมาวางแบบ premium card บน glass stage ให้มันสื่อความรู้สึกว่า anonymity ไม่ได้แปลว่ามั่ว แต่มันคือพื้นที่ปลอดภัยสำหรับการลอง ของจริงคือ contribution ไม่ใช่หน้าตา

Hero Upgrade Flow

จากการ์ดธรรมดา
กลายเป็น HERO

Guild X ไม่ควรจบแค่คำว่า “join community” แต่ต้องมีผลลัพธ์ที่รู้สึกได้ทันที หน้านี้เลยชัดมากว่าหลังจากเข้า Guild แล้ว มึงจะได้รับ Hero Upgrade Code เพื่อเอากลับไปใช้ในหน้า /card และเปลี่ยนสถานะการ์ดเป็น HERO

ทั้ง visual และ flow ถูกออกแบบให้ดูเหมือน product reveal ของ Apple: step ชัด ภาพเด่น clean และมีแค่ข้อมูลที่สำคัญจริง ๆ
