# Guild X — Asset Request (FX / Motion)

ของที่ขอเพิ่มเพื่อดัน `/guild` ต่อ แต่ละชิ้นบอกไว้ว่าจะเอาไปใช้ตรงไหนและปลดล็อก animation อะไร
ถ้าเจนไม่ครบ ให้ไล่จาก **P0 → P1 → P2** ตามลำดับ P0 คุ้มที่สุดเพราะเป็นภาพเดิม แค่เปลี่ยน canvas

---

## กฎที่ต้องทำทุกชิ้น (สำคัญ)

1. **อย่าให้ art ชนขอบ canvas — เว้น margin ว่างรอบด้านอย่างน้อย 4%**
   เพิ่งแก้ปัญหานี้ไปกับ `petal-*.png` ทั้ง 8 ไฟล์: ตัวโคลเวอร์ถูก export แบบล้นออกนอก canvas ทุกกลีบเลยจบด้วยเส้นตรงแทนส่วนโค้ง เห็นเป็นใบแหว่ง 4 ด้านบนหน้าเว็บ ต้องซ่อมกลับทีละกลีบ ขอให้เช็ค alpha ก่อนส่ง: แถวบนสุด/ล่างสุด/ซ้ายสุด/ขวาสุดของภาพต้องโปร่งใสทั้งแถว
2. **PNG โปร่งใสจริง** ไม่มีพื้นดำ/พื้นเขียวติดมา (เช็คด้วยการวางบนพื้นขาว)
3. **จัด art ให้อยู่กึ่งกลาง canvas** ทุกชิ้นที่จะเอาไปหมุน ไม่งั้นหมุนแล้วส่าย
4. **ไม่มีตัวหนังสือในภาพ** ข้อความทั้งหมดเป็น HTML จริง
5. โทน: black / emerald / antique gold + 4 path colors (red · green · blue · silver)
6. ตั้งชื่อไฟล์ตัวเล็ก คั่นด้วย `-` เก็บใน `/guild/assets/` (ของ FX ใหม่เก็บใน `/guild/assets/extras/` ได้)

---

## P0 — Re-export ของเดิมเป็นจัตุรัส 1:1

ภาพกลุ่มนี้เป็นเอฟเฟกต์ทรงกลม/แผ่รัศมี แต่ export มาเป็น 3:2 (หรือ 2:3) แล้วโค้ดวางไว้ในกล่องจัตุรัส
`object-fit:contain` เลยใส่ขอบว่างให้ ทำให้ภาพจริงเล็กกว่าที่ควรมาก — วัดจากหน้าเว็บจริงที่ 1440px:

| ไฟล์ | ตอนนี้ | กินพื้นที่กล่องจริง | ขอใหม่ |
|---|---|---:|---|
| `ring-portal.png` | 1536×1024 | **67%** | 1536×1536 |
| `x-energy.png` | 1536×1024 | **67%** | 1536×1536 |
| `spark-x.png` | 1536×1024 | **67%** | 1536×1536 |
| `emerald_clover_dust_swirl_overlay.png` | 1536×1024 | **59%** | 1536×1536 |
| `emerald_gold_starburst_emblem.png` | 1024×1536 | **65%** | 1536×1536 |

เป็นภาพเดิมทุกอย่าง แค่ให้ตัวเอฟเฟกต์เต็มกรอบจัตุรัส (ไม่ใช่เอาภาพเดิมมาแปะกลางผ้าใบจัตุรัส —
ต้องวาดให้รัศมีกระจายเต็มทั้ง 4 ทิศ) ได้อันนี้ วงแหวน/พลัง X ในหน้า hero จะใหญ่ขึ้นราว 50% ทันทีโดยไม่ต้องแก้ CSS

## P1 — ของใหม่ที่มีที่ใช้แน่นอน

### `foil-holo-tile.png`
- **1024×1024 · seamless tile · โปร่งใส**
- ลาย holographic/iridescent แบบฟอยล์การ์ดสะสม — เส้นรุ้งบาง ๆ เหลือบเขียว-ทอง-ม่วง บนพื้นโปร่ง
- ใช้ทับหน้าการ์ด HERO ผ่าน mask ที่ทำไว้แล้ว (`.card-sheen`) แทนแถบขาวเรียบ ๆ ที่ใช้อยู่
- ปลดล็อก: เลื่อน tile ช้า ๆ ใต้ mask = การ์ดเหลือบรุ้งตอนขยับ เหมือนเอียงการ์ดจริง

### `grain-tile.png`
- **512×512 · seamless tile · โปร่งใส · ขาวดำ**
- noise/grain ฟิล์มละเอียด opacity ต่ำ
- ใช้ทับ panel ทั้งหน้าแบบ `mix-blend-mode:overlay` opacity ~4%
- ปลดล็อก: ลด banding ของ gradient เขียว-ดำ และทำให้ทั้งหน้าดู "ถ่ายมา" ไม่ใช่ "เรนเดอร์มา" — ชิ้นเล็กแต่ยกคุณภาพทั้งหน้า

### `ember-motes.png`
- **1024×1024 · โปร่งใส**
- ฝุ่นแสง/ประกายลอย กระจายไม่สม่ำเสมอ มีทั้งเม็ดคมและเม็ดเบลอ สีเขียวมรกต + ทอง
- ใช้ 2–3 ชั้นซ้อนใน hero กับ dungeon เลื่อนคนละความเร็ว
- ปลดล็อก: parallax แบบมีความลึกจริง ตอนนี้ `dust` มีชั้นเดียวเลยได้แค่หมุน

### `light-shafts.png`
- **1536×1536 · โปร่งใส**
- ลำแสง (god rays) พุ่งลงจากบนกลาง กระจายเป็นรูปพัด ขอบฟุ้ง สีทองอมเขียว
- ใช้หลัง panel ปิดท้าย "Endgame คือ Multiplayer"
- ปลดล็อก: ให้ CTA สุดท้ายมีน้ำหนัก ตอนนี้มีแค่ตัว X จาง ๆ เป็นพื้นหลัง

### `petal-glow-red.png` · `-green.png` · `-blue.png` · `-silver.png`
- **1024×1024 · โปร่งใส · ชุด 4 ไฟล์**
- แสงเรืองล้วน ๆ (glow only) ทรงเดียวกับกลีบแต่ละสี ไม่มีขอบทอง ไม่มีเนื้อกลีบ — เอาไว้วางซ้อนแบบ additive
- ใช้ใต้การ์ด 4 Paths และใต้กลีบใน hero
- ปลดล็อก: ตอนการ์ด path เลื่อนเข้าจอ ให้กลีบสีนั้นเรืองขึ้นมาหนึ่งจังหวะ — บนมือถือที่ไม่มี hover จะได้มีอะไรตอบสนอง

## P2 — ถ้ามีเวลา

### `dungeon-door.png`
- **1024×1536 · โปร่งใส**
- ประตูหิน/ไม้เก่ามีขอบทอง แง้มออกนิดหน่อย มีแสงลอดจากในประตู
- section Dungeon ตอนนี้มีแค่หีบกับกุญแจ ยังไม่มีตัว "ประตู" ที่ชื่อ section พูดถึง

### `rune-band.png`
- **1536×1536 · โปร่งใส · หมุนได้ 360° แบบไร้รอยต่อ**
- แถบวงแหวนอักขระรูน เรียงรอบวงสม่ำเสมอ ศูนย์กลางตรงเป๊ะ
- ซ้อนรอบ `.orbital` หมุนสวนทางกับ `ring-portal`
- ปลดล็อก: ชั้นความลึกอีกชั้นใน hero โดยไม่ต้องเพิ่มภาพใหญ่

### `path-emblem-{taster,keeper,thinker,maker}.png`
- **512×512 · โปร่งใส · ชุด 4 ไฟล์**
- สัญลักษณ์ประจำ path (ไม่ใช่กลีบ) — เช่น ลิ้ม/เก็บ/คิด/สร้าง ในสไตล์ตราทองบนพื้นโปร่ง
- ตอนนี้ทั้ง badge role และการ์ด 4 Paths ใช้รูปกลีบซ้ำกันหมด ทำให้แยก path ด้วยสีอย่างเดียว
