SOURCE-BASED AI WORKFLOW

AI ใส่ซอสไม่ได้สอนให้จำ Prompt เยอะขึ้น แต่วางวัตถุดิบให้ AI ทำงานตรงกับคุณมากขึ้น

Prompt ยังใช้ แต่เป็นเพียงคำสั่งของจานนั้น ส่วน Source คือวัตถุดิบ สูตร รสมือ และกติกาที่ควรติดไปกับทุกจาน

ก่อนมี Source

เริ่มใหม่ทุกครั้ง แล้วหวังว่า AI จะจำเราได้

  • ก๊อป Prompt จากคนอื่นแล้วปรับไปเรื่อย ๆ
  • ส่งไฟล์กองเดิมให้ AI อ่านใหม่ทุกแชต
  • กติกาและคำตัดสินล่าสุดกระจายหลายที่
  • แก้งานปลายทางซ้ำโดยไม่รู้ว่าต้นเหตุอยู่ไหน
→
หลังมีซอสขวดแรก

มี Source 1 ชุดที่พกไปเริ่มงานกับ AI ตัวไหนก็ได้

  • เป้าหมาย ข้อเท็จจริง น้ำเสียง และข้อห้ามอยู่ด้วยกัน
  • ตรวจและแก้ความเข้าใจที่ต้นทางได้
  • ใช้ Source เดิมสร้างงานได้หลายรูปแบบ
  • คนอื่นรับงานต่อได้โดยไม่ต้องเดาใหม่ทั้งหมด
กลับบ้านพร้อมอะไร

ไม่ได้กลับไปพร้อมแค่ความรู้ แต่พร้อมของที่เปิดใช้ต่อได้

ผลลัพธ์ของแต่ละคนไม่จำเป็นต้องเหมือนกัน เพราะทุกคนเข้าห้องด้วยวัตถุดิบและ Quest คนละแบบ

FAQ

คำถามที่น่าจะอยากรู้ก่อนตัดสินใจ

ต้องเขียน Prompt เก่งก่อนหรือไม่?

ไม่ต้อง จุดเริ่มของคลาสคือสิ่งที่คุณมีอยู่แล้ว เราจะใช้ AI ช่วยถาม สกัด และจัดโครงสร้าง ก่อนค่อยเลือกคำสั่งที่เหมาะกับงานปลายทาง

ต้องใช้ ChatGPT หรือ AI แบบเสียเงินหรือไม่?

หลักสูตรไม่ผูกกับ AI ตัวเดียว คุณสามารถเริ่มจากเครื่องมือที่มีอยู่ได้ ในรอบจริงจะมีรายการเครื่องมือและทางเลือกฟรี/เสียเงินแจ้งให้เตรียมล่วงหน้า

คนที่ไม่มีพื้นฐานเทคนิคเรียนได้ไหม?

ได้ เนื้อหาหลักคือการจัดความรู้และตัดสินใจเกี่ยวกับงานของตัวเอง ไม่ได้เน้นเขียนโค้ด ผู้เรียนต้องใช้คอมพิวเตอร์พื้นฐานและพร้อมลองทำตามเท่านั้น

ควรเอาโปรเจกต์แบบไหนมา?

เลือกงานที่คุณอยากให้เกิดขึ้นจริงและมีวัตถุดิบอยู่บ้างแล้ว เช่น เอกสารกองหนึ่ง ความรู้ในหัว คลิปเสียง แชตเดิม หลักสูตรที่ค้าง คู่มือ Proposal หรือไอเดียเว็บไซต์

จบคลาสแล้วงานจะเสร็จสมบูรณ์ 100% ไหม?

เป้าหมายคือให้คุณได้ Source ที่ตรวจแล้ว ผลงานชิ้นแรกที่จับต้องได้ และเส้นทางทำต่อที่ชัด ความสมบูรณ์ของงานขึ้นกับขนาดโปรเจกต์ คุณภาพวัตถุดิบ และสิ่งที่ต้องตรวจสอบเพิ่มเติม

ต่างจากคอร์ส Prompt ทั่วไปอย่างไร?

คอร์ส Prompt มักเริ่มจากคำสั่ง ส่วน AI ใส่ซอสเริ่มจากความรู้ กติกา ข้อห้าม และเสียงของเจ้าของงาน แล้วสร้าง Source กลางไว้ก่อน คำสั่งจึงสั้นลงและผลลัพธ์หลายชิ้นอ้างอิงแกนเดียวกันได้

ตอนนี้สมัครและจ่ายเงินได้เลยหรือยัง?

ยัง รอบแรกอยู่ระหว่างออกแบบรายละเอียด แอด LINE บ้าน myClover เพื่อรับประกาศวัน เวลา สถานที่ ราคา และสิทธิ์ Founding Class ก่อนเปิดสาธารณะ

เอาของที่มีอยู่แล้วมา

อย่าปล่อยให้ความรู้ดี ๆ ต้องเริ่มใหม่ทุกครั้งที่เปิดแชตใหม่

ทำให้มันกลายเป็น Source ที่ AI เข้าใจ คนอื่นรับต่อได้ และคุณนำกลับมาใช้สร้างงานชิ้นถัดไปโดยไม่เสียของเดิม
