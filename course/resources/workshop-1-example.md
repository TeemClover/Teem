# ตัวอย่างคำตอบ Workshop 1 — โพสต์ 1 ชิ้น + คำตอบ 3 สถานการณ์

> ตัวอย่างจากข้อมูลสมมติ “คลินิกยิ้มตัวอย่าง” ไม่ใช่ข้อความพร้อมเผยแพร่ในนาม The Dent ต้องแทนข้อมูลและตรวจอนุมัติก่อนใช้จริง

## โพสต์ตัวอย่าง

อยากวางแผนเข้ามาปรึกษา เริ่มต้นได้ง่าย ๆ ครับ

ส่งวันและช่วงเวลาที่สะดวกทาง Inbox ของคลินิกยิ้มตัวอย่าง แล้วรอแอดมินตรวจสอบคิวและตอบกลับ

การส่งคำขอยังไม่ใช่การยืนยันนัด กรุณารอแอดมินยืนยันก่อนนะครับ

## คำตอบ 1 — “ขอนัดวันพรุ่งนี้ได้ไหม”

แจ้งช่วงเวลาที่สะดวกได้เลยครับ แอดมินจะตรวจสอบคิวแล้วตอบกลับ การส่งคำขอยังไม่ใช่การยืนยันนัดนะครับ

## คำตอบ 2 — “มีค่าปรึกษาเท่าไร”

ขอให้แอดมินตรวจสอบค่าปรึกษาและเงื่อนไขก่อนแจ้งรายละเอียดนะครับ ตอนนี้ยังไม่มีข้อมูลที่ได้รับการยืนยันครับ

## คำตอบ 3 — “ส่งข้อความแล้ว ถือว่าจองแล้วใช่ไหม”

ต้องรอแอดมินยืนยันก่อนนะครับ การส่งวันและช่วงเวลาที่สะดวกเป็นขั้นตอนส่งคำขอนัดครับ

## ตารางตรวจย้อนกลับ

| ข้อความหรือการตัดสินใจ | ต้นทาง | ผลตรวจ |
|---|---|---|
| แจ้งวันและช่วงเวลาทาง Inbox | S1 | มีต้นทาง |
| แอดมินตรวจสอบคิวและตอบกลับ | S1, S3 | มีต้นทาง |
| ต้องรอยืนยันนัด | S1, S2, S3 | มีต้นทาง |
| ไม่รับรองว่าพรุ่งนี้มีคิว | S1 ไม่มีข้อมูลคิวว่าง | ไม่แต่งข้อมูล |
| ยังไม่แจ้งราคา | S1, S3 ข้อ 2 | ส่งตรวจข้อมูลที่ขาด |
| ประโยคสั้นและชวนทำหนึ่งขั้นตอน | ซอสที่เสนอจาก S2 | ต้องให้เจ้าของงานรับรองน้ำเสียง |

ไม่จำเป็นต้องเหมือนตัวอย่างทุกคำ เกณฑ์ผ่านคือข้อเท็จจริงถูก ขั้นตอนชัด และรู้ว่าจุดไหนยังต้องให้คนตรวจ
