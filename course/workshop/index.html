BEFORE WE START

เตรียมตัวแค่นี้

ต้องเตรียมอะไรมาบ้าง?

คอมพิวเตอร์ บัญชี ChatGPT หรือ Claude ที่เข้าใช้งานได้ และงานประจำหนึ่งเรื่อง พร้อมข้อมูลหรือไฟล์ที่อนุญาตให้ใช้ ภาพประกอบใช้ภาพของตนเองหรือภาพที่มีสิทธิ์ใช้

ใช้บัญชีฟรีได้ไหม?

ได้ มีทางทำผ่านแชตของ ChatGPT และ Claude ตามฟีเจอร์ที่บัญชีเปิดให้ใช้ หากสร้างไฟล์แนบไม่ได้ ใช้ข้อความหรือตารางจากแชตไปจัดต่อใน Word/Excel ส่วนผู้ที่มี Work หรือ Cowork ใช้เส้นทางทำงานกับไฟล์ได้ตามบัญชีของตนเอง

ถ้ายังไม่มีไฟล์ส่งออกจากระบบ?

ใช้หัวตารางจริงหรือคำอธิบายงานที่รู้ เตรียมคำสั่งและวิธีอ่านไฟล์ไว้ก่อน แล้วทดลองกับไฟล์จริงภายหลัง ในวันเรียนจะระบุชัดว่ายังไม่ได้วิเคราะห์ข้อมูล และไม่สร้างข้อมูลลูกค้าสมมติแทน

ต้องส่งข้อมูลลูกค้าให้ผู้สอนไหม?

ผู้เรียนเปิดไฟล์ของตนเอง ผู้สอนไม่รวบรวมหรือเตรียมข้อมูลลูกค้าแทน ใช้เฉพาะฟิลด์ที่ได้รับอนุญาตและตัดตัวระบุที่ไม่จำเป็น การทำงานกับ AI อาจประมวลผลผ่านผู้ให้บริการตามเครื่องมือที่เลือก

คอร์สนี้รวมการสร้างระบบหรือเชื่อม ERP ไหม?

คอร์ส 3 ชั่วโมงเน้น Source งานสำนักงาน คอนเทนต์ และไฟล์ข้อมูล การเขียนโค้ด สร้างเว็บ หรือเชื่อมระบบธุรกิจเป็นงานคนละขอบเขต หากทีมพร้อมสร้างส่วนกลาง ดูรายละเอียด myClover Advance ได้
