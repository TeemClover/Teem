ONE FULL DAY · FOUR WORKING BLOCKS

เริ่มจากเตรียมเครื่อง
จบที่ทีมลองทำต่อได้

  1. ช่วงที่ 1

    ติดตั้งและเตรียมโปรเจกต์

    เตรียม GitHub, Claude Code และ Codex เปิดโฟลเดอร์งาน ตั้งบัญชีและสิทธิ์ให้เหมาะกับทีม

    เครื่องมือพร้อมกับโจทย์หนึ่งเรื่อง
  2. ช่วงที่ 2

    จัด Source และประวัติ

    วางไฟล์ กำหนดผู้ดูแล ฝึกแก้ ดูความต่าง รับรุ่นใหม่ และย้อนการเปลี่ยนแปลง

    มีต้นทางและวิธีดูแลร่วมกัน
  3. ช่วงที่ 3

    สร้างต้นแบบที่เลือก

    ใช้ Source และ PRD ให้ AI ช่วยสร้างโค้ด เปิดทดลอง แล้วปรับตามเกณฑ์ของงาน

    มีต้นแบบขนาดเล็กที่เปิดใช้ได้
  4. ช่วงที่ 4

    ทดลองและส่งต่อ

    รับเวอร์ชันเดียวกันบนสองเครื่อง ให้เครื่องมืออ่านใหม่ และให้เพื่อนทำตามคู่มือ

    มีหลักฐานว่าคนอื่นทำต่อได้

ก่อนวันเรียนจะตกลงโจทย์ ข้อมูล บัญชี และวิธีใช้เครื่องมือให้ตรงกับสภาพแวดล้อมจริงของทีม
