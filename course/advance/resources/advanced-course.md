# myClover Advance — สร้างระบบที่ทีมใช้ต่อได้

คอร์สเพิ่มเติมแบบเต็มวันสำหรับเจ้าของธุรกิจและทีมที่ใช้ AI กับงานจริงแล้ว เป้าหมายคือ **Source กลางหนึ่งชุดบน GitHub และต้นแบบขนาดเล็กหนึ่งชิ้นที่เลือกสร้างร่วมกัน** พร้อมวิธีอัปเดตและส่งต่อให้ทีม

## ปัญหาที่จะช่วยแก้

| สิ่งที่ทีมเจอ | สิ่งที่ได้ลงมือสร้าง |
| --- | --- |
| ข้อมูลกระจายในแชตและหลายโฟลเดอร์ | ที่เก็บ Source กลาง พร้อมที่มาและผู้ดูแล |
| คนละเครื่องใช้ข้อมูลคนละรุ่น | วิธีรับเวอร์ชันที่ทีมตกลงและให้เครื่องมืออ่านใหม่ |
| ต้องถามคนเดิมทุกครั้ง | ต้นแบบและคู่มือที่เพื่อนร่วมงานเปิดทำตามได้ |
| เริ่มอธิบายงานและคำสั่งใหม่ทุกรอบ | ขอบเขตงาน โค้ด และคำสั่งทำซ้ำที่อ้างอิง Source เดียวกัน |

## เลือกต้นแบบหลักหนึ่งชิ้น

- **หน้าค้นความรู้ของทีม:** ค้นสินค้า บริการ หรือขั้นตอนทำงาน พร้อมดูข้อมูลต้นทางและรุ่นที่ใช้
- **ตัวช่วยเตรียมบรีฟงาน:** เลือกประเภทงาน แล้วประกอบข้อเท็จจริงและรูปแบบผลลัพธ์เป็นบรีฟสำหรับทำงานกับ AI
- **ตัวช่วยทำรายงานซ้ำ:** ใช้ไฟล์ส่งออกที่เตรียมพร้อม สร้างขั้นตอนจัดข้อมูลและสรุปตามกติกาของทีม

เลือกหนึ่งโจทย์ขนาดเล็กก่อนเรียน ทางรายงานต้องมีไฟล์ตัวอย่างและความหมายของข้อมูลพร้อม ตัวอย่างบนหน้าแนะนำคอร์สใช้ข้อมูลสมมติเพื่ออธิบายแนวคิด ปุ่มจำลองการเปลี่ยนเวอร์ชันในหน้านั้น ไม่มีการเชื่อม GitHub หรือเรียก AI

## ลงมือ 4 ช่วงในหนึ่งวัน

| ช่วง | ทำอะไร | ผลลัพธ์ |
| --- | --- | --- |
| **1. ติดตั้งและเตรียมโปรเจกต์** | เตรียม GitHub, Claude Code และ Codex เปิดโฟลเดอร์งาน ตั้งบัญชีและสิทธิ์ให้เหมาะกับทีม | เครื่องมือพร้อม ขอบเขตหนึ่งเรื่อง และบทบาทผู้ดูแล/ผู้ใช้ |
| **2. จัด Source และประวัติ** | วางไฟล์ใน repository ระบุที่มาและเจ้าของ ฝึกแก้ ดูความต่าง รับรุ่นใหม่ และย้อนการเปลี่ยนแปลง | Source กลางที่ตามประวัติได้ พร้อมขั้นตอนดูแล |
| **3. สร้างต้นแบบที่เลือก** | ใช้ Source และ PRD ให้ AI ช่วยอ่านและแก้โค้ด เปิดทดลอง แล้วปรับตามเกณฑ์ของงาน | ต้นแบบหนึ่งชิ้น ไฟล์ต้นฉบับ และคำสั่งทำซ้ำ |
| **4. ทดลองและส่งต่อ** | รับรุ่นเดียวกันบนสองเครื่อง ให้เครื่องมืออ่านใหม่ และให้เพื่อนทำตามคู่มือ | หลักฐานการใช้ข้อมูลตรงกันและคู่มือส่งต่อสั้น ๆ |

GitHub เก็บไฟล์และประวัติการเปลี่ยนแปลง ทีมต้องรับเวอร์ชันใหม่และให้เครื่องมืออ่านไฟล์นั้นอย่างชัดเจน ไฟล์ที่ดาวน์โหลดหรือแนบในแชตเก่าไม่ได้เปลี่ยนตามเอง

## เห็นผลจากสิ่งที่ทีมทำได้

1. เจ้าของอนุมัติการแก้ข้อมูลหนึ่งจุด ทั้งสองเครื่องรับรุ่นใหม่และให้เครื่องมืออ่าน ผลงานอ้างข้อเท็จจริงตรง Source แม้ถ้อยคำต่างกัน
2. ชี้ได้ว่าแก้อะไร ใช้รุ่นใด และทดลองย้อนการเปลี่ยนแปลงโดยเก็บประวัติไว้
3. เพื่อนร่วมงานใช้คู่มือเปิดต้นแบบและทำงานหนึ่งรอบ พร้อมบอก Source ที่ใช้

สิ่งที่จะเก็บกลับคือ repository ของทีมที่มีเจ้าของและสิทธิ์เข้าถึง, Source ชุดแรก, ต้นแบบที่เลือกหนึ่งชิ้นพร้อม PRD และโค้ด/ไฟล์ต้นฉบับ, คำสั่งทำซ้ำ และคู่มือรับข้อมูลใหม่/เสนอแก้/ส่งต่องาน พร้อมผลทดลองสองเครื่อง

## เมื่อทีมพร้อมต่อยอด

คุยกับผู้สอนหลังคลาสจากงานหนึ่งเรื่อง ข้อมูลที่มี และคนที่จะดูแลต่อ ก่อนวันเรียนจะตกลงโจทย์ บัญชี วิธีใช้เครื่องมือ และข้อมูลที่อนุญาตให้ใช้ให้ตรงกับสภาพแวดล้อมจริงของทีม

Advance เป็นคอร์สเพิ่มเติมแบบเต็มวัน มีค่าเรียนแยกที่ตกลงก่อนเริ่ม บริการที่ตกลงไว้ในคอร์สเดิมยังเป็นไปตามเดิม งานเชื่อมระบบธุรกิจหรือเปิดใช้งานอัตโนมัติจริงกำหนดขอบเขตเพิ่มเติมภายหลัง
