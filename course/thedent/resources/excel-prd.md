# Mini PRD — จากไฟล์ส่งออกสู่ Excel พร้อมใช้

**ผู้ใช้:** ทีมแอดมิน บัญชี และผู้ดูแลงาน The Dent
**เป้าหมาย:** ใช้ไฟล์ Excel / CSV ที่ส่งออกจากระบบเดิม ทำตารางสะอาดและหน้าสรุปสำหรับงานรอบนี้

## ข้อมูลเข้า

ไฟล์ Excel / CSV ที่แนบ ให้ AI อ่านชื่อชีต หัวคอลัมน์ และช่วงข้อมูลเอง
หากใช้ไฟล์ฝึก `thedent-branches.xlsx` หรือ `.csv` ให้ทำตารางติดต่อสาขาจากข้อมูลเว็บไซต์

## สิ่งที่จะทำ

1. อ่านข้อมูลและเลือกรูปแบบการจัดที่เหมาะกับคอลัมน์จริง
2. สร้างสำเนาที่จัดชื่อคอลัมน์ ช่องว่าง และรูปแบบข้อมูลให้สม่ำเสมอ
3. สรุปข้อมูลที่มี พร้อมบันทึกคำสั่งไว้ใช้กับไฟล์รอบหน้า

รหัสและเบอร์โทรเก็บเป็นข้อความเพื่อรักษาเลข 0 นำหน้า วันเดือนปีที่ยังตีความไม่ได้ให้เก็บค่าเดิม รายการซ้ำให้แสดงแยกโดยยังเก็บต้นฉบับไว้

## ไฟล์ส่งมอบ

**`thedent-report.xlsx`** มี 3 ชีต

| ชีต | ใช้ทำอะไร |
|---|---|
| cleaned | ตารางข้อมูลที่จัดแล้ว มีหัวคอลัมน์และตัวกรอง |
| summary | สรุปจากคอลัมน์ที่มีจริง พร้อมกราฟเมื่อเหมาะกับข้อมูล |
| issues | เฉพาะรายการที่อ่านไม่ได้หรืออาจซ้ำ ถ้าไม่มีให้ระบุว่าไม่พบ |

**`repeat-workflow.md`** คำสั่งสำหรับแนบไฟล์รอบหน้าแล้วทำซ้ำ

ถ้าใช้ตารางสาขาฝึก หน้าสรุปคือรายการชื่อสาขา เบอร์โทร และช่องทางติดต่อ ไม่สร้างยอดขายหรือกราฟการเงินเพิ่ม

## ขอบเขตครั้งนี้

ทำงานจากไฟล์ส่งออกและบันทึกผลเป็นไฟล์ใหม่ ไม่เชื่อมต่อหรือเขียนกลับระบบเดิม

## เสร็จเมื่อ

เปิด Excel แล้วใช้ตัวกรองและอ่านหน้าสรุปได้ พร้อมมีคำสั่งที่นำไปใช้กับไฟล์รอบถัดไป
