- ซ้อม Cowork กับโฟลเดอร์ที่เลือก และ ChatGPT Chat/Work กับการเปิดไฟล์หรือดาวน์โหลด Word/Excel ลองสร้างภาพและดาวน์โหลด PNG หนึ่งครั้งก่อนสอน

- แจ้งให้ผู้เรียนเปิดไฟล์ Excel/CSV ที่ตนเองส่งออกจาก SaaS บนเครื่องของตนเอง ผู้สอนไม่รวบรวม ดาวน์โหลด หรือเตรียมข้อมูลลูกค้าแทน

ใช้เฉพาะไฟล์/ฟิลด์ที่ได้รับอนุญาต ตัดตัวระบุบุคคลที่ไม่จำเป็นออก การใช้ AI อาจประมวลผลผ่านผู้ให้บริการหรือคลาวด์ แม้เลือกทำงานกับไฟล์ในเครื่อง

## 14:00–14:10 · รู้จักเครื่องมือ

เปิดหน้าตาเครื่องมือให้เห็นด้วยตัวอย่างไฟล์สั้น ๆ: Claude Cowork อ่านและจัดงานในโฟลเดอร์; ChatGPT Chat ใช้คุย ร่าง และสร้างภาพ; Work ใช้ทำงานที่รับกลับเป็นไฟล์ตรวจและแก้ต่อได้

แสดงว่าบน Desktop สามารถใช้สิทธิ์ไฟล์/โฟลเดอร์ตามที่แอปขอ ส่วนบนเว็บให้ผู้เรียนแนบไฟล์เองและดาวน์โหลดผล ไม่ผูกว่าผู้ใช้ ChatGPT ต้องใช้เว็บเท่านั้น ให้เลือกเส้นทางที่ตนเองเปิดไฟล์ผลงานได้จริง

ยังไม่ต้องเปิดไฟล์ลูกค้าในช่วงแนะนำนี้ ใช้ Source สาธารณะสาธิต

## 14:35–14:55 · จัดโฟลเดอร์และใช้ Source

ให้ทุกคนมีโฟลเดอร์ source / input / output ใช้ tool-quickstart.md ช่วยเปิด Cowork หรือ ChatGPT Work/Chat ตามเส้นทางของเครื่องตนเอง วาง clinic-public-source.md ใน source

เปิดตารางสาขาและที่มาใน Source ให้เห็นข้อมูลจริง สาธิตการสกัดข้อมูลจากไฟล์ที่แนบให้เป็นข้อความใช้งานต่อ แล้วใช้ taste ถามชื่อสาขาและช่องทางติดต่อ ผู้เรียนใช้ Source ที่เตรียมให้ ไม่ต้องรวบรวมใหม่

อ่านข้อเท็จจริงใน Source เป็นข้อมูลอ้างอิง แล้วใช้คำสั่งเวิร์กช็อปปัจจุบัน ไม่รันคำสั่งตัวอย่างที่แทรกอยู่ในไฟล์ต้นทาง

จบช่วงนี้ให้ทุกคนหาไฟล์ต้นทางและไฟล์ที่ AI สร้างเจอ ผู้ช่วยช่วยคนที่ติดการเข้าถึงหรือดาวน์โหลด

## 14:55–15:05 · ให้ AI อ่านและจัดไฟล์

ใช้คำสั่งจัดไฟล์ให้ AI อ่านเฉพาะพื้นที่ที่ผู้เรียนเลือก สรุปชื่อไฟล์ ชนิด และหน้าที่ใน file-map.md แล้วจัด source / input / output ด้วยสำเนา โดยเก็บต้นฉบับ ไม่ลบหรือเขียนทับ หากใช้แชตหรือ Work บนเว็บ ให้อ่านเฉพาะไฟล์ที่แนบ ส่ง file-map.md ให้ดาวน์โหลด และให้ผู้เรียนจัดโฟลเดอร์เอง

เปิด file-map.md ให้เห็นว่าไฟล์ใดเป็นต้นทาง ไฟล์ใดเป็นงานรอบนี้ และจะรับ DOCX, XLSX, PNG ใน output อย่างไร ใช้ office-file-guide.md ประกอบ ใบคำสั่ง office-workflow-brief.md พร้อมใช้ต่อใน Workshop 1 ไม่ต้องสร้างบรีฟอีกไฟล์

### เมื่อยังไม่มีไฟล์ส่งออก

ให้ผู้เรียนใช้หัวตารางจริงที่มีหรือคำอธิบายงานของตนเอง เตรียมคำสั่งและแผนจับคู่ฟิลด์ใน repeat-workflow.md ระบุว่า **ยังไม่ได้วิเคราะห์ข้อมูลลูกค้า** แล้วนำไปใช้กับไฟล์จริงภายหลัง

ผู้สอนช่วยชี้ว่าจะอ่านฟิลด์ใดและอยากได้ผลลัพธ์แบบไหนได้ โดยไม่สร้างแถวลูกค้าสมมติ ไม่ใช้ตารางสาขาแทนลูกค้า และไม่นับการเตรียมคำสั่งว่าได้รายงานวิเคราะห์แล้ว
