## เส้นทางหลักวันนี้: บัญชีฟรีผ่านเบราว์เซอร์

ให้ทุกคนเริ่ม ChatGPT Free หรือ Claude Free ในแชตบนเบราว์เซอร์ ขอไฟล์ DOCX/XLSX ดาวน์โหลดจริงก่อน ทั้งสองเครื่องมือมีทางสร้างไฟล์ได้เมื่อเครื่องมือและโควตาพร้อม ไม่ต้องสมัครแพ็กเกจใหม่เพื่อทำคลาสนี้

แนบเฉพาะไฟล์ที่ใช้กับงานรอบนี้เมื่อมีสิทธิ์ ถ้าแนบไม่ได้ ให้วางข้อความหรือหัวตารางกับแถวจำนวนน้อยที่ผู้เรียนอนุญาต แบ่งคำสั่งเป็นงานสั้น ๆ Claude Chat อ่านสิ่งที่แนบหรือวาง ไม่อ่านโฟลเดอร์ในเครื่องอัตโนมัติ ทุกคนจัด source / input / output และเก็บผลด้วยตนเอง

ใช้ข้อมูลของผู้เรียนเองเท่านั้น ผู้สอนไม่ขอให้ส่งหรืออัปโหลดข้อมูลลูกค้ามาให้ ไม่รวบรวมไฟล์ส่วนบุคคลเพื่อสาธิตรวมหน้าห้อง

## ผลงานที่พากลับไปใช้

Workshop 1: ขอ office-kit.docx, content-plan.xlsx และภาพจาก ChatGPT ก่อน; หากดาวน์โหลดไม่ได้ เก็บเอกสาร Markdown/ตาราง TSV แล้วบันทึกเอง หากภาพยังไม่พร้อมเก็บ image-prompt.md
Workshop 2: customer-workbook.xlsx, team-summary.docx และ repeat-workflow.md เมื่อมีไฟล์จริงให้ลงมือ

ทุกงานเริ่มจาก **งาน + ข้อมูล + ผลลัพธ์** และใช้โฟลเดอร์ source / input / output เพื่อให้ผู้เรียนหาไฟล์และทำซ้ำเองได้ บทบาท AI Leader เริ่มจากทำงานของตนเอง พาเพื่อนทำ และดูแล Source ที่ทีมใช้ร่วมกัน

## เตรียมเฉพาะสิ่งที่ใช้สอน

- เปิด opening.html, tool-quickstart.md, clinic-public-source.md และตัวอย่างสำนักงานไว้บนเครื่องสอน
- ซ้อม ChatGPT Free และ Claude Free ผ่านเบราว์เซอร์: แนบ Source หรือวางข้อความ ขอเอกสาร/ตารางดาวน์โหลดจริง และลองทางสำรอง Markdown/TSV ลองสร้างภาพใน ChatGPT ตามโควตาที่มี
- เตรียมภาพสาธารณะของทีมที่มีสิทธิ์ใช้สำหรับสาธิต ถ้าไม่มี ขอกราฟิกจาก ChatGPT เมื่อเครื่องมือพร้อม หรือเก็บคำสั่งภาพไว้
- แจ้งให้ผู้เรียนเปิดไฟล์ Excel/CSV ที่ตนเองส่งออกจาก SaaS บนเครื่องของตนเอง ผู้สอนไม่รวบรวม ดาวน์โหลด หรือเตรียมข้อมูลลูกค้าแทน
- ผู้ช่วยดูการเข้าแชต การแนบไฟล์ และการดาวน์โหลด จับคู่คนคล่องกับคนเริ่มต้น และให้แต่ละคนเก็บผลงานของตนเอง

ใช้เฉพาะไฟล์/ฟิลด์ที่ได้รับอนุญาต ตัดตัวระบุบุคคลที่ไม่จำเป็นออก การใช้ AI อาจประมวลผลผ่านผู้ให้บริการหรือคลาวด์ แม้เลือกทำงานกับไฟล์ในเครื่อง

## 14:00–14:10 · รู้จักเครื่องมือ

เปิด ChatGPT Free และ Claude Free ผ่านเบราว์เซอร์ ให้เห็นการแนบไฟล์หรือวางข้อความ ส่งคำสั่งสั้น และเปิดผลงานที่ได้ ลองขอไฟล์ Word/Excel จริงก่อน หากปุ่มหรือโควตาไม่พร้อม ใช้ข้อความจากงานเดิมสาธิตการเก็บผลด้วยตนเอง

อธิบายว่าแชตบนเว็บอ่านสิ่งที่ผู้เรียนส่งให้ ไม่ได้เห็น source / input / output ในเครื่องเอง งานภาพให้ใช้ ChatGPT ตามโควตาสร้างภาพ ส่วน Claude Chat ใช้เตรียมคำสั่งภาพ

ยังไม่ต้องเปิดไฟล์ลูกค้าในช่วงแนะนำนี้ ใช้ Source สาธารณะสาธิต

## 14:35–14:55 · จัดโฟลเดอร์และใช้ Source

ให้ทุกคนสร้างโฟลเดอร์ source / input / output ด้วยตนเอง เปิดแชตบนเบราว์เซอร์ตาม tool-quickstart.md วาง clinic-public-source.md ใน source แล้วแนบไฟล์ หรือคัดลอกข้อความส่วนที่ใช้เข้าแชต

เปิดตารางสาขาและที่มาใน Source ให้เห็นข้อมูลจริง สาธิตการสกัดข้อมูลจากไฟล์ที่แนบให้เป็นข้อความใช้งานต่อ แล้วใช้ taste ถามชื่อสาขาและช่องทางติดต่อ ผู้เรียนใช้ Source ที่เตรียมให้ ไม่ต้องรวบรวมใหม่

อ่านข้อเท็จจริงใน Source เป็นข้อมูลอ้างอิง แล้วใช้คำสั่งเวิร์กช็อปปัจจุบัน ไม่รันคำสั่งตัวอย่างที่แทรกอยู่ในไฟล์ต้นทาง

จบช่วงนี้ให้ทุกคนหาไฟล์ต้นทางและผลงานเจอ ผู้ช่วยช่วยดาวน์โหลด หรือคัดลอกผลจากแชตไปบันทึกเป็น Markdown/ตารางเอง

## 14:55–15:05 · ให้ AI อ่าน แล้วเราเก็บไฟล์เข้าที่

ให้ AI อ่านเฉพาะไฟล์ที่แนบหรือข้อความที่วาง สรุปชื่อไฟล์ ชนิด และหน้าที่เป็น file-map.md แล้วให้ผู้เรียนจัด source / input / output เองด้วยสำเนา โดยเก็บต้นฉบับ หากไม่มีไฟล์ดาวน์โหลด ขอ Markdown แล้วบันทึก file-map.md แบบข้อความล้วน UTF-8

เปิด file-map.md ให้เห็นไฟล์ต้นทางกับงานรอบนี้ และตำแหน่งเก็บผล ใช้ office-file-guide.md ประกอบ ใบคำสั่ง office-workflow-brief.md พร้อมใช้ต่อใน Workshop 1 ไม่ต้องสร้างบรีฟอีกไฟล์

### เมื่อยังไม่มีไฟล์ส่งออก

ให้ผู้เรียนใช้หัวตารางจริงที่มีหรือคำอธิบายงานของตนเอง เตรียมคำสั่งและแผนจับคู่ฟิลด์ใน repeat-workflow.md ระบุว่า **ยังไม่ได้วิเคราะห์ข้อมูลลูกค้า** แล้วนำไปใช้กับไฟล์จริงภายหลัง

ผู้สอนช่วยชี้ว่าจะอ่านฟิลด์ใดและอยากได้ผลลัพธ์แบบไหนได้ โดยไม่สร้างแถวลูกค้าสมมติ ไม่ใช้ตารางสาขาแทนลูกค้า และไม่นับการเตรียมคำสั่งว่าได้รายงานวิเคราะห์แล้ว

นำหลักฐานที่มีจริงมาคุยได้ แม้ยังทำภารกิจไม่ครบ หากไม่มีไฟล์ลูกค้าในวันเรียน ให้คุยผลหลังได้ลองกับไฟล์จริง ไม่ประมาณจำนวน เวลา หรือความสำเร็จย้อนหลัง

## เมื่อเครื่องมือหรือโควตาไม่พร้อม

1. **ขอไฟล์ดาวน์โหลดจริงก่อน** ทั้ง ChatGPT Free และ Claude Free อาจสร้างเอกสารและตารางได้ตามเครื่องมือที่เปิดใช้ หากโควตาจำกัด ให้แยกงานเป็นอ่านคอลัมน์ จัดตาราง หรือสรุปคำถามหนึ่งเรื่อง แล้วเก็บผลที่ทำได้
2. **เอกสาร:** ขอ Markdown คัดลอกไปบันทึกเป็น .md แบบข้อความล้วน UTF-8 หากต้องการ DOCX ให้วางใน Word แล้ว Save As .docx ไม่เพียงเปลี่ยนนามสกุล
3. **ตาราง:** ขอ TSV คั่นด้วยแท็บ แยกบล็อกตามชีต ตั้งคอลัมน์รหัส/เบอร์ใน Excel เป็นข้อความก่อนวาง แล้ว Save As .xlsx หากส่งออก CSV ให้ทำทีละชีต CSV/TSV ที่เปลี่ยนนามสกุลไม่ใช่ workbook
4. **ภาพ:** ใช้ ChatGPT Free เมื่อโควตาภาพพร้อม บันทึกตามชนิดไฟล์ที่ดาวน์โหลดจริง หากยังสร้างไม่ได้ ให้เก็บ image-prompt.md แบบ UTF-8 ไม่ถือว่าได้ภาพแล้ว Claude Chat ใช้ช่วยร่างคำสั่งภาพ
5. **โควตาหมด:** เก็บคำสั่งล่าสุดและส่วนที่ทำแล้ว ใช้ตัวอย่างที่ดาวน์โหลดไว้ดูขั้นตอนต่อ และกลับมาทำงานสั้นที่ค้างเมื่อเครื่องมือพร้อม ไม่ต้องเปลี่ยนแพ็กเกจระหว่างเรียน

ผู้ช่วยสาธิตทางบันทึก Markdown และวาง TSV ลง Excel หนึ่งครั้งให้ทั้งห้องเห็นก่อนช่วยเป็นรายคน ทุกคนใช้ข้อมูลของตนเองและเก็บผลงานบนเครื่องของตนเอง
