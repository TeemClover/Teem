| --- | --- |
| file-map.md | ชื่อ ชนิด และหน้าที่ของไฟล์ที่เลือกใช้ |
| office-kit.docx | บันทึกถึงทีม คำตอบแอดมิน และแคปชัน แก้ต่อใน Word ได้ |
| content-plan.xlsx | แผนคอนเทนต์ร่างสามแถว |

| repeat-workflow.md | คำสั่งสั้นสำหรับงานรอบหน้า |

## โฟลเดอร์เดียว หาไฟล์เจอ

~~~text
source/   ข้อมูลอ้างอิง
input/    ไฟล์ที่นำมาทำงานรอบนี้
output/   ผลงานและคำสั่งทำซ้ำ
~~~

ช่วงจัดไฟล์ ให้ AI สำรวจเฉพาะโฟลเดอร์ที่เลือก ทำ file-map.md จากไฟล์จริง แล้วจัดหมวดด้วยสำเนา เก็บต้นฉบับ ไม่ลบหรือเขียนทับ ถ้าใช้เว็บ ให้อ่านเฉพาะไฟล์แนบ ดาวน์โหลด file-map.md แล้วจัดโฟลเดอร์เอง

Cowork และ ChatGPT Work บน Desktop ใช้สิทธิ์เข้าถึงไฟล์/โฟลเดอร์ตามที่แอปขอ ส่วนแชตหรือ Work บนเว็บให้เปิดไฟล์จากเครื่อง แนบ และดาวน์โหลดผลเข้า output

ถ้าได้เพียงข้อความ บอก “สร้างเป็นไฟล์ตามชื่อที่ขอให้ดาวน์โหลดด้วย” หากโหมดนั้นยังสร้างไฟล์ชนิดที่ต้องการไม่ได้ ให้ใช้เส้นทางที่ผู้สอนสาธิตและบอกว่าส่วนใดยังไม่ได้ไฟล์

สำหรับ Excel ดาวน์โหลด workbook .xlsx โดยตรง การดาวน์โหลดตารางเป็น CSV ไม่เก็บหลายชีตไว้ด้วยกัน

เปิดงานหนึ่งครั้ง แก้หนึ่งจุด แล้วเก็บฉบับที่เลือกใช้ใน output การเปิดไฟล์ที่ดาวน์โหลดแล้วทำได้ในเครื่อง ส่วนการใช้ AI อาจประมวลผลผ่านผู้ให้บริการหรือคลาวด์
