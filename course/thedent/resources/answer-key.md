## Workshop 2

ผลลัพธ์ขึ้นอยู่กับไฟล์จริงของแต่ละคน จึงไม่มีเฉลยจำนวนแถวหรือยอดเดียวสำหรับทั้งห้อง

| ผลงาน | หลักฐานที่ควรเห็น |
| --- | --- |
| cleaned | รักษารายการเดิม รหัส/เบอร์เป็นข้อความ ไม่รวมคนเดิมหลายรายการโดยอัตโนมัติ |
| summary | ตอบคำถามจากคอลัมน์จริง บอกช่วง หน่วย และตัวหารของอัตราที่ใช้ |
| issues | ระบุค่าว่าง วันที่กำกวม รายการอาจซ้ำพร้อมเหตุผล ถ้าไม่มีให้บอกว่าไม่พบ |
| field-map | ใช้ชื่อคอลัมน์จริง มีความหมาย ชนิดข้อมูล และกติกาจับคู่/แปลง |
| team-summary.docx | สิ่งที่พบ สิ่งที่ทีมทำต่อได้ และข้อจำกัดสอดคล้องกับ workbook |
| repeat-workflow.md | อ่านโครงสร้างไฟล์รอบใหม่ก่อนใช้กติกาที่ได้ลอง |

ทั้งสี่ชีตอยู่ใน customer-workbook.xlsx การนับไม่มาตามนัดต้องมีสถานะและความหมายรองรับ การนับจำนวนครั้งต้องมีข้อมูลเหตุการณ์ที่ใช้ได้ ไม่อนุมานข้อมูลทางคลินิกจากคำที่กำกวม

ข้อความตอบลูกค้า หากมี เป็นร่างจากบริบททั่วไปที่อนุญาตให้ใช้ ยังไม่ได้ส่งจริง

**กรณีไม่มี export:** ผลที่นับว่าเสร็จได้คือเตรียม repeat-workflow.md และแผนจับคู่ฟิลด์จากงานหรือหัวตารางที่มีจริง ระบุว่ายังไม่ได้วิเคราะห์ ไม่สร้างลูกค้าสมมติหรืออ้างว่ามี workbook/ผลสรุปจากข้อมูลแล้ว

## ภารกิจหลังเรียน

ใช้สาม IDs เดิม: repeat-work / teach-peer / source-owner ดูไฟล์ของผู้เรียนและของเพื่อนจริง ไม่ถือว่าการมีไฟล์หรือการติ๊กครบหมายถึงผ่านการรับรอง ให้นำสิ่งที่ทำได้กับจุดติดมาคุยติดตาม
