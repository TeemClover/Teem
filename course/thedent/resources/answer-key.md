## เฉลยไฟล์สำรองจากเว็บไซต์

thedent-branches.xlsx และ thedent-branches.csv มีข้อมูลเดียวกัน เป็นตารางข้อมูลสาขาจากเว็บไซต์ ไม่ใช่ SaaS export ของคลินิก

- XLSX มีชีต “ข้อมูลสาขา” แถวหัวตาราง 7 และข้อมูลแถว 8–10 ชื่อเรื่องกับหมายเหตุไม่ใช่รายการ
- CSV มีหัวตารางหนึ่งแถวและข้อมูลสามแถว เข้ารหัส UTF-8 พร้อม BOM
- หัวคอลัมน์หกช่อง: ชื่อสาขา, จุดสังเกต / พื้นที่, โทรศัพท์, LINE กลาง, URL ต้นทาง, วันที่ตรวจข้อมูล
- เบอร์ทั้งสามเป็นข้อความ รักษาเลขศูนย์นำหน้าและคู่สาขาตามตารางด้านบน
- LINE ทุกแถวคือ https://line.me/ti/p/@thedent และ URL ต้นทางทุกแถวคือ https://thedent.co.th/quotation/
- วันที่ตรวจทุกแถวคือ 2026-09-11; XLSX เก็บเป็นวันที่จริงและแสดง yyyy-mm-dd
- มีสามรายการที่พบใน Source ไม่ใช่ข้อยืนยันจำนวนสาขาที่เปิดล่าสุด

ผลสรุปที่เหมาะสมคือรายชื่อ/ข้อมูลติดต่อ กรองรัชโยธินต้องได้เบอร์ 02-512-4595 กรองรังสิตต้องได้ 02-147-2244 กรองราชพฤกษ์ต้องได้ 02-591-6868 ไม่รวมเบอร์เป็นยอดและไม่สร้างกราฟธุรกิจจากตารางนี้

ต้นทางจัดรูปแบบอยู่แล้วจึงไม่ต้องแต่งข้อมูลผิดขึ้นมาเพื่อทำความสะอาด อาจฝึกเพิ่มคอลัมน์เบอร์แบบไม่มีขีดเป็นข้อความ เช่น 025124595 โดยเก็บค่าเดิมไว้ และอธิบายว่าเป็นการแปลงรูปแบบ

ใช้ XLSX/CSV สลับกันหรือใช้ไฟล์เดิมอีกรอบเพื่อทดสอบคำสั่งทำซ้ำได้ ให้ระบุว่าเป็นการทดลองกับข้อมูลเดิม ไม่อ้างว่าเป็นข้อมูลรอบใหม่จากธุรกิจ
