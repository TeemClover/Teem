# แนวตรวจคำตอบ · Source → งานสื่อสาร → Branch Desk

ใช้หลังผู้เรียนลองทำและจับคู่ตรวจแล้ว แนวตรวจนี้อ้างอิง clinic-public-source.md เวอร์ชัน 0.1.0 และ website-source-notes.md ซึ่งบันทึกการเปิดตรวจวันที่ 2026-09-11 ไม่ใช่คำอนุมัติของคลินิกหรือหลักฐานว่าข้อมูลยังไม่เปลี่ยนหลังวันตรวจ

ไม่มีคำตอบร่างข้อความเพียงแบบเดียว ให้พิจารณาข้อเท็จจริง ขอบเขต และผลการทดลองที่ผู้เรียนแสดงได้

## 1. ซอสที่ผ่านการฝึกควรมีอะไร

- ระบุชื่อไฟล์ เวอร์ชัน วันที่ตรวจ และขอบเขตของ Source
- ทุกข้อเท็จจริงที่นำไปใช้มี URL หรือ ID ต้นทางที่ตามกลับได้
- แยก SOURCE / COMPANY CLAIM / DERIVED / OPEN ไม่ปะปนข้อเสนอของ AI กับข้อมูลคลินิก
- มีคู่ชื่อสาขา–เบอร์ที่ไม่สลับกันและมีช่องทางติดต่อกลางตามต้นทาง
- เก็บความขัดกันเรื่องข้อความ 2/3 สาขาไว้เป็น OPEN
- บันทึกเป็น thedent-source-v0.1.md เปิดอ่านได้จริง แล้วแนบในแชตใหม่เพื่อทดสอบ
- แชตใหม่ตอบเรื่องติดต่อสาขาได้จากไฟล์ และบอกได้ว่าเรื่องคิว เวลาเปิด–ปิด ราคา และขั้นตอนยืนยันนัดยังไม่มีข้อมูลพอ

### จุดสำคัญของข้อขัดกัน

คำตอบที่ยอมรับได้: “หน้าติดต่อมีข้อความพูดถึง 2 สาขา แต่มีรายละเอียดรัชโยธิน รังสิต และราชพฤกษ์ 3 รายการ จึงเก็บสามรายการที่มีหลักฐานไว้ใช้ในต้นแบบ และรอผู้รับผิดชอบยืนยันจำนวนสาขาที่เปิดล่าสุด”

คำตอบที่ต้องแก้: ตัดราชพฤกษ์ออกเพราะย่อหน้าแรกบอกสอง หรือเขียนว่ามีสามสาขาที่เปิดทั้งหมดแน่นอน หรือสรุปว่าโดเมนหนึ่งเก่า/เลิกใช้โดยไม่มีหลักฐาน

ชื่อไฟล์ภาพมีวันที่ไม่ได้แปลว่าข้อมูลบนเพจอัปเดตวันนั้น และวันตรวจ URL ไม่ใช่วันเริ่มมีผลของข้อมูล

## 3. Workshop 1 · content-pack.md

ต้องมีโพสต์แนะนำช่องทางติดต่อ 1 ชิ้น และคำตอบแอดมิน 3 สถานการณ์ พร้อมตารางตรวจ

| สถานการณ์ | ข้อมูลที่ควรตอบได้ | สิ่งที่ยังตอบเป็นข้อยืนยันไม่ได้ |
| --- | --- | --- |
| เดินทางไปรัชโยธิน | BTS รัชโยธิน ทางออก 4 และเบอร์ 02-512-4595 โดยอ้าง Source | เส้นทางละเอียด เวลาเดิน หรือเวลาทำการที่ยังไม่มีหลักฐาน |
| ติดต่อรังสิต | เบอร์ 02-147-2244 และจุดสังเกตตาม Source; ใช้ LINE กลางเป็นทางเลือกได้ | อ้างว่าติดต่อแอดมินสาขาโดยตรงผ่าน LINE เฉพาะสาขา หาก Source ไม่ระบุ |
| ขอเช็กคิววันพรุ่งนี้ | ชวนระบุสาขาที่สนใจและติดต่อช่องทางที่มี เพื่อให้ทีมตรวจคิว | คิวว่าง แพทย์ออกตรวจ การจองสำเร็จ หรือกำหนดเวลาตอบกลับ |

คำตอบตัวอย่างสำหรับสถานการณ์คิว: “ขอทราบสาขาที่สนใจก่อนนะคะ สามารถติดต่อ LINE @thedent เพื่อให้ทีมตรวจสอบคิวได้ค่ะ ข้อมูลชุดนี้ยังยืนยันคิววันพรุ่งนี้ไม่ได้”

ข้อความนี้เป็นร่างเพื่อฝึก ยังไม่ใช่สคริปต์ที่คลินิกอนุมัติ ขั้นตอนรับคำขอและยืนยันนัดอยู่ใน OPEN น้ำเสียง “ค่ะ/ครับ” และรายละเอียดการรับเรื่องต้องให้เจ้าของงานเลือก

โพสต์ควรใช้ชื่อและช่องทางที่ตรวจแล้ว ไม่เติมโปรโมชั่นปัจจุบัน รีวิว ผลการรักษา หรืออ้างว่าผู้จัดคอร์สเป็นผู้อนุมัติข้อความคลินิก
