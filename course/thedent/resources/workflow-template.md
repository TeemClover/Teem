# วิธีเริ่มงานรอบหน้า

เก็บ Source ใน source ไฟล์รอบนี้ใน input และผลลัพธ์กับ repeat-workflow.md ใน output

## คำสั่งบันทึกวิธีทำ

~~~text
จากงานที่เราทำ ช่วยเก็บ repeat-workflow.md ให้เพื่อนร่วมทีมใช้กับไฟล์ครั้งหน้าได้ทันที
บอกว่าจะต้องเปิดหรือแนบไฟล์อะไร ให้ AI ทำอะไร และจะได้ไฟล์ใดกลับมา
ใช้ขั้นตอนและชื่อคอลัมน์ที่ได้ลองจริง แต่ให้ตรวจโครงสร้างไฟล์ใหม่ทุกครั้ง หากมีข้อมูลที่กำกวมหรือขาด ให้คงไว้และถามเฉพาะจุดที่เปลี่ยนผลลัพธ์
ไม่ต้องทำแบบฟอร์มให้กรอกหรือเล่าประวัติแชต เก็บเฉพาะวิธีทำ ไม่ใส่ข้อมูลลูกค้ารายคนในคำสั่งทำซ้ำ
~~~

## งานสำนักงาน

ใช้ Source และภาพรอบใหม่ ทำ office-kit.docx / content-plan.xlsx แล้วใช้ ChatGPT สร้าง image.png เลือกแก้เนื้อหาหรือรูปแบบตามงาน โดยรักษาข้อเท็จจริงต้นทาง

## ไฟล์ลูกค้า

ให้ผู้เรียนเปิดไฟล์ส่งออกรอบใหม่ของตนเอง อ่านหัวตารางและจับคู่จากความหมายก่อนใช้กติกาเดิม สร้าง customer-workbook.xlsx สี่ชีต cleaned / summary / issues / field-map, team-summary.docx และ repeat-workflow.md ฉบับรอบนี้ โดยเก็บต้นฉบับไว้

หากยังไม่มีไฟล์ ให้เตรียมวิธีทำจากงานหรือหัวตารางที่ทราบจริง และบอกว่ายังไม่ได้วิเคราะห์ เมื่อได้ไฟล์แล้วจึงค่อยลงมือ หากทดลองซ้ำกับไฟล์เดิม ให้ระบุว่าเป็นการทดลองทำซ้ำกับข้อมูลเดิม
