# วิธีทำซ้ำจากไฟล์ Excel/CSV

ใช้ลำดับนี้กับไฟล์ส่งออกรอบถัดไปได้ทันที เก็บไฟล์ต้นทาง ผลงาน และ repeat-workflow.md ไว้ด้วยกัน เพื่อให้คนถัดไปเริ่มจากงานที่มีอยู่ได้

| ขั้น | ลงมือทำ | สิ่งที่ต้องได้ |
| --- | --- | --- |
| 1. รับไฟล์ | เก็บไฟล์ .xlsx/.csv จากรอบนี้ไว้ในโฟลเดอร์ต้นทาง | ไฟล์เดิมยังเปิดได้ |
| 2. อ่านโครงสร้าง | แนบไฟล์แล้วใช้ repeat-workflow.md ให้ AI ตรวจหัวตาราง/ชนิดข้อมูลใหม่ | สรุปสิ่งที่อ่านจริงและความต่างที่พบ |
| 3. จัดระเบียบ | ให้ AI สร้าง thedent-report.xlsx สามชีต cleaned / summary / issues โดยเก็บค่าเดิม | ชื่อคอลัมน์และรูปแบบสม่ำเสมอ รายการไม่หาย |
| 4. สรุป | ทำ summary ตามข้อมูลและคำถามที่งานต้องใช้ | ตัวเลข/รายชื่อที่ตามกลับไปยังข้อมูลได้ |
| 5. เปิดใช้ | เปิดตัวกรองและหน้าสรุปในไฟล์ใหม่ | อ่านข้อมูลที่ต้องใช้ได้ |
| 6. เก็บคำสั่ง | บันทึกการแก้ที่ใช้ได้กลับเข้า repeat-workflow.md | พร้อมใช้กับไฟล์ครั้งถัดไป |

## คำสั่งสำหรับไฟล์รอบใหม่

> ใช้ repeat-workflow.md และตัวอย่างผลงานรอบก่อนที่แนบ กับไฟล์ Excel/CSV รอบใหม่นี้
> อ่านหัวตารางและข้อมูลจริงก่อน หากชื่อคอลัมน์ ลำดับ ชีต หรือชนิดข้อมูลเปลี่ยน ให้จับคู่จากความหมายและบอกความต่างที่พบ ไม่อ้างตำแหน่งเดิมโดยไม่ตรวจ
> ส่ง thedent-report.xlsx สามชีต cleaned / summary / issues พร้อม repeat-workflow.md ฉบับที่ใช้กับรอบนี้ รักษาต้นฉบับ จำนวนรายการ และค่าเดิมไว้ ไม่ลบรายการเอง ถ้ามีข้อมูลกำกวมที่กระทบผลให้ถามเฉพาะข้อที่พบจริง
> ส่งไฟล์ที่เปิดได้และสรุปสิ่งที่เปลี่ยนจากรอบก่อน ถ้าเป็นไฟล์เดิมที่ใช้ทดลองซ้ำ ให้ระบุว่าเป็นการทดสอบทำซ้ำ ไม่ใช่ข้อมูลรอบธุรกิจใหม่

## ใช้กับงานสื่อสารได้เช่นกัน

แนบ Source + บรีฟ + content-pack.md ที่ตรวจแล้ว ให้ AI ทำร่างรอบถัดไปจากข้อมูลชุดใหม่และระบุสิ่งที่เปลี่ยน รักษาคู่ชื่อ–เบอร์–URL และเรื่องที่รอยืนยัน เก็บคำสั่งที่แก้แล้วไว้ข้างผลงาน

ก่อนคุยติดตาม เลือกงานจริงหนึ่งเรื่องที่ได้ลอง ใช้หลักฐานจากไฟล์และแชตเล่าว่าทำอะไรได้เอง ใช้เวลาเท่าไร และติดตรงไหน โดยไม่ต้องสร้างเอกสารรับข้อมูลอีกชุด
