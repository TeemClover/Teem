# AI Leader Advance — ซอสกลางขององค์กรบน GitHub

คอร์สต่อยอดแบบเต็มวันสำหรับทีมที่เริ่มใช้ AI กับงานจริงแล้ว เป้าหมายคือ **Source กลางหนึ่งชุดที่ทีมดูแลต่อได้ และต้นแบบเล็กหนึ่งชิ้นที่เลือกสร้างร่วมกัน** เป็นคอร์สเพิ่มเติมที่มีค่าเรียนแยกจาก Workshop ปัจจุบัน

## ปัญหาที่จะช่วยแก้

| สิ่งที่ทีมเจอ | สิ่งที่จะเปลี่ยนหลังลงมือ |
| --- | --- |
| ข้อมูลกระจายในแชตและหลายโฟลเดอร์ | มีที่เก็บ Source กลาง พร้อมเจ้าของและที่มาของข้อมูล |
| คนละเครื่องใช้ข้อมูลคนละเวอร์ชัน | รู้ว่าใช้เวอร์ชันใด และมีวิธีรับฉบับที่ทีมเลือกก่อนเริ่มงาน |
| ต้องถามคนเดิมทุกครั้ง | เพื่อนร่วมงานเริ่มทำตามคู่มือได้ และรู้ว่าเรื่องใดต้องถามเจ้าของข้อมูล |
| เริ่มอธิบายและเขียนคำสั่งใหม่ทุกงาน | มีต้นแบบและคำสั่งทำซ้ำที่อ้างอิง Source ชุดเดียวกัน |

GitHub เป็นที่เก็บไฟล์และประวัติการเปลี่ยนแปลง เราจะกำหนดวิธีให้แต่ละเครื่องรับข้อมูลและให้เครื่องมือ AI อ่านเวอร์ชันนั้นใหม่อย่างชัดเจน ไฟล์ที่ดาวน์โหลดหรือแนบในแชตเก่าไม่ได้เปลี่ยนตามเอง

## เลือกต้นแบบที่ทีมจะได้ใช้ก่อนหนึ่งอย่าง

| ทางเลือก | เปิดใช้แล้วทำอะไรได้ |
| --- | --- |
| **Branch Desk** | ค้นชื่อสาขาหรือจุดสังเกต ดูเบอร์ คัดลอกข้อมูลติดต่อ และเปิดที่มาจาก Source สาธารณะของ The Dent |
| **เครื่องมือเตรียมบรีฟคอนเทนต์และแอดมิน** | เลือกสาขาและประเภทงาน แล้วได้บรีฟหรือข้อความตั้งต้นพร้อมข้อเท็จจริง เพื่อนำไปใช้กับ Claude หรือ ChatGPT ต่อ |
| **รายงาน Excel/CSV ที่ทำซ้ำได้** | ใช้ไฟล์ส่งออกจริงที่เตรียมพร้อมแล้ว ทำสำเนาจัดระเบียบและหน้าสรุป พร้อมคำสั่งสำหรับรอบถัดไป |

ในวันเรียนเลือกสร้าง **หนึ่งต้นแบบหลัก** อีกสองทางเลือกเป็นแนวขยายหลังทีมใช้ชุดแรกได้ ทางเลือก Excel/CSV ต้องมีไฟล์จริงและความหมายของข้อมูลพร้อมก่อนกำหนดขอบเขต

Branch Desk และเครื่องมือบรีฟใช้ข้อมูลสาธารณะ The Dent เป็นตัวอย่างเริ่มต้น ปุ่มหรือข้อความตัวอย่างแสดงผลจากข้อมูลที่เตรียมไว้ ไม่ได้เรียก AI หรือเชื่อม GitHub แบบสด และไม่ตอบผู้ป่วยหรือยืนยันนัดแทนทีม

## เรียนและลงมือ 4 ช่วง

| ช่วง | ทำอะไร | สิ่งที่ได้ |
| --- | --- | --- |
| **1. เตรียมทีมและเครื่องมือ** | ติดตั้งเครื่องมือ ตั้งค่าบัญชีและสิทธิ์ เลือก Source เจ้าของข้อมูล และต้นแบบหลัก | เครื่องที่พร้อมทำงาน ขอบเขตหนึ่งชุด และบทบาทผู้ดูแล/ผู้ใช้ |
| **2. จัด Source กลาง** | สร้าง repository จัดไฟล์ ที่มา และเวอร์ชัน ฝึกแก้ข้อมูล ดูความต่าง และย้อนการเปลี่ยนแปลง | Source ที่ตามประวัติได้ พร้อมวิธีเสนอแก้และตรวจรับข้อมูล |
| **3. สร้างต้นแบบที่เลือก** | ให้ AI ช่วยสร้างจาก Source และบรีฟเดียวกัน เปิดทดลองและปรับให้ตรงงาน | ต้นแบบหนึ่งชิ้นและคำสั่งที่ใช้ทำซ้ำ |
| **4. ส่งต่อให้ทีมใช้ได้** | รับเวอร์ชันเดียวกันบนสองเครื่อง ให้เครื่องมืออ่านใหม่ แล้วให้เพื่อนทำตามคู่มือ | หลักฐานการใช้ข้อมูลตรงกันและคู่มือส่งต่อสั้น ๆ |

## หลักฐานว่างานจบจริง

- ผู้ดูแลอนุมัติการแก้ข้อมูลหนึ่งจุด บันทึกเวอร์ชันใหม่ แล้วทั้งสองเครื่องรับเวอร์ชันนั้นและอ่านข้อมูลใหม่ได้
- ผลงานบนสองเครื่องอ้างข้อเท็จจริงตรง Source เช่น คู่ชื่อสาขา–เบอร์และ URL แม้ถ้อยคำที่ AI เขียนจะต่างกัน
- ทดลองย้อนการเปลี่ยนแปลงหนึ่งรายการ ตรวจว่าค่ากลับตามที่ตั้งใจและประวัติยังอยู่
- เพื่อนร่วมงานเปิดคู่มือแล้วทำงานเดิมได้หนึ่งรอบ พร้อมบอกว่าใช้ Source เวอร์ชันใด

## สิ่งที่จะเก็บกลับ

Repository ของทีมที่มีเจ้าของและสิทธิ์เข้าถึง, Source ชุดแรก, ต้นแบบที่เลือกหนึ่งชิ้น, คำสั่งทำซ้ำ และคู่มือรับข้อมูลใหม่/เสนอแก้/ส่งต่องาน พร้อมผลทดลองจากสองเครื่อง

ก่อนเรียนจะตกลงเครื่องมือ วิธีเข้าถึง repository ข้อมูลที่ทีมอนุญาตให้ใช้ และต้นแบบหลักให้เหมาะกับบัญชีและสภาพแวดล้อมจริง งานเชื่อม ERP หรือระบบอื่นค่อยกำหนดขอบเขต implement แยกภายหลัง

นำหลักฐานจากการบ้าน AI Leader มาเลือกโจทย์ได้ แล้วตกลงวันเรียนและค่าคอร์สก่อนเริ่ม นัดติดตามกลุ่ม 30 นาทีที่รวมใน Workshop เดิมยังได้รับตามปกติ ไม่ขึ้นกับการเลือกเรียน Advance
