# AI Leader Advance — ซอสกลางขององค์กรบน GitHub

คอร์สต่อยอดแบบเต็มวันสำหรับทีมที่เริ่มใช้ AI กับงานจริงแล้ว และต้องการให้หลายคนใช้ Source กลางที่ดูแลต่อได้ เป็นคอร์สเพิ่มเติมที่มีค่าเรียนแยกจาก Workshop ปัจจุบัน

## สิ่งที่ทีมจะทำได้

มีพื้นที่ Source กลางบน GitHub พร้อมผู้ดูแล สิทธิ์เข้าถึง ประวัติการเปลี่ยนแปลง และวิธีให้เครื่องมือ AI ของทีมอ่านไฟล์เวอร์ชันเดียวกัน เมื่อข้อมูลเปลี่ยน ทีมรู้ว่าใครแก้ ใครตรวจ และแต่ละเครื่องรับข้อมูลใหม่อย่างไร

## ลงมือร่วมกัน 4 ช่วง

| ช่วง | สิ่งที่จะทำ | ผลงานที่ได้ |
| --- | --- | --- |
| 1. เตรียมเครื่องและบัญชี | ติดตั้งเครื่องมือที่ใช้ในคลาส ตั้งค่าบัญชี GitHub และสิทธิ์ตามบทบาท เลือก Source ที่ทีมอนุญาตให้ใช้ | เครื่องและบัญชีที่พร้อมทำงานกับพื้นที่กลาง |
| 2. สร้างบ้านให้ Source | สร้าง repository ของทีม จัดไฟล์และชื่อให้หาเจอ กำหนดเจ้าของข้อมูล ที่มา และเวอร์ชัน | Source ชุดแรกพร้อมโครงสร้างที่ทีมใช้ร่วมกัน |
| 3. ฝึกอัปเดตอย่างเป็นขั้นตอน | แก้ข้อมูลหนึ่งจุด ดูความต่าง ให้ผู้ดูแลตรวจ แล้วบันทึกการเปลี่ยนแปลง ฝึกเปิดดูเวอร์ชันก่อนหน้า | วิธีแก้และรับรอง Source ที่ทำซ้ำได้ |
| 4. ให้สองเครื่องใช้ข้อมูลเดียวกัน | ตั้งค่าเครื่องมือให้เข้าถึงไฟล์จาก repository รับเวอร์ชันที่ทีมเลือก แล้วให้ AI อ่านข้อมูลใหม่อย่างชัดเจน ทดลองงานเดียวกันบนสองเครื่อง | ผลทดสอบว่าแต่ละเครื่องอ่าน Source เวอร์ชันเดียวกันและใช้ข้อมูลที่แก้แล้ว |

## ภาพปลายทางที่ต้องเห็น

ผู้ดูแลแก้ Source หนึ่งจุด → ทีมรับเวอร์ชันใหม่ → AI บนเครื่องที่หนึ่งและเครื่องที่สองอ่านข้อมูลใหม่นั้น → ผลงานอ้างข้อเท็จจริงตรงกัน โดยรู้ว่าใช้เวอร์ชันใด ข้อความที่ AI เขียนอาจต่างรูปแบบกันได้

GitHub เก็บไฟล์และประวัติ ส่วนการรับข้อมูลลงเครื่องและการให้ AI อ่านใหม่ต้องมีวิธีที่ตั้งค่าไว้ในคอร์ส ไฟล์ที่ดาวน์โหลดหรือแนบในแชตเก่าจะไม่เปลี่ยนตามเอง

## สิ่งที่จะเก็บกลับไป

- Repository ของทีมที่กำหนดผู้ดูแลและสิทธิ์แล้ว
- Source ชุดแรกและตัวอย่างการอัปเดตที่ตามประวัติได้
- วิธีรับเวอร์ชันที่ใช้ร่วมกันและคำสั่งให้ AI อ่าน Source ปัจจุบัน
- คู่มือสั้นสำหรับเพิ่มผู้ใช้งานและผลทดลองจากสองเครื่อง

เริ่มจาก Source หนึ่งชุดที่สำคัญกับงานร่วมกัน ใช้หลักฐานจากการบ้าน AI Leader เลือกโจทย์ แล้วตกลงขอบเขต วันเรียน และค่าคอร์สก่อนเริ่ม การเผยแพร่ข้อมูลสาธารณะและการเชื่อมระบบงานอื่นไม่ได้เกิดขึ้นอัตโนมัติจากการมี repository

นัดติดตามกลุ่ม 30 นาทีที่รวมใน Workshop เดิมยังได้รับตามปกติ ทีมเลือกเรียน Advance ได้เมื่อพร้อม
