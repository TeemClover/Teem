# ใบสั่งงานสั้น — ชุดสำนักงาน The Dent

**งาน:** ทำเอกสารให้ทีมสื่อสารข้อมูลติดต่อจากต้นทางเดียวกัน
**ข้อมูล:** clinic-public-source.md และภาพสาธารณะของทีมที่เลือกใช้
**ผลลัพธ์:** office-kit.docx + content-plan.xlsx + image.png

ใบคำสั่งนี้พร้อมใช้ ไม่ต้องสร้างบรีฟแยกอีกไฟล์ คัดลอกไปเริ่มงานได้เลย:

~~~text
อ่าน clinic-public-source.md แล้วสร้างชุดเอกสารภาษาไทย น้ำเสียงสุภาพ กระชับ

ส่ง office-kit.docx: ร่างบันทึกถึงทีมหนึ่งหน้าเรื่องใช้ข้อมูลติดต่อจากต้นทางเดียวกัน / คำตอบแอดมินสามสถานการณ์ (ไปรัชโยธิน ติดต่อรังสิต ขอเช็กคิวพรุ่งนี้) / แคปชันสามแบบ

ส่ง content-plan.xlsx เป็นแผนคอนเทนต์ร่างสามแถวตรงกับแคปชัน มีลำดับ หัวข้อ ข้อความ ภาพประกอบที่ใช้ และขั้นตอนถัดไป ไม่กำหนดวันเผยแพร่หรือผู้รับผิดชอบที่ยังไม่ได้ระบุ

รักษาคู่สาขา–เบอร์–ลิงก์ตาม Source เรื่องคิวให้แนะนำช่องทางสอบถามทีม ไม่เพิ่มราคา เวลาเปิด คิวว่าง หรือข้อมูลการรักษา เก็บที่มาไว้ท้ายเอกสาร
ถ้าใช้โฟลเดอร์ให้บันทึกใน output โดยเก็บต้นทาง ถ้าใช้แชตให้ส่งไฟล์ดาวน์โหลดชื่อเดียวกัน
~~~

## สร้างภาพใน ChatGPT

~~~text
ใช้ Source และภาพของทีมที่แนบ สร้างภาพประชาสัมพันธ์ข้อมูลติดต่อ The Dent หนึ่งภาพ โทนส้ม ขาว อ่านง่าย หากไม่มีภาพให้ใช้กราฟิกเรียบง่าย
ใช้ข้อมูลเท่าที่ Source มี ไม่เพิ่มราคา คิว หรือคำกล่าวอ้างการรักษา เลือกข้อความสั้นและเว้นพื้นที่ให้แคปชันประกอบ
สร้างภาพจริงและส่งให้ดาวน์โหลดเป็น image.png
~~~
