# ใบสั่งงานสั้น — ชุดสำนักงาน The Dent

**งาน:** ทำเอกสารให้ทีมสื่อสารข้อมูลติดต่อจากต้นทางเดียวกัน
**ข้อมูล:** clinic-public-source.md และภาพสาธารณะของทีมที่เลือกใช้
**ผลลัพธ์หลัก:** office-kit.docx + content-plan.xlsx + ภาพที่สร้างได้ใน ChatGPT

เริ่มใน ChatGPT Free หรือ Claude Free ผ่านเบราว์เซอร์ แนบ Source ทีละงานเมื่อมีสิทธิ์ หรือวางข้อความส่วนที่ใช้ในแชต ขอไฟล์ดาวน์โหลดจริงก่อน ทั้งสองเครื่องมืออาจมีโควตาและความพร้อมของเครื่องมือแตกต่างกัน

ใบคำสั่งนี้พร้อมใช้ ไม่ต้องสร้างบรีฟแยกอีกไฟล์ คัดลอกไปเริ่มงานได้เลย:

~~~text
อ่าน clinic-public-source.md แล้วสร้างชุดเอกสารภาษาไทย น้ำเสียงสุภาพ กระชับ

ส่ง office-kit.docx: ร่างบันทึกถึงทีมหนึ่งหน้าเรื่องใช้ข้อมูลติดต่อจากต้นทางเดียวกัน / คำตอบแอดมินสามสถานการณ์ (ไปรัชโยธิน ติดต่อรังสิต ขอเช็กคิวพรุ่งนี้) / แคปชันสามแบบ

ส่ง content-plan.xlsx เป็นแผนคอนเทนต์ร่างสามแถวตรงกับแคปชัน มีลำดับ หัวข้อ ข้อความ ภาพประกอบที่ใช้ และขั้นตอนถัดไป ไม่กำหนดวันเผยแพร่หรือผู้รับผิดชอบที่ยังไม่ได้ระบุ

รักษาคู่สาขา–เบอร์–ลิงก์ตาม Source เรื่องคิวให้แนะนำช่องทางสอบถามทีม ไม่เพิ่มราคา เวลาเปิด คิวว่าง หรือข้อมูลการรักษา เก็บที่มาไว้ท้ายเอกสาร
ขอไฟล์ดาวน์โหลดชื่อข้างต้น ฉันจะเก็บใน output เอง โดยเก็บต้นทางไว้
ถ้าสร้างไฟล์ดาวน์โหลดไม่ได้ ให้ส่งเอกสารเป็น Markdown และตารางเป็น TSV คั่นด้วยแท็บในคนละบล็อก ไม่อ้างว่าสร้าง DOCX/XLSX สำเร็จแล้ว
~~~

## เก็บเอกสารเมื่อไม่มีไฟล์ดาวน์โหลด

คัดลอก Markdown ไปบันทึกเป็น office-kit.md แบบข้อความล้วน UTF-8 หรือวางใน Word แล้ว Save As .docx คัดลอก TSV ลง Excel แล้ว Save As content-plan.xlsx หากส่งออก CSV จะได้ตารางของชีตนั้น ไม่ใช่ workbook และไม่ใช้การเปลี่ยนนามสกุลแทน

Claude Chat อ่านเฉพาะสิ่งที่แนบหรือวาง ไม่อ่านและจัดโฟลเดอร์บนเครื่องเอง

## สร้างภาพใน ChatGPT

~~~text
ใช้ Source และภาพของทีมที่แนบ สร้างภาพประชาสัมพันธ์ข้อมูลติดต่อ The Dent หนึ่งภาพ โทนส้ม ขาว อ่านง่าย หากไม่มีภาพให้ใช้กราฟิกเรียบง่าย
ใช้ข้อมูลเท่าที่ Source มี ไม่เพิ่มราคา คิว หรือคำกล่าวอ้างการรักษา เลือกข้อความสั้นและเว้นพื้นที่ให้แคปชันประกอบ
เมื่อเครื่องมือสร้างภาพพร้อม ให้สร้างภาพจริงและส่งให้ดาวน์โหลด
ถ้าโควตาหรือเครื่องมือสร้างภาพไม่พร้อม ให้ส่งคำสั่งสร้างภาพที่พร้อมใช้เป็นข้อความ เพื่อเก็บใน image-prompt.md ไม่อ้างว่ามีภาพแล้ว
~~~

ใช้ ChatGPT Free สร้างภาพตามโควตาที่มี ส่วน Claude Chat ใช้เตรียมคำสั่งภาพได้ ให้บันทึกภาพตามชนิดไฟล์ที่ดาวน์โหลดจริง หรือเก็บ image-prompt.md แบบ UTF-8 เมื่อยังสร้างไม่ได้

เปิดผลงาน ปรับหนึ่งจุด แล้วเก็บสิ่งที่ทำได้จริงใน output หากโควตาจำกัดให้แยกขอเอกสาร ตาราง และภาพทีละงานสั้น ๆ ใช้ข้อมูลและภาพของตนเองที่ได้รับอนุญาต ไม่ต้องส่งข้อมูลลูกค้าให้ผู้สอน
