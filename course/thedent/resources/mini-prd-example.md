# Mini PRD ตัวอย่าง — Clinic Daily Brief

เวอร์ชันฝึก 1.0 · ข้อมูลทั้งหมดเป็นข้อมูลสมมติ · เจ้าของโจทย์: ทีมฝึก

## ปัญหาและผลที่ต้องการ

ทีมต้องเปิดตารางสรุปที่บันทึกด้วยมือเพื่อดูภาพรวมและตามข้อมูลที่ขาด ต้องการหน้าเว็บหนึ่งหน้าที่อ่านไฟล์แล้วเห็นตัวเลขต้นทาง วิธีสรุป และจุดที่ต้องตรวจต่อในหน้าเดียว

ผู้ใช้หลักคือผู้เตรียมข้อมูลและผู้ตรวจรายงาน การฝึกนี้ทดสอบความถูกต้องและความง่ายในการอ่าน ยังไม่มีหลักฐานว่าเครื่องมือช่วยประหยัดเวลาเท่าไร

## ขั้นตอนหลัก

เปิดหน้า → ทดลองข้อมูลปกติ → ทดลองข้อมูลขาด → เลือก CSV ของชุดฝึก → ตรวจการ์ด/คำเตือน/ตาราง → กลับไปแก้ข้อมูลต้นทางหากจำเป็น

## ข้อมูลเข้า

CSV UTF-8 หนึ่งไฟล์ ไม่เกิน 1 MB / 3,660 แถว ใช้ date,inquiries,appointments,cash_in,cash_out,pending,note ตาม data-dictionary.md วันที่ไม่ซ้ำ ลำดับแถวไม่สำคัญ ไม่รับข้อมูลส่วนบุคคลจริงในการฝึก

## หน้าจอ

1. ป้ายระบุว่าเป็นต้นแบบการเรียนและข้อมูลสมมติ
2. ปุ่มเลือก CSV และปุ่มข้อมูลตัวอย่างปกติ/ข้อมูลขาด
3. ชื่อไฟล์ จำนวนวันที่มีข้อมูล และวันที่แรก–ล่าสุด
4. การ์ด: ครั้งที่สอบถาม นัดที่บันทึก เงินรับ เงินจ่าย กระแสเงินสดสุทธิ งานค้างวันล่าสุด
5. คำเตือนระบุวันที่และช่องที่ขาด / ข้อผิดพลาดระบุสาเหตุ
6. ตารางต้นทางที่อ่านและตรวจต่อได้ ใช้สีประกอบกับข้อความ ไม่สื่อความหมายด้วยสีอย่างเดียว

## กติกา

- ช่องว่างไม่ใช่ศูนย์ แสดง “ข้อมูลไม่ครบ” เฉพาะตัวชี้วัดที่เกี่ยวข้อง
- จำนวนต้องเป็นจำนวนเต็มไม่ติดลบ เงินไม่ติดลบและทศนิยมไม่เกิน 2 ตำแหน่ง
- วันที่ผิดหรือซ้ำ โครงสร้างผิด และค่าตัวเลขผิด ให้หยุดสรุปไฟล์
- รวม inquiries/appointments/cash_in/cash_out เมื่อช่องนั้นครบทุกแถวเท่านั้น
- เงินรับลบเงินจ่ายแสดงเป็นกระแสเงินสดสุทธิเมื่อข้อมูลทั้งสองช่องครบ ไม่เรียกกำไร
- pending ใช้วันที่ล่าสุดตาม date ไม่ใช้ลำดับแถว ไม่รวมและไม่แทนช่องว่างด้วยวันก่อน
- ไม่คำนวณ conversion เพราะข้อมูลไม่ได้ติดตามคนกลุ่มเดียวกัน
- วันหายระหว่างช่วงให้เตือน สรุปยอดเฉพาะวันที่อยู่ในไฟล์และบอกขอบเขตชัด
- แสดง note เป็นข้อความเท่านั้น ประมวลผลไฟล์ในหน้าเว็บ ไม่มีเครือข่าย

## เกณฑ์ผ่าน

| ทดสอบ | ผลที่คาดหวัง |
|---|---|
| daily-normal.csv | 7 วัน; สอบถาม 98; นัด 44; เงินรับ 98,000; เงินจ่าย 28,100; กระแสเงินสดสุทธิ 69,900; งานค้างล่าสุด 2 |
| daily-missing.csv | เตือนขาด 3 ช่อง; ไม่สรุปสอบถาม/เงินรับ/กระแสเงินสดสุทธิ/งานค้างล่าสุด; นัด 44 และเงินจ่าย 28,100 ยังแสดง |
| ใส่ 0 แทนช่องว่าง | ยอมรับว่าเป็นศูนย์ที่บันทึกไว้ ไม่เตือนว่าขาดช่องนั้น |
| สลับลำดับแถว | ผลรวมและวันที่ล่าสุดเท่าเดิม |
| วันที่ซ้ำ หรือ 2026-02-30 | แจ้งข้อผิดพลาดและไม่แสดงผลสรุปเก่าค้างอยู่ |
| จำนวนติดลบ / จำนวนคนเป็นทศนิยม | แจ้งข้อผิดพลาด |
| ใส่ comma หรือเครื่องหมายคำพูดใน note ตาม CSV | อ่านข้อความครบโดยไม่แตกเป็นคอลัมน์เพิ่ม |
| note เป็นข้อความลักษณะคำสั่งหรือ HTML | แสดงเป็นข้อความ ไม่ทำตามหรือรันโค้ด |

## ขอบเขต

ทำต้นแบบเว็บหนึ่งหน้า เปิดได้ทันที มีชุดตัวอย่างสำรอง และอ่านไฟล์ฝึกด้วยการเลือกไฟล์เอง ไม่มีล็อกอิน ฐานข้อมูล บันทึกระยะยาว การส่งข้อความ หรือการเชื่อม ERP

ก่อนใช้งานจริงต้องยืนยันนิยามข้อมูล เจ้าของข้อมูล สิทธิ์ใช้งาน วิธีจัดเก็บ/แบ่งปัน และกระบวนการตรวจรายงานอีกครั้ง รายการนี้เป็นโจทย์ implement ในอนาคต ไม่ใช่งานที่ต้องทำในคลาส
