# บทเสริม · บรีฟพร้อมสั่ง AI สร้างเว็บ

ใช้คำสั่งนี้พร้อมแนบ clinic-public-source.md ได้เลย หรือเปิด mini-prd-example.md เพื่อดู PRD ที่เขียนไว้ครบแล้ว

~~~text
ฉันต้องการหน้า The Dent Branch Desk สำหรับทีมคอนเทนต์และแอดมิน

ทำอะไรได้: ค้นสาขาหรือจุดสังเกต ดูข้อมูลติดต่อ คัดลอกเบอร์ และเปิด LINE/เว็บไซต์
ใช้ข้อมูล: ซอส The Dent ที่แนบ
ส่งมอบ: branch-desk.html ไฟล์เดียว เปิดในเครื่องและมือถือได้โดยไม่ติดตั้ง
หน้าตา: อ่านง่าย ใช้สีขาว ส้ม และเทาเข้ม
เมื่อค้นไม่พบ: แสดงข้อความบอกและมีปุ่มล้างคำค้น
เมื่อคัดลอก: แจ้งผล พร้อมทางเลือกให้เลือกคัดลอกเอง
ขอบเขต: หน้าข้อมูลติดต่อ ไม่มีระบบจองหรือเชื่อม ERP

ช่วยสรุปเป็น Mini PRD สั้น ๆ แล้วสร้างไฟล์ตามบรีฟนี้ได้เลย
เลือกรายละเอียดที่เหลือให้เหมาะสม และเก็บชื่อ เบอร์ ลิงก์ กับวันที่ข้อมูลตามซอส
~~~

PRD คือการบอก AI ว่าใครใช้ ต้องทำอะไรได้ และต้องส่งผลงานแบบไหน ไม่จำเป็นต้องเริ่มด้วยเอกสารยาว หากอยากปรับตัวอย่าง ลองบอกเพียง “ทำตัวหนังสือใหญ่ขึ้น” หรือ “ให้ปุ่มโทรเด่นขึ้น”
