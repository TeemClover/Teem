# Mini PRD · แม่แบบ Branch Desk

ชื่อผลงาน: …
เวอร์ชัน / วันที่แก้: …
ผู้ทำ / ผู้ตรวจ: …
สถานะ: ร่างสำหรับฝึก / ตรวจแล้วตามเกณฑ์ฝึก / รอข้อมูล

## 1. ปัญหาและผู้ใช้

ผู้ใช้หลักคือใคร: …
ตอนนี้ต้องทำอะไร และติดตรงไหน: …
หลังมีผลงานนี้ ผู้ใช้ควรทำอะไรสำเร็จ: …

อธิบายผลลัพธ์หนึ่งประโยค: “ช่วยให้ … ค้น … และ … ได้จากหน้าเดียว โดยตรวจกลับไปที่ต้นทางได้”

## 2. ข้อมูลเข้าและสิ่งที่ยังไม่ทราบ

Source ที่ใช้: thedent-source-v0.1.md ของผู้เรียน หรือ clinic-public-source.md ฉบับตัวอย่าง
เวอร์ชัน Source: …
วันที่ตรวจข้อมูล: … (วันเปิดตรวจ ไม่ใช่วันเริ่มมีผลของข้อมูล)
URL และตำแหน่งที่ใช้: …

แสดงเฉพาะรายการที่ Source มีหลักฐาน โดยเก็บชื่อสาขา จุดสังเกต โทรศัพท์ URL ต้นทาง และวันที่ตรวจไว้คู่กัน แยกช่องทางติดต่อกลางออกจากช่องทางเฉพาะสาขา

| ข้อมูล | หลักฐาน / URL | สถานะ |
| --- | --- | --- |
| ชื่อสาขาและโทรศัพท์แต่ละคู่ | … | SOURCE / รอตรวจ |
| จุดสังเกตหรือพื้นที่ | … | SOURCE / รอตรวจ |
| LINE และเว็บไซต์ | … | SOURCE / รอตรวจ |
| วันที่ตรวจข้อมูล | … | วันที่เปิดตรวจ |
| จำนวนสาขาที่ให้บริการล่าสุด | มีข้อความ 2/3 สาขาไม่ตรงกันในต้นทาง | OPEN |
| เรื่องอื่นที่ยังไม่ทราบ | … | OPEN |

กติกาที่ต้องรักษา: ข้อมูลที่เว็บไซต์แสดงยังไม่ใช่คำรับรองจากผู้รับผิดชอบคลินิก อย่าเปลี่ยนข้อเสนอวิธีตอบให้เป็นนโยบาย อย่าเดาข้อเท็จจริงเพื่อเติมช่องว่าง

## 3. สิ่งที่จะสร้างในรอบนี้

ส่งมอบ branch-desk.html หนึ่งไฟล์ มี HTML/CSS/JavaScript ในตัว เปิดในเบราว์เซอร์ได้โดยไม่ต้องติดตั้งหรือดึงไลบรารีภายนอก พร้อมคำอธิบายวิธีเปิดและแก้ข้อความสั้น ๆ

- แสดงชื่อสาขา จุดสังเกต โทรศัพท์ และหลักฐานจาก Source
- ค้นหาด้วยชื่อสาขาหรือจุดสังเกต และล้างคำค้นได้
- มีสถานะเมื่อไม่พบข้อมูล
- คัดลอกเบอร์โทร พร้อมแจ้งผลหรือมีทางเลือกเมื่อ clipboard ใช้ไม่ได้
- มีลิงก์โทร, LINE กลาง และเว็บไซต์/URL ต้นทางตาม Source
- แสดงวันที่ตรวจและประเด็นจำนวนสาขาที่ยังรอยืนยัน
- อ่านและกดใช้ได้บนจอมือถือ

จำนวนรายการที่แสดงหมายถึงรายการที่มีหลักฐานใน Source ไม่ประกาศว่าเป็นสาขาทั้งหมดที่เปิดให้บริการในปัจจุบัน

## 4. ลำดับการใช้งาน

1. เปิด branch-desk.html → เห็นรายการที่มีใน Source และวันที่ตรวจ
2. พิมพ์ชื่อสาขาหรือจุดสังเกต → เห็นรายการที่ตรงคำค้น
3. กดคัดลอกเบอร์ → วางในโปรแกรมข้อความเพื่อตรวจ
4. อ่านปลายทางของลิงก์โทร/LINE/เว็บไซต์ก่อนเลือกเปิด
5. ค้นคำที่ไม่มี → เห็นข้อความไม่พบข้อมูล → ล้างคำค้นเพื่อกลับมาดูรายการ

## 5. สิ่งที่อยู่นอกขอบเขต

ไม่มีข้อมูลผู้ป่วย ไม่มีการจองหรือยืนยันคิว ไม่มีข้อมูลสถานะบริการรายวัน และไม่เชื่อม ERP หรือระบบภายใน ไม่ส่งข้อความ โทร หรือจองให้อัตโนมัติ ไม่เติมราคา เวลาเปิด–ปิด หรือผลการรักษาที่ Source ไม่ยืนยัน
