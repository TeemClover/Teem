# ใบตรวจผลงาน — ตรวจจากต้นทาง ก่อนเชื่อหน้าจอ

ชื่อผู้ทำ / ผู้ตรวจ: … / …
งานที่ตรวจ: …

## งานข้อความ

- [ ] ใช้ข้อมูลและตัวอย่างที่เจ้าของงานยืนยัน
- [ ] แยกข้อเท็จจริงออกจากกติกาที่ AI ตีความ
- [ ] ทุกข้อมูลสำคัญชี้กลับไปที่ต้นทางได้
- [ ] ไม่เติมราคา คิวว่าง เงื่อนไข หรือผลการรักษาที่ไม่มีข้อมูล
- [ ] มีขั้นตอนให้ผู้อ่านทำต่อ และส่งต่อเรื่องที่ยังไม่ทราบ
- [ ] เจ้าของข้อมูลและผู้ตรวจที่เกี่ยวข้องได้ตรวจตามบทบาทแล้ว

## งานรายงานและเว็บต้นแบบ

- [ ] เห็นชื่อไฟล์ วันที่ และขอบเขตข้อมูลที่กำลังดู
- [ ] ตรวจผลปกติด้วย answer-key.md ได้
- [ ] ช่องว่างและศูนย์ให้ผลต่างกันอย่างถูกต้อง
- [ ] ข้อมูลผิดทำให้หยุดสรุป ไม่เหลือตัวเลขจากไฟล์ก่อนหน้าให้เข้าใจผิด
- [ ] งานค้างใช้ยอดของวันที่ล่าสุด ไม่ใช่ผลรวม
- [ ] กระแสเงินสดสุทธิคำนวณเมื่อข้อมูลครบและไม่เรียกกำไร
- [ ] ไม่เรียกสัดส่วนนัด/สอบถามว่า conversion
- [ ] ตารางและคำเตือนอ่านตามได้ทั้งคอมพิวเตอร์และมือถือ
- [ ] ลองไฟล์ที่ลำดับแถวเปลี่ยน มีข้อความ comma และวันที่ซ้ำแล้ว

สิ่งที่ต้องแก้ก่อนใช้งาน: …
สิ่งที่ยังไม่ทราบ: …
