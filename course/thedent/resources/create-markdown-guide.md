# สร้างไฟล์ซอส .md ของตัวเอง

Markdown (.md) คือไฟล์ข้อความที่ใช้เครื่องหมายง่าย ๆ จัดหัวข้อ รายการ และลิงก์ คนอ่านได้ และแนบให้ AI ในแชตใหม่ได้

## 1. ลองเปิดตัวอย่างก่อน

ดาวน์โหลด `clinic-public-source.md` จากหน้าเรียน เปิดอ่านด้วยโปรแกรมข้อความหรือแนบให้ AI สังเกตหัวข้อที่ขึ้นต้นด้วย `#` รายการที่ขึ้นต้นด้วย `-` และลิงก์ที่มี URL

## 2. สกัดจากต้นทาง

เปิดเว็บไซต์จริงหรือแนบ `website-source-notes.md` แล้วใช้พรอมป์ “สกัดซอสจากเว็บไซต์ The Dent” ตรวจ URL โทรศัพท์ และจุดที่ข้อมูลขัดกันก่อนเก็บเป็นไฟล์

## 3. ให้ AI ส่งออกเป็นไฟล์

**ใน Cowork:** เลือกโฟลเดอร์งานที่ใช้เรียน แล้วมอบหมายว่า “บันทึกซอสที่ตรวจแล้วเป็น thedent-source-v0.1.md ในโฟลเดอร์นี้” เปิดไฟล์จากโฟลเดอร์จริงเพื่อยืนยันว่าบันทึกแล้ว

**ใน ChatGPT:** ขอให้สร้างไฟล์ `.md` สำหรับดาวน์โหลด แล้วดาวน์โหลดลงเครื่อง หากหน้าที่ใช้อยู่ส่งได้เพียงข้อความ ให้ใช้วิธีข้อความล้วนด้านล่าง

**วิธีสำรอง:** คัดลอก Markdown ทั้งหมดใส่โปรแกรมแก้ข้อความล้วน บันทึกแบบ UTF-8 เป็น `thedent-source-v0.1.md` เลือกชนิดไฟล์ที่รักษานามสกุลเองได้ ตรวจชื่อจริงว่าไม่ลงท้าย `.md.txt` และไม่เป็นเอกสาร rich text `.rtf`

## 4. โครงสั้นสำหรับเริ่มไฟล์ใหม่

```markdown
# The Dent — Source สำหรับทีม

เวอร์ชัน: 0.1.0
วันที่รวบรวม: [วันที่ทำไฟล์]
วันที่ตรวจแหล่งข้อมูล: [วันที่เปิดอ่านจริง]
ผู้ดูแลไฟล์: [ให้ทีมกำหนด]

## ขอบเขต
[นำไปใช้ทำอะไร]

## แหล่งข้อมูล
- S01: [URL] — ตรวจเมื่อ [วันที่] — [อ่านได้/อ่านไม่ได้]

## SOURCE — ข้อมูลที่มีหลักฐาน
- [ข้อเท็จจริง] — ที่มา S01

## COMPANY CLAIM — สิ่งที่องค์กรกล่าว
- [คำกล่าวพร้อม URL และเงื่อนไข ถ้าไม่มีไม่ต้องเติม]

## DERIVED — ข้อเสนอจากการตีความ
- [น้ำเสียงหรือกติกาที่เสนอให้ทีมรับรอง]

## OPEN — ยังไม่ทราบหรือข้อมูลขัดกัน
- [ประเด็น / ต้องตรวจจากใครหรือที่ไหน]

## วิธีตรวจและแก้
[ตรวจอะไร ก่อนใช้ซ้ำ]

## ประวัติแก้ไข
- 0.1.0: [สร้างจากแหล่งใด]
```

## 5. ทดสอบว่าเป็นไฟล์ที่ใช้ต่อได้

1. ปิดแล้วเปิดไฟล์ใหม่ ตรวจว่าภาษาไทยอ่านได้ครบ
2. เปิดแชตใหม่ แนบเฉพาะ `.md` ที่ตัวเองทำ
3. ให้ตอบเรื่องสาขาและเรื่องที่ยังไม่มีข้อมูล พร้อมระบุที่มา
4. หากตอบผิด ให้แก้ Source แล้วบันทึกเวอร์ชันและสิ่งที่เปลี่ยน

วันที่บันทึกไฟล์ไม่ใช่วันที่โปรโมชั่นเริ่มมีผล และการตั้งชื่อ “final” ไม่ใช่การอนุมัติจากคลินิก
