# เก็บคำสั่งเป็นไฟล์ .md

.md คือไฟล์ข้อความที่มีหัวข้อ อ่านเองหรือแนบให้ AI ได้ ใช้เก็บ Source และ repeat-workflow.md

หลังทำงานเสร็จ บอก AI ว่า:

~~~text
เก็บวิธีทำงานรอบนี้เป็น repeat-workflow.md สั้น ๆ ระบุไฟล์ต้นทาง ขั้นตอน และชื่อไฟล์ผลลัพธ์ที่ได้จริง ให้ใช้กับรอบหน้าได้ เก็บเฉพาะวิธีทำ ไม่ใส่ข้อมูลลูกค้ารายคน
ถ้าใช้โฟลเดอร์ บันทึกใน output ถ้าใช้แชต ส่งไฟล์ดาวน์โหลด
~~~

เปิดไฟล์ที่ได้ แล้วเก็บคู่กับผลงาน เมื่อเริ่มรอบใหม่แนบคำสั่งนี้กับไฟล์ของตนเองได้เลย หากได้รับเพียงข้อความ ให้คัดลอกลงโปรแกรมข้อความและบันทึกแบบ UTF-8
