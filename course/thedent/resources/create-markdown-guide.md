# ไฟล์ .md ใช้อย่างไร

.md คือไฟล์ข้อความที่มีหัวข้อและลิงก์ อ่านเองหรือแนบให้ AI ได้เหมือนไฟล์เอกสารทั่วไป

**สำหรับคลาสนี้:** ดาวน์โหลด clinic-public-source.md แล้วแนบใน Claude หรือ ChatGPT ได้เลย ไม่ต้องสร้างไฟล์ใหม่ก่อนเริ่มเรียน

## ถ้าอยากเก็บคำตอบของตัวเองเป็นไฟล์

คัดลอกคำสั่งนี้หลังจาก AI ทำงานเสร็จ:

~~~text
บันทึกคำตอบล่าสุดเป็นไฟล์ my-work.md ให้ดาวน์โหลด พร้อมจัดหัวข้อให้อ่านง่าย
~~~

ใน Cowork สามารถให้บันทึกลงโฟลเดอร์งานที่เลือกไว้ได้ หากได้เป็นข้อความแทนไฟล์ ให้คัดลอกใส่โปรแกรมข้อความและบันทึกชื่อ my-work.md แบบ UTF-8

เมื่อจะใช้ต่อในแชตใหม่ เพียงแนบไฟล์เดิมพร้อมบอกงานถัดไป เช่น “ใช้ข้อมูลนี้ทำโพสต์สั้นอีกหนึ่งแบบ”
