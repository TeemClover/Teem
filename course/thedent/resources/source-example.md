# ตัวอย่างการสกัดซอส — กติกาที่เอาไปทำงานซ้ำได้

> สกัดจาก clinic-training-brief.md ซึ่งเป็นข้อมูลสมมติสำหรับการเรียนเท่านั้น “อนุมัติ” ในเอกสารนี้หมายถึงอนุมัติเฉพาะสถานการณ์ฝึก

## 1. ข้อเท็จจริงที่ใช้ได้

| เรื่อง | ข้อมูลที่ยืนยันในสถานการณ์ฝึก | ต้นทาง |
|---|---|---|
| งานที่ต้องการ | ส่งคำขอนัดปรึกษาเบื้องต้น | S1 |
| ขั้นตอน | แจ้งวัน/ช่วงเวลาทาง Inbox → แอดมินตรวจคิว → แอดมินยืนยัน | S1, S3 |
| สถานะนัด | คำขอยังไม่ใช่นัดที่ยืนยันแล้ว | S1, S2, S3 |
| ช่วงรับคำขอ | จันทร์–ศุกร์ 10:00–18:00 น. ของคลินิกสมมติ | S1 |

## 2. ซอสที่ตีความจากตัวอย่าง และต้องให้เจ้าของงานรับรอง

| กติกาที่เสนอ | หลักฐาน | สถานะ |
|---|---|---|
| เป็นมิตร สุภาพ และบอกขั้นตอนตรงไปตรงมา | S2 A/B และ S3 ใช้ประโยคสั้น บอกการกระทำต่อไป | ข้อเสนอจากตัวอย่าง |
| หนึ่งข้อความชวนทำหนึ่งเรื่อง คือส่งวันและช่วงเวลาที่สะดวก | S2 A/B | ข้อเสนอจากตัวอย่าง |
| เมื่อพูดถึงการจอง ต้องแยก “ส่งคำขอ” กับ “ยืนยันนัด” | S1 และ S2 A/B | ข้อเท็จจริงและกติกาที่มีต้นทางชัด |
| ข้อมูลที่ยังไม่ยืนยันให้บอกตรง ๆ แล้วส่งตรวจ | S1, S3 ข้อ 2 | ข้อเท็จจริงและกติกาที่มีต้นทางชัด |

ผู้เรียนควรแก้กติกาที่ไม่ตรงใจและทำเครื่องหมายรับรองก่อนส่งให้ AI เขียนงานใหม่ อย่าให้ข้อสรุปของ AI กลายเป็นนโยบายองค์กรเอง

## 3. สิ่งที่ยังไม่ทราบ

- ค่าปรึกษาและเงื่อนไขการชำระเงิน
- คิวที่ว่างและเวลาที่จะได้รับคำตอบ
- รายการตรวจรักษา ผู้ให้บริการ และผลที่คาดหวัง
- ข้อมูลจริงของ The Dent สำหรับแทนที่ข้อมูลสมมติ

## 4. บรีฟพร้อมมอบหมาย

“ใช้ S1–S3 ใน clinic-training-brief.md และกติกาที่ฉันรับรองแล้ว เขียนโพสต์สั้น 1 ชิ้นเพื่อให้ผู้สนใจส่งคำขอนัด และร่างคำตอบ 3 สถานการณ์: ขอจอง ถามค่าใช้จ่าย ถามสถานะนัด แยกชิ้นงานกับตารางตรวจข้อมูล ระบุต้นทางของข้อเท็จจริง และรายการที่ยังต้องยืนยัน ห้ามเติมข้อเท็จจริงที่ไม่มีในไฟล์”
