# เตรียมคุยติดตาม 30 นาที

นัดกลุ่มหลังเรียนประมาณ 1–2 สัปดาห์ รวมอยู่ในคอร์ส วันเวลาตกลงร่วมกันภายหลัง

ห้องติดตามผล: https://www.teambook.me/join/?c=52113

ระหว่างเจ็ดวัน ทำภารกิจของวันนั้นแล้วกด **ลงชื่อวันนี้ → ลงชื่อ** วันละหนึ่งครั้ง เล่าสั้น ๆ ว่าทำอะไร ได้อะไร ไม่ต้องส่งไฟล์หรือข้อมูลลูกค้า ผู้สอนใช้ความคิดเห็นหลังคลาสและเรื่องที่ทีมเล่าเพื่อเลือกจุดที่ควรช่วยในนัดนี้

นำ ai-leader-progress.md และไฟล์ที่ได้ลองจริงมาเปิดคุย:

- งานตัวเอง: office-kit.docx / content-plan.xlsx / image.png หรือ customer-workbook.xlsx กับ team-summary.docx และคำสั่งทำซ้ำ
- งานของเพื่อน: ไฟล์ที่เขาลงมือเองและจุดที่ต้องช่วย
- Source ของทีม: ข้อมูลที่เลือก ผู้ดูแล และปัญหาจริงหรือทางอัปเดตครั้งหน้า

ใช้คำสั่งใน ai-leader-homework.md ให้ AI สรุปจากหลักฐานที่มี ไม่ต้องสร้างรายงานใหม่ ถ้ายังไม่มี export ให้บอกว่าเตรียมวิธีทำแล้วหรือได้รันกับไฟล์จริงภายหลังถึงขั้นไหน

| เวลา | คุยร่วมกัน |
| --- | --- |
| 0–5 นาที | เลือกจุดติดร่วมจากสามภารกิจ |
| 5–15 นาที | เปิดผลงานจริงสองหรือสามตัวอย่าง |
| 15–25 นาที | ช่วยแก้จุดสำคัญหนึ่งเรื่อง |
| 25–30 นาที | เลือกงานถัดไปและผู้รับผิดชอบ |
