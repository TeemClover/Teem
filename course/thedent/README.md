# The Dent basic workshop

This classroom teaches office documents, images and analysis of learners' own customer exports. Work is organized in local source / input / output folders. Cowork uses a selected folder; ChatGPT Work on desktop can use authorized local files, while Chat or Work on the web uses attachment/download flows. AI processing may involve provider or cloud services.

## Deliverables

The file session produces file-map.md listing actual selected files, their types and purpose. Desktop tools organize copies into source / input / output while preserving originals. Web sessions only inspect attachments and return the file map for the learner to download and organize locally.

Workshop 1 uses the finished public clinic Source and the learner's chosen public photo, or a generated graphic. It produces office-kit.docx (one-page staff memo, three FAQ replies, three captions), content-plan.xlsx (three draft rows) and a real image.png created with ChatGPT.

Workshop 2 produces customer-workbook.xlsx with cleaned / summary / issues / field-map, team-summary.docx and repeat-workflow.md. Analysis is conditional on actual fields and known meanings. Learners open their own exports; the instructor does not collect, download or prepare customer data. No fictional customer rows or public branch-table fallback are supplied. Without an export, learners prepare a prompt and field-map plan from their own known task or real headers and explicitly record that customer analysis has not run.

The basic course stays with files, documents, images and repeatable work. It does not teach PRDs, coding, website construction, publishing or SaaS integration.

## Authoring and resources

- Lessons, prompts and workshop slides: course-content.js. UI: course.js / course.css.
- Opening presentation: opening.html and resources/opening-notes.md.
- Canonical Source: ../../shelf/source/thedent/public-company.md. The build copies it exactly to resources/clinic-public-source.md; do not edit the generated copy.
- Public-source context stays in website-source-notes.md and source-example.md.
- Ready office command and example: office-workflow-brief.md and office-kit-example.md. The command sheet is supplied; learners do not create a separate brief before working.
- File flows: tool-quickstart.md, office-file-guide.md and excel-csv-guide.md.
- Instructor/reference docs: instructor-guide.md, clinic-training-brief.md, answer-key.md, review-checklist.md, create-markdown-guide.md and workflow-template.md.
- Seven-day missions in ai-leader-homework.md retain repeat-work / teach-peer / source-owner. Evidence is saved as ai-leader-progress.md; followup-worksheet.md supports the included call.
- Run the course build after edits to regenerate the copied Source, prompt library, slide notes, embedded resources and offline ZIP. Do not edit generated files directly.

After extracting the kit, open index.html. Presentation images, fonts and text resources are available in the downloaded files; AI and external sites require the connection their tools use. Learner progress stays on the device.
