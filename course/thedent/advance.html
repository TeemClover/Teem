  • หน้าค้นข้อมูลที่เปิดใช้ได้

02

CONTENT · ADMIN

ตัวช่วยเตรียมบรีฟของทีม

  • ต้นแบบหน้าเตรียมบรีฟ
  • แม่แบบโพสต์ คลิป และแอดมิน
  • วิธีส่งต่อไฟล์ให้คนผลิตงาน

03

OPERATIONS · EXCEL / CSV

วิธีทำรายงานซ้ำจากไฟล์ส่งออก

เก็บความหมายคอลัมน์ กติกาจัดข้อมูล และคำสั่งสรุปไว้ให้ทีมใช้กับไฟล์รอบหน้า

  • Source อธิบายไฟล์และกติกา
  • ต้นแบบขั้นตอนสร้างรายงาน
  • Excel ผลลัพธ์กับคำสั่งทำซ้ำ
ดูแนวทาง Excel / CSV ↗

เลือกทางนี้เมื่อมีไฟล์ส่งออกและโจทย์รายงานพร้อม

ขอบเขตวันเรียน: ซอสกลางหนึ่งชุด + ต้นแบบที่ตกลงหนึ่งชิ้น การเชื่อม ERP หรือเปิดระบบอัตโนมัติเป็นงาน implement ที่กำหนดแยกภายหลัง

ONE DAY · BUILD TOGETHER

เต็มวัน เพราะเราทำ
ตั้งแต่เตรียมเครื่องจนส่งต่อ

  1. ช่วงที่ 1

    เตรียมเครื่องและบัญชี

    ติดตั้งเครื่องมือ เปิด GitHub และตั้งสิทธิ์สำหรับโจทย์ของทีม

    พร้อมเริ่มทำงานร่วมกัน
  2. ช่วงที่ 2

    จัด Source กลาง

    วางไฟล์ กำหนดเจ้าของ ลองแก้ข้อมูลและรับเวอร์ชันเดียวกัน

    มีซอสหลักและวิธีดูแล
  3. ช่วงที่ 3

    สร้างต้นแบบที่เลือก

    ใช้ Source + PRD พา AI สร้างงาน แล้วลองกับโจทย์จริง

    ได้ชิ้นงานที่เปิดใช้ได้
  4. ช่วงที่ 4

    ทดสอบและส่งต่อ

    ลองจากสองเครื่อง ให้เพื่อนทำตามคู่มือ และเก็บวิธีทำซ้ำ

    ทีมมีทางไปต่อหลังคลาส
