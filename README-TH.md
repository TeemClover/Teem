## สิ่งที่ปรับจาก V4.3
- เอาปุ่ม Inventory ใต้ Main Quest ออก
- Inventory ยังอยู่ใน nav และ Sub Quest ตามบทบาทจริง
- ย่อผลเลือกสายให้เหลือชื่อสายกับปุ่มเข้าสู่เส้นทาง
- เอาย่อหน้าอธิบาย RGBG ด้านล่างออก
- เปลี่ยนคำเปิด Sub Quest ให้เล่าบ้านเป็นเกม Open World
- `Open World` กดดูคำอธิบายได้
- `วันละ 10 นาที` กดดูการเปรียบเทียบเวลาได้:
  - ประมาณ 0.7% ของหนึ่งวัน
  - 70 นาทีต่อสัปดาห์
  - ราว 5 ชั่วโมงต่อเดือน
- เพิ่มลูกศรและ hover เบา ๆ ให้การ์ด Sub Quest โดยไม่เพิ่มกล่องใหม่
- JavaScript ผ่าน `node --check`
