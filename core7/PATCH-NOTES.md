# myClover: CORE7 — Patch Notes

## 2026-08-04 — v0.5 Set Ending + Sound Trim

- เสียง `player-joined` ดังเฉพาะตอนมีผู้เล่นอีกคนเข้าห้องจริง ๆ เท่านั้น
- ตัดออกจากตอนคู่แข่งกดพร้อมเล่นรอบต่อไป และตอนเราสร้าง/เข้าห้องเอง (กลับไปใช้เสียงสังเคราะห์สั้น ๆ เหมือนเดิม)
- จบ SET แล้วหน้าผลกลายเป็น **หน้าจบจริงหน้าเดียว** ไม่ต้องกด "กลับห้องเดิม" เพื่อไปดูผลชุดอีกชั้น
  - หัวเรื่องประกาศผลของชุด พร้อมคะแนนรวมและคำว่า "จบชุดแล้ว"
  - เปิดเผย Starting Hands ของทั้งสองฝั่งตรงหน้านี้เลย
  - ปุ่มเป็นทางออกจริง: สร้างห้องใหม่ / กลับ Public Lobby
- แก้คะแนนชุดบนหน้าผลที่เคยช้าไปหนึ่งนัด — เดิมใช้ค่าที่ค้างไว้ตั้งแต่ก่อนแมตช์เริ่ม ตอนนี้ถามสถานะจาก server หลังแมตช์จบ
- ชุดที่ยังไม่จบยังทำงานเหมือนเดิมทุกอย่าง (ปุ่มเล่นรอบต่อไป · ยังไม่เปิด Starting Hands)

## 2026-08-04 — v0.5 Real Sound Effects

- เพิ่มเสียงจากไฟล์จริง 3 เสียง แทนเสียงสังเคราะห์ในจังหวะที่สำคัญ
  - `player-joined` — มีคนเข้าห้องที่เราสร้าง และตอนคู่แข่งกดพร้อมเล่นรอบต่อไปใน SET
  - `card-flip` — พลิกการ์ดกติกาหน้าแรก และพลิกเปิดการ์ดใบใหม่ที่ได้รับ
  - `card-swap` — สลับตำแหน่งไพ่ในมือ
- แปลงเสียงสลับไพ่จาก `.m4a` (AAC) เป็น `.mp3` เพราะ AAC ต้องพึ่ง decoder ของระบบ บางเบราว์เซอร์เล่นไม่ได้
- โหลดไฟล์ไว้ล่วงหน้าตั้งแต่หน้าโหลดเสร็จ แต่ decode ตอนใช้จริง เสียงครั้งแรกจึงไม่ต้องรอเน็ต
- ถ้าโหลดหรือ decode ไม่ผ่าน ถอยไปใช้เสียงสังเคราะห์ตัวเดิมอัตโนมัติ — เสียงเพี้ยนดีกว่าเงียบสนิท
- ปุ่มปิดเสียงคุมทั้งไฟล์เสียงและเสียงสังเคราะห์เหมือนเดิม

## 2026-08-04 — v0.5 Table Reading + Hand Gestures

- บรรทัดผลรอบวางอีโมจิ**ฝั่งเราไว้ซ้ายเสมอ** ตรงกับการ์ดฝั่งซ้ายบนโต๊ะและในประวัติ
- แพ้แล้วไม่สลับฝั่งอีกต่อไป เปลี่ยนเป็นกลับเครื่องหมายเป็น `<` แทน (ชนะ `>` · เสมอ `=`)
- ลากการ์ดขึ้นได้ไกลถึงกลางจอ ไม่ติดเพดาน 120px เหมือนเดิม
- เกณฑ์ "ลงการ์ด" เปลี่ยนจากระยะตายตัว 58px เป็น **พ้นขอบบนของแถวมือ** พร้อมขอบทองบอกว่าปล่อยได้แล้ว
- แตะ/คลิกสองทีเร็ว ๆ = เลือก + Lock + ลง ในทีเดียว (คลิกเดียวยังเป็นแค่เลือกเหมือนเดิม)
- **จัดลำดับไพ่ในมือได้** ด้วยการลากไปทางข้าง ใบข้าง ๆ ขยับหลบให้เห็นตำแหน่งใหม่ก่อนปล่อย
- ลำดับมือเก็บฝั่ง client อย่างเดียว แยกตาม matchId อยู่รอด refresh กลางเกม และไม่กระทบกติกา
- แปลข้อความที่ JS สร้างครบทั้งหมด: หน้าจอเล่นเกม, ห้องออนไลน์, หน้าผล, ป๊อปอัปรางวัล, footer, ชื่อบอท, ชื่อ Rank และ aria-label/title/alt ทุกจุด
- สลับภาษากลางแมตช์ได้แล้ว โครงหน้าจอกับไพ่ในมือวาดใหม่ตามภาษาใหม่ทันที

## 2026-08-04 — v0.5 Bilingual Web + Card Unlock Stat

- ขึ้นเวอร์ชันเกมเป็น `v0.5` ทุกจุดที่แสดงผล และรวมเลขเวอร์ชันไว้ที่ `CORE7_GAME_VERSION` ที่เดียว
- ทั้งเว็บใช้คีย์ภาษาเดียวกันคือ `mc_lang` และย้ายค่าเดิมจาก `c7:lang` ให้อัตโนมัติครั้งเดียว (ยกเว้นหน้า Kickstarter ที่เป็นอังกฤษเสมอ)
- เพิ่มหน้า `/en/` เป็น Landing Page ภาษาอังกฤษสำหรับ SEO พร้อม hreflang ทั้งสองทาง
- เก็บ Stat จำนวนการ์ด FIRST HAND ใบใหม่ที่ถูกเปิด ผ่าน event `CARD_UNLOCK` ใหม่ (Analytics v1.2)

- Export CSV รวมข้อมูลรายวันและ Card Unlock ด้วย

## 2026-08-02 — v0.3 Beta

- เปิดสถาปัตยกรรม multiplayer แบบ server-authoritative ผ่าน Cloudflare Pages Functions + D1
- ใช้รหัสห้องตัวเลข 4 หลัก (`0000–9999`) ที่ server จองแบบ atomic และคืนเมื่อหมดอายุ
- เพิ่ม Public Lobby พร้อม Refresh, empty/error/loading state และ atomic Join
- สร้างห้องได้แบบ Quick Match, Best of 3 และ Best of 5
- Series ใช้ Starting Hand เดิมทุก Match และเปิดเผยมือเต็มเมื่อจบ Series
- local player อยู่ฝั่งซ้ายเสมอบนเครื่องของตน
- ไพ่ที่ผู้แพ้ทิ้งถูกเปิดเผยในโต๊ะ, history และ summary
- เพิ่มสรุปแยกผู้เล่น ไพ่ที่เล่น ไพ่ที่ทิ้ง และจำนวนสี
- ลดบอทเหลือ EASY (สุ่ม) และ HARD (คิดจากข้อมูลสาธารณะ)

- รีเฟรช FIRST HAND ทั้ง 28 ใบเป็น procedural SVG `ART v0.3.0`
