# myClover: CORE7 — Patch Notes

## 2026-08-05 — จัดระเบียบหน้าสถิติ + Dashboard กลาง

**ทางเข้าเดียว: `myclover.com/stat/` ล็อกด้วยรหัสผ่าน**

- ล็อกที่ขอบด้วย Cloudflare Pages middleware (`functions/stat/_middleware.js`)
  ไม่ใช่ JS ในหน้า — ล็อกฝั่ง client เป็นแค่ผ้าม่าน ใครกด View Source ก็เห็นรหัส
  และ HTML ก็ถูกส่งถึงเครื่องเขาแล้วอยู่ดี
- ตั้ง `STAT_PASSWORD` (และ `STAT_USER` ถ้าอยากเปลี่ยนจาก `teem`) ที่
  Cloudflare Pages → Settings → Environment variables
- **ยังไม่ตั้งรหัส = ปิดประตูไว้ก่อน** พร้อมบอกวิธีตั้ง ไม่ใช่เปิดโล่ง
  เพราะ "ลืมตั้งแล้วเปิดทิ้ง" เป็นความผิดพลาดที่เงียบและแพงกว่ามาก

**Dashboard สรุปวันนี้**

- วันนี้เทียบเมื่อวานทั้ง 8 ตัวชี้วัด เรียงตามลำดับที่คนเดิน
  เลขเดี่ยว ๆ อ่านไม่ออกว่าดีหรือแย่ จนกว่าจะมีของเมื่อวานมาเทียบ
- บอกตรง ๆ ว่าวันนี้ยังไม่เต็มวัน — ต่ำกว่าเมื่อวานตอนบ่ายไม่ได้แปลว่าตก
- สัญญาณที่ต้องไปดูต่อ พร้อมลิงก์: achievement ที่ยิงซ้ำ (ข้อมูลผิด) ขึ้นก่อน
  ส่วนที่ยังไม่ได้ต่อสาย (ยังไม่มีเลข) ตามหลัง
- กราฟ 14 วัน และการ์ดทางเข้าห้องย่อย พร้อมป้ายว่าห้องไหนมีข้อมูลแล้ว
- ปุ่มไป Command Center

**แถบนำทางกลาง — `assets/stat-nav.js`**

ทุกหน้าสถิติ import ไฟล์เดียวแล้วแถบขึ้นเอง ไฮไลต์หน้าปัจจุบันจาก path
เพิ่มห้องใหม่ = เติมทะเบียนที่เดียว ไม่ต้องไล่แก้ทุกหน้าและไม่มีหน้าไหนตกหล่น

**ย้ายให้โครงบอกความหมายถูก**

## 2026-08-05 — Achievement Stat + Act Tracking

**หน้าใหม่ `/collection/stat/` — ของทุกชิ้นที่ปลดได้ในบ้าน เรียงตามเส้นทางจริง**

- เรียงตาม stage ที่คนเดินจริง (หน้าแรก → การ์ตูน → Walkthrough → CORE7 → ห้องเรียน
  → AWAKEN → Player Card → ห้องอื่น → เส้นทางลับ) ไม่ใช่เรียงตามยอด
  เพราะคำถามคือ "คนหล่นหายช่วงไหน" ไม่ใช่ "อะไรดัง"
- **ACT** = การกระทำที่ทำซ้ำได้ นับแยกสองเลข "กี่ครั้ง" กับ "กี่เครื่อง"
  ส่วนต่างบอกว่าคนกลับมาทำซ้ำหรือกดครั้งเดียวแล้วหาย
- **ACHIEVEMENT** ปลดได้ครั้งเดียวต่อเครื่อง สองเลขต้องเท่ากันเสมอ
  ถ้าไม่เท่าคือมีบั๊กยิงซ้ำ — หน้านี้เตือนให้เห็นทันที
- ของที่ยังไม่มีใครได้ยังอยู่ในรายการเป็นศูนย์ (ซ่อนได้ด้วยปุ่ม) ใบที่หายไป
  จากตารางคือสัญญาณ ต้องเห็น
- id ที่ไม่อยู่ในทะเบียน (ถูกเปลี่ยนชื่อ/ลบไปแล้ว) ถูกแยกไปกอง orphans ให้เห็น
  ไม่กลืนทิ้ง

**ทะเบียนกลาง `assets/achievements.js`**

- ที่เดียวที่รู้ว่ามีอะไรให้ปลดและเรียงยังไง — หน้าสถิติ ตัวยิง event และ
  หน้า Collection (รอบหน้า) อ่านจากไฟล์นี้ไฟล์เดียว เพิ่มของใหม่ = เติม object
- Forge เป็น **9 ใบ** แล้ว: เพิ่ม `forge-intro` (myClover · Intro) ไว้ก่อน EP1
- id เดิมของ Collection ทั้ง 36 ใบไม่ถูกแตะ ของที่คนปลดไว้แล้วยังเป็นใบเดิม

**ยิง event โดยไม่ต้องเขียน JS — `assets/track.js`**

```html
<meta name="mc-act-view" content="home-open">   <!-- ยิงตอนเปิดหน้า -->
<button data-mc-act="home-video">               <!-- ยิงตอนกด -->
```

- view นับครั้งเดียวต่อ session · click นับทุกครั้งจริง (กันรัว 800ms)
- ต่อสายหน้าแรกแล้ว: เปิดหน้า · กดดูคลิปเปิดบ้าน · หยิบเข็มทิศ

API ใหม่: `GET /api/core7/achievement-stats?from&to`

## 2026-08-04 — Journey Tracking (Analytics v1.3)

**ตัวรับข้อมูลของเส้นทาง First Run — ทำมาก่อนหน้าเว็บโดยตั้งใจ**

event ที่ไม่ได้เก็บวันนี้ คือข้อมูลที่ย้อนกลับไปเก็บไม่ได้ตลอดไป ถ้าหน้าเสร็จ
ก่อนแล้วค่อยมาต่อสาย ช่วงแรกที่คนเดินผ่านมากที่สุดจะไม่มีตัวเลขให้ดูเลย

- รับ event ครบ 15 ขั้น ตั้งแต่ `JOURNEY_START` ถึง `LESSON_1_START`
  ลำดับอยู่ที่ `JOURNEY_STEPS` ที่เดียว เพิ่มขั้นใหม่ที่นั่นแล้วกราฟตามไปเอง
- `reportJourneyStep()` ฝั่งเบราว์เซอร์ — กันซ้ำในตัว ยิงทิ้งไม่รอผล ไม่ throw
- แฟล็กทางเข้า `?entry=forge` จำไว้ในเครื่องแล้วติดไปกับทุก event หลังจากนั้น
  CORE7 ยังเปิดให้ทุกคนเข้าตรงได้เหมือนเดิม แฟล็กมีไว้แยกตัวเลขตอนอ่านอย่างเดียว
- หน้าใหม่ `/stat/journey/` (ตอนนั้นอยู่ที่ `/core7/stat/journey/`) — บันไดขั้น, % ที่ผ่านต่อ, จุดที่คนหายเยอะสุด,
  ตารางแยก forge/direct และรายวัน
- ตราบใดที่ยังไม่มีหน้าไหนยิง event หน้าสถิติจะเตือนว่า "ยังไม่ได้ต่อสาย"
  เพื่อไม่ให้อ่านเลขศูนย์ผิดเป็น "ไม่มีคนเดิน"

API ใหม่: `GET /api/core7/journey-stats?from&to` · คู่มือต่อสาย: `core7/JOURNEY-TRACKING.md`

## 2026-08-04 — Collection Stat

**หน้าใหม่ `/core7/collection/stat/` — ดูว่าคนหลุดตอนไหน ไม่ใช่ดูว่าใบไหนดัง**

- บันได drop-off: มีกี่เครื่องที่เก็บได้อย่างน้อย n ใบ ตั้งแต่ 1 ถึง 28
  พร้อม % ของคนที่มาถึงใบก่อนหน้าแล้วไปต่อได้อีกใบ
- ทำเครื่องหมายใบที่ 7 (ปลดล็อกโหมด SELECT) กับใบที่ 28 (ครบชุด) ไว้บนกราฟ
- ชี้จุดที่คนหายเยอะที่สุดให้เลย ไม่ต้องไล่อ่านตารางเอง
- Funnel ก่อนถึงการ์ดใบแรก: เปิด CORE7 → ล็อกมือ → เริ่ม Match → เล่นจบ → ได้ใบแรก
  ถ้าคนหลุดก่อนถึงขั้นสุดท้าย ปัญหาอยู่ก่อนระบบสะสม ไม่ใช่ที่การ์ด
- รายการการ์ดครบ 28 ใบ รวมใบที่ยังไม่เคยถูกสุ่มออกมา (แสดงเป็นเส้นประ)
  ใบที่หายไปจากตารางคือสัญญาณ ต้องเห็นเป็นศูนย์
- Export CSV และเลือกช่วงวันที่ได้เหมือนหน้า Stat หลัก

API ใหม่: `GET /api/core7/collection-stats?from&to`

## 2026-08-04 — v0.5 Silver + Icon Canon

**เปลี่ยนชื่อสีที่สี่จาก GRAY เป็น SILVER · ไทยเรียก "เงิน"**

- `RGBS` = Red / Green / Blue / Silver — เลิกใช้คำว่า Gray และ "เทา" บนเว็บทั้งหมด
- ไล่เปลี่ยนครบทุกหน้า: กติกา, Tutorial, หน้าแรก, Collection, เลือกมือ, Open Play, About, Profile, หน้าผล, Kickstarter และ Hall
- `Final Gray` → `Final Silver` ทุกที่ที่ผู้เล่นเห็น
- ปุ่มกรองสีแยก "ป้ายที่คนเห็น" ออกจาก "ค่าที่ใช้กรอง" แล้ว ป้ายมาจาก `COLOR_META` ส่วนค่ายังเป็นคีย์สีเดิม
- **คีย์ในข้อมูลยังเป็น `GRAY`** ทั้ง `COLOR_META.GRAY`, `fh-gray-*`, คอลัมน์ `played_gray` ใน D1 และ snapshot ใน localStorage — เปลี่ยนเมื่อไหร่ข้อมูลเก่าและสถิติที่เก็บไว้อ่านไม่ออกทันที

**ไอคอนและโลโก้ยึดไฟล์เดียวทั้งเว็บ**

- ไฟล์ canon อยู่ที่ `/assets/myclover-icon.png` ครอปให้เป็นจัตุรัสและเผื่อขอบแล้ว
- สร้างชุดไอคอนจากต้นฉบับเดียวกัน: `favicon.ico` (16/32/48), `icon-192`, `icon-512`, `apple-touch-icon` (180)

- แพ้แล้วไม่สลับฝั่งอีกต่อไป เปลี่ยนเป็นกลับเครื่องหมายเป็น `<` แทน (ชนะ `>` · เสมอ `=`)
- ลากการ์ดขึ้นได้ไกลถึงกลางจอ ไม่ติดเพดาน 120px เหมือนเดิม
- เกณฑ์ "ลงการ์ด" เปลี่ยนจากระยะตายตัว 58px เป็น **พ้นขอบบนของแถวมือ** พร้อมขอบทองบอกว่าปล่อยได้แล้ว
- แตะ/คลิกสองทีเร็ว ๆ = เลือก + Lock + ลง ในทีเดียว (คลิกเดียวยังเป็นแค่เลือกเหมือนเดิม)
- **จัดลำดับไพ่ในมือได้** ด้วยการลากไปทางข้าง ใบข้าง ๆ ขยับหลบให้เห็นตำแหน่งใหม่ก่อนปล่อย
- ลำดับมือเก็บฝั่ง client อย่างเดียว แยกตาม matchId อยู่รอด refresh กลางเกม และไม่กระทบกติกา
- แปลข้อความที่ JS สร้างครบทั้งหมด: หน้าจอเล่นเกม, ห้องออนไลน์, หน้าผล, ป๊อปอัปรางวัล, footer, ชื่อบอท, ชื่อ Rank และ aria-label/title/alt ทุกจุด
- สลับภาษากลางแมตช์ได้แล้ว โครงหน้าจอกับไพ่ในมือวาดใหม่ตามภาษาใหม่ทันที
