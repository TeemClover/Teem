# 4. Four-Color Protocol — RGBG

ลำดับ Canon ทุกหน้า ทุกแกลเลอรี และทุกเอกสารคือ:

1. 🔴 **RED · BODY**
2. 🟢 **GREEN · SOUL**
3. 🔵 **BLUE · MIND**
4. ⚙️ **GRAY · CRAFT**

Canonical phrase:

> **Body · Soul · Mind · Craft**

## 4.1 Color Cycle

- 🔴 RED ชนะ 🟢 GREEN
- 🟢 GREEN ชนะ 🔵 BLUE
- 🔵 BLUE ชนะ 🔴 RED
- สีเดียวกันเสมอ
- ⚙️ GRAY เสมอหรือ Block ทุกสีใน Round ปกติ

ลำดับการนำเสนอควรไหลต่อเนื่องตามวงจร:

> **RED → GREEN → BLUE → RED**

GRAY อยู่ตรงกลางหรือแยกเป็นแกนที่สี่ ไม่ควรแทรกระหว่างวงจรชนะ

## 4.2 Gray

ตอนค้นพบกลไก Gray ถูกเพิ่มในฐานะการ์ดที่ไม่มีพลังชนะสีใด มันเป็นการเลือกทิ้งเพื่อ Block รอบหนึ่ง

ภายหลัง Semantic Layer ให้ Gray เป็น **CRAFT** และมีคำ Observe, Measure, Build, Repair, Connect, Adapt, Iterate แต่บทบาทเชิงกลไกยังเป็น Block

> **Gray does not add randomness. It adds uncertainty.**

> **Three colors created the rules. The fourth created the game.**

> **สามสีสร้างกติกา สีที่สี่สร้างเกม**

# 5. เกมนี้ถูกค้นพบอย่างไร

CORE7 ไม่ได้เกิดจากการเพิ่ม Skill, Stats หรือข้อยกเว้น แต่มาจากการถอดสิ่งที่ไม่จำเป็นออก

ผู้ก่อตั้งกับลูกสาวถามคำถามเดิมซ้ำ ๆ:

> **เราจะถอดอะไรออกได้อีก โดยที่เกมยังคงเป็นเกม?**

สิ่งที่ต้องอธิบายแต่ไม่สร้างการตัดสินใจถูกตัดออก จนเหลือสามสีที่สร้างวงจรสมบูรณ์ แล้วเพิ่ม Gray ซึ่งตั้งใจให้ “ไม่มีอะไร”

ความไม่มีอะไรของ Gray กลับสร้าง:

- Timing
- Sacrifice
- Hidden Information
- Bluffing
- Doubt
- Resource Management
- Endgame Pressure
- การอ่านคนตรงหน้า

> **We did not build CORE7 by adding rules. We found it by removing them until there was nothing left to remove.**

## 5.1 การออกแบบร่วมกับลูกสาว

ผู้ก่อตั้งและลูกสาวเริ่ม Playtest เมื่อเธออายุหกขวบ ทั้งคู่ร่วมคิดและร่วมถอดกติกา ไม่ควรลดบทบาทเธอเหลือเพียงผู้ทดลองเล่น

> **My daughter and I kept removing the rules together until only the choices remained.**

# 6. กติกา CORE7

## 6.1 Setup

- ผู้เล่น 2 คน
- แต่ละคนเลือกการ์ด 7 ใบเป็น **CORE7 hand**
- สีใดกี่ใบก็ได้
- ไม่มี Deck และไม่มีกองจั่ว
- ไม่มีการสุ่มมือในกติกามาตรฐาน
- ผู้เล่นเห็นมือของตนทั้งหมดตั้งแต่เริ่ม
- มือคู่แข่งเป็น Hidden Information
- บันทึกจำนวน Gray เริ่มต้นไว้สำหรับ Tie Break ขั้นสุดท้าย

## 6.2 แต่ละ Round

1. ผู้เล่นทั้งสองเลือกการ์ดหนึ่งใบจากมือแบบลับ
2. Lock การเลือก
3. เปิดพร้อมกัน
4. Resolve จากสี
5. การ์ดที่เล่นทั้งสองใบไป Used Pile แบบหงายหน้า
6. ผู้ชนะได้ 1 Round Win และเสียเฉพาะใบที่เล่น
7. ผู้แพ้เสียใบที่เล่น และเลือกทิ้งเพิ่มอีก 1 ใบจากมือแบบหงายหน้า
8. ถ้าเสมอ ทั้งคู่เสียเฉพาะใบที่เล่น ไม่มีใครได้ Round Win และไม่มี Extra Discard

## 6.3 การชนะ CORE7 Match

ตรวจตามลำดับ:

1. ผู้เล่นคนใดมี 3 Round Wins ก่อน ชนะ Match ทันที
2. ถ้าคู่แข่งไม่มีการ์ดเหลือ แต่เรายังมีการ์ด เราชนะ Match
3. ถ้าทั้งคู่หมดมือพร้อมกัน ใช้ Tie Break

## 6.4 Tie Break เมื่อหมดมือพร้อมกัน

ตรวจตามลำดับ:

1. ถ้า Round สุดท้ายมีผู้ชนะตามวงจรสีปกติ ผู้ชนะ Round นั้นชนะ Match
2. **Final Gray:** ถ้า Gray เป็นการ์ดสุดท้ายและเจอกับสีที่ไม่ใช่ Gray, Gray แพ้
3. ถ้า Round สุดท้ายเป็นสีเดียวกัน รวม Gray vs Gray ให้ย้อนประวัติจาก Round ล่าสุดไปเก่าสุด ข้าม Round เสมอ ผู้ชนะ Round แรกที่พบชนะ Match
4. ถ้าทุก Round เสมอ ผู้ที่เริ่มด้วย Gray น้อยกว่าชนะ
5. ถ้าจำนวน Gray เริ่มต้นเท่ากันจริง ผลเป็น Draw

> **A tool can buy time, but it cannot choose the final victory for you.**

## 6.5 หลังจบ Match

ก่อนเริ่ม Match ใหม่ ผู้เล่นสามารถ:

- ใช้เจ็ดใบเดิม
- เปลี่ยนบางใบ
- สร้างมือใหม่ทั้งหมด

ยกเว้นเมื่อเล่น CORE7 Set ซึ่งมือถูก Lock ตลอด Set

# 7. CORE7 Set — Locked Hand

## 7.1 โครง

- ผู้เล่นแต่ละคนเลือก CORE7 เจ็ดใบก่อนเริ่ม Set
- ล็อกเจ็ดใบนั้นตลอด Set
- หลังจบแต่ละ Match รีเซ็ตการ์ดเจ็ดใบเดิมกลับมา
- คนแรกที่ชนะ 3 Matches ชนะ CORE7 Set

## 7.2 เหตุผลที่ Locked Hand สำคัญ

เมื่อมือไม่เปลี่ยน ความใหม่ไม่ได้มาจากการแจกข้อมูลใหม่ แต่มาจากสิ่งที่ผู้เล่นเรียนรู้เกี่ยวกับกัน

- Match แรก: จำสีและการตัดสินใจแรก
- Match ต่อมา: เริ่มเห็น Pattern
- เมื่อข้อมูลสะสม: ใช้ Memory เพื่อหลอกหรือปรับตัว
- ช่วงท้าย Set: ทุกใบมีประวัติร่วมกันแล้ว

> **Same hand. Next Match. Different feeling each time.**

> **The hand stays the same. The humans do not.**

> **A CORE7 Match creates the first impression. A CORE7 Set strengthens it into shared memory.**

## 7.3 0% RNG

ใน CORE7 Match และ CORE7 Set:

- ไม่มี Dice
- ไม่มี Draw Luck
- ไม่มี Random Hand
- ไม่มี Random Damage
- ไม่มี Random Resolution
- ไม่มีการ์ดที่สุ่มเป้าหมาย

Uncertainty ทั้งหมดเกิดจาก Hidden Choice และมนุษย์ตรงหน้า

> **0% RNG. 100% DECISIONS.**

Variant ที่ใช้การสุ่มต้องระบุชัดว่าอยู่นอกกติกามาตรฐานและ CORE7 Set
