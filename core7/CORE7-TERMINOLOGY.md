# CORE7 Public Terminology

This file overrides earlier public format names. Use the following hierarchy everywhere in campaign copy, rule explanations, AI knowledge, manufacturer briefs, and future documents.

## Round

One secret card choice and one simultaneous reveal.

## CORE7 Match

The first player to win **3 Rounds** wins one **CORE7 Match**.

A Match is one complete game. Players may keep or change their seven-card hand before starting another Match.

## CORE7 Set

Both players lock the same seven-card CORE7 hand for the entire Set. Reset those seven cards after every Match. The first player to win **3 Matches** wins the **CORE7 Set**.

## Memory shorthand

> **3 Round wins = 1 Match win.**
>
> **3 Match wins with the same hand = 1 Set victory.**

## Public-language rule

Use only this sequence:

> **Round → CORE7 Match → CORE7 Set**

Retire the previous competitive-format labels from public material. They add hobby-game jargon without adding useful meaning.

## ภาษาไทย

- **Round** — ผู้เล่นทั้งสองเลือกการ์ดหนึ่งใบลับ และเปิดพร้อมกันหนึ่งครั้ง
- **CORE7 Match** — คนแรกที่ชนะ **3 Rounds** ชนะหนึ่ง Match
- **CORE7 Set** — ล็อก CORE7 เจ็ดใบเดิมตลอด Set รีเซ็ตมือเดิมหลังทุก Match และคนแรกที่ชนะ **3 Matches** ชนะ Set

จำง่าย:

> **ชนะ 3 Rounds = ชนะ 1 Match**
>
> **ชนะ 3 Matches ด้วยมือเดิม = ชนะ 1 Set**
