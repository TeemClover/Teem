# ต้นฉบับช่องการ์ตูน

ไฟล์ในโฟลเดอร์นี้คือ **ต้นฉบับ** ที่ `tools/build.py` อ่านไปแปลงเป็น
`forge/img/*.webp` และ `*.jpg` แล้วประกอบเป็นหน้าเว็บใน `/forge/`

เก็บไว้ใน repo เพราะถ้าไม่มี จะแก้ช่องเดียวไม่ได้ — ต้องมีครบทั้งตอน
`build.py` ถึงจะยอมแปลงตอนนั้นใหม่

## ชื่อไฟล์

```
001 002          บทนำ /forge/intro/   (ไม่นับเป็นตอน)
011 … 014        ตอนที่ 1
021 … 024        ตอนที่ 2
   ⋮
071 … 074        ตอนที่ 7
```

## วิธีแปลงใหม่

```bash
FORGE_SRC=.forge-src python3 tools/build.py
```

ตอนไหนที่ไฟล์ต้นฉบับครบทุกช่อง จะถูกแปลงใหม่ทั้งตอน
ตอนไหนไม่ครบ จะข้ามไปใช้ภาพที่แปลงไว้แล้วใน `forge/img/`

## ยังเป็นภาพชั่วคราว

`063` `064` `071` `072` `073` `074` — ถอดกลับมาจาก `forge/img/` ที่แปลงไว้ตั้งแต่รอบก่อน
ยังไม่ใช่ภาพชุดใหม่ ทับไฟล์พวกนี้แล้วรัน `build.py` ใหม่ได้เลย
