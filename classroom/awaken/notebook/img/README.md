# ภาพของตอนพิเศษ "สมุดเล่มเก่า"

หน้า `../index.html` รอไฟล์ 10 ไฟล์นี้อยู่ วางไฟล์ลงในโฟลเดอร์นี้ได้เลย
ไม่ต้องแก้โค้ด — หน้าเว็บจะสลับจากกรอบ "รอไฟล์" มาเป็นภาพจริงเองทันที

| ไฟล์ | ใช้ตรงไหน | เห็นตอนไหน |
|---|---|---|
| `nb-01.jpg` | ช่องที่ 1 | เห็นเสมอ ทุกสถานะ |
| `nb-torn.jpg` | หน้าสมุดที่เสียหาย | แทนช่อง 2–9 จนกว่าจะใช้ RESTORE |
| `nb-02.jpg` … `nb-09.jpg` | ช่องที่ 2–9 | หลังกด "ซ่อมสมุด" เท่านั้น |

## ข้อกำหนดไฟล์

- นามสกุล `.jpg` ชื่อตรงตามตารางเป๊ะ ๆ (ตัวพิมพ์เล็ก)
- กว้าง 1200–1600px กำลังดี หน้านี้กว้างสุด 760px
- ช่องทั้ง 9 ควรกว้างเท่ากันทุกช่อง จะได้ต่อกันสนิทเหมือนตอนอื่น
- `nb-torn.jpg` ควรสูงพอ ๆ กับหนึ่งช่อง ไม่ต้องยาวเท่า 8 ช่องรวมกัน

## หลังวางไฟล์แล้วยังต้องทำอีกอย่าง

แก้ `alt` ของแต่ละช่องใน `../index.html` ให้บรรยายภาพจริง
ตอนนี้เป็นข้อความชั่วคราวว่า "ช่องที่ N ของตอนพิเศษ" ซึ่งคนใช้โปรแกรมอ่านหน้าจอยังไม่ได้อะไรจากมัน
