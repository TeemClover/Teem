ใช้ซอส myclover ที่เตรียมให้

ไฟล์ myclover / GLHF / GrowthOS ที่ใช้สร้างภาพและสไลด์ตัวอย่างด้านล่าง เลือกทางนี้ได้ทันทีแม้ยังไม่มีไฟล์ของตัวเอง

⬇️ ดาวน์โหลดซอส (.md)👀 เปิดอ่าน

เลือกวิธีนำเข้า หลังเลือกซอสแล้ว
มีไฟล์ในเครื่อง: เลือกอัปโหลดไฟล์ที่เครื่องมือรองรับ
มือถือไม่รับ .md: คัดลอกข้อความทั้งไฟล์ แล้วเพิ่มเป็น Copied text ใช้ได้ทั้งซอสของคุณและซอสตัวอย่าง
📱 Browser กับ App ใส่ซอสไม่เหมือนกันทางออกสำหรับคนที่หาเมนูอัปโหลด `.md` ไม่เจอ

Browser: สร้าง Notebook → เพิ่มซอส → อัปโหลดไฟล์หรือเลือกซอสที่รองรับ

App: ถ้าไม่เห็นไฟล์ .md ให้กดคัดลอกด้านบน แล้วเพิ่มเป็น Copied text

อย่ายึดติดกับชื่อปุ่ม เป้าหมายคือให้ข้อความซอสชุดเดียวกันเข้า Notebook ครบ

🔎 ผ่าไฟล์ `.md` ดูว่าทำไมแตกงานได้Key Messages, Tone และ Canon ที่คุมรสทุกเมนู

หัวข้อ: บอกลำดับและความสัมพันธ์

Key Messages: ประโยคที่ห้ามเพี้ยน

Tone: น้ำเสียงที่ทุก Output ใช้ร่วมกัน

Canon / ข้อห้าม: สิ่งที่ต้องคงเดิมและห้ามเติมเอง

ตรวจ Source ที่แนบ แล้วส่งรายงานความพร้อมสั้น ๆ ก่อนนำไปสร้างงาน: 1. ข้อเท็จจริงหลักมีอะไร 2. Key Messages ที่ห้ามเพี้ยนคืออะไร 3. Tone และ Canon ที่ต้องคงเดิมคืออะไร 4. จุดไหนยังขาดหรือขัดกัน 5. สรุปข้อเท็จจริง 3 ข้อให้ฉันใช้เทียบกับงานทุกชิ้น ตอบเป็นรายงานตรวจ Source เท่านั้น ถ้าข้อมูลขาด ให้ระบุว่า “ยังไม่มีข้อมูล” โดยไม่แต่งเพิ่ม

🖼️ ผง Infographic

เห็นเรื่องยากในภาพเดียว

สร้างอินโฟกราฟิกแนวตั้งภาษาไทยสำหรับคนที่ไม่เคยรู้เรื่องนี้ เลือกเฉพาะแกนสำคัญจากซอส เรียงภาพรวมก่อนรายละเอียด ใช้ภาษาสั้น ชัด เป็นมิตร รักษา Key Messages, Tone และ Canon ห้ามเพิ่มตัวเลข คำสัญญา หรือข้อสรุปนอกซอส ตรวจชื่อ ตัวเลข และการสะกดก่อนจบ

📊 ผง Slide Deck

เอาไปคุยกับทีม สอน หรือนำเสนอ

สร้าง Slide Deck ภาษาไทย 8–10 หน้า ผู้ฟังคือ [ระบุกลุ่มคน] เป้าหมายหลังดูจบคือ [สิ่งที่อยากให้เข้าใจหรือตัดสินใจ] 1 หน้าเล่า 1 ประเด็น เริ่ม Why → How → What → Next Action ทุกหน้าต้องอ้างซอสเดียวกัน รักษา Key Messages, Tone และ Canon ใช้ตัวเลขเฉพาะที่มีในซอส

🎬 ผง Video Overview

เล่าให้คนที่ไม่เคยรู้เรื่องตามทัน

สร้าง Video Overview ภาษาไทยแบบกระชับ เปิดด้วยคำถามหรือปัญหาที่ทำให้สงสัย อธิบายแกนหลักด้วยภาษาง่ายและตัวอย่างในซอส รักษา Key Messages, Tone และ Canon จบด้วย Action 1 อย่างที่ผู้ชมลองได้ทันที ห้ามเติมข้อเท็จจริงนอกซอส

🎧 ผง Audio Overview

ฟังได้ระหว่างเดินทางหรือทำงาน

สร้าง Audio Overview ภาษาไทยที่ฟังเป็นธรรมชาติ อธิบายเหมือนคนมีประสบการณ์คุยกับผู้เริ่มต้น เริ่มจากเหตุผลว่าทำไมเรื่องนี้สำคัญ ยกตัวอย่างจริงจากซอส รักษา Key Messages, Tone และ Canon จบด้วยคำถามให้คิดต่อ 1 ข้อ

🧠 ผง Mind Map

เห็นว่าของทุกส่วนต่อกันอย่างไร

สร้าง Mind Map จากซอส วางแกนกลางเป็น [หัวข้อหลัก] แตกแขนงตามความสัมพันธ์จริง ไม่ใช่แค่แบ่งย่อหน้า แยก Fact / Principle / Example / Action รักษาคำสำคัญและ Canon ถ้าไม่ชัด ให้ระบุว่ายังต้องยืนยันแทนการเดา

❓ ผง Quiz

เช็กว่าเข้าใจจริงหรือแค่พยักหน้า

สร้าง Quiz ภาษาไทย 8 ข้อจากซอส ผสมความจำ ความเข้าใจ และการประยุกต์ใช้ มีคำตอบและเหตุผลทุกข้อ ทุกคำตอบต้องชี้กลับไปยังซอสได้ ห้ามสร้างตัวเลขหรือข้อเท็จจริงใหม่ ท้ายชุดสรุป 3 เรื่องที่คนทำผิดบ่อย

ใช้ผงคนละซองไม่เป็นไรค่ะ แต่ถ้า Infographic บอกอย่างหนึ่ง Slide บอกอีกอย่าง และเสียงสรุปคิดพล็อตเพิ่มเอง เชฟขอเรียกว่าโต๊ะบุฟเฟต์ข่าวลือค่ะ ไม่ใช่การแตกเมนู

  4. สร้าง Output อย่างน้อย 3 รูปแบบด้วยผงด้านบน
