บทที่ 4 · MULTIPLY

ซอสขวดเดียว แตกได้หลายเมนู

ใช้ Source ครั้งเดียว แล้วสร้าง หลาย Output โดยไม่เริ่มเล่าใหม่ทุกครั้ง

⏱ 15–25 นาที🍱 3 Output🧴 Source เดียวกัน
เป้าหมายของบทนี้

แตก Source 1 ขวดเป็นงานอย่างน้อย 3 แบบ

เครื่องมือใดก็ได้ที่อ่าน Source ได้ ส่วน NotebookLM เป็นเพียงตัวอย่างหนึ่ง

1

เตรียมของ

เลือก Source ที่ผ่านการใช้จริงแล้วจากบท 3

🧴

Source 1 ขวดใช้ไฟล์เดียวเป็นฐานข้อเท็จจริงของทุก Output

👥

คนรับ 3 แบบเช่น ลูกค้า ทีมงาน และคนที่เพิ่งเริ่มต้น

2

ทำตาม 5 ขั้น

เมนูต่างกันได้ แต่รสหลักต้องเหมือนเดิม

1

ตรวจ Source

แก้ชื่อ ตัวเลข Canon และข้อห้ามให้เรียบร้อยก่อนเริ่มแตกงาน

2

เลือกคนรับ 3 กลุ่ม

เขียนให้ชัดว่าแต่ละกลุ่มรู้อะไรอยู่แล้ว และต้องการรู้อะไรต่อ

3

เลือก Output 3 แบบ

เช่น บทความ FAQ Checklist สไลด์ Script เสียง หรือหน้าเว็บ

ใช้ Source ที่แนบเป็นฐานข้อเท็จจริงหลัก แล้วแตกเป็น Output 3 แบบ 1. สำหรับ [คนรับกลุ่มที่ 1] เป็น [รูปแบบที่ 1] 2. สำหรับ [คนรับกลุ่มที่ 2] เป็น [รูปแบบที่ 2] 3. สำหรับ [คนรับกลุ่มที่ 3] เป็น [รูปแบบที่ 3] กติกา: - รักษา Key Messages ชื่อ ตัวเลข Tone และ Canon ตาม Source - ปรับเฉพาะภาษา ความยาว และรูปแบบให้เหมาะกับคนรับ - ถ้าข้อมูลไม่พอให้ถามก่อน ห้ามแต่งเพิ่ม
4

เทียบแกนกลาง

เช็กว่า Key Messages และข้อเท็จจริงสำคัญยังตรงกันทั้ง 3 ชิ้น

5

แก้ที่ต้นทางเมื่อผิดซ้ำ

ถ้าทุก Output ผิดเรื่องเดียวกัน ให้แก้ Source แล้วสร้างใหม่จากขวดที่แก้แล้ว

ไม่ต้องต้มใหม่ทุกหม้อ ถ้ามีซอสขวดเดียวที่ใช้ต่อได้

เชฟชิมแล้ว

ทำหลายเมนูจากซอสผิดขวด ไม่ได้เรียกว่าขยายผลค่ะ เรียกว่ากระจายปัญหา
