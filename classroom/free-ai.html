🚀 ใช้ AI เป็นอยู่แล้ว?

ถ้าบทนี้ง่ายเกินไป ข้ามไป LV.4 ได้เลย — นั่นคือบทที่ผมอยากเน้นที่สุด และเชื่อว่าจะได้ใช้จริง

ข้ามไป LV.4 →

1รู้จักผู้ช่วย 2 ตัวของเรา

✨
Gemini — ผู้ช่วยคุยได้ทุกเรื่องถาม-ตอบ เขียนข้อความ คิดไอเดีย สร้างภาพ แปลภาษา — เหมือนมีผู้ช่วยเก่ง ๆ นั่งข้างตัวตลอดเวลา ใช้ฟรีด้วยบัญชี Google
📚
NotebookLM — บรรณารักษ์ส่วนตัวโยนเอกสาร ไฟล์ ลิงก์ ให้มันอ่าน แล้วถามอะไรก็ได้จาก "ของของเรา" — มันตอบพร้อมชี้ว่าเอามาจากหน้าไหน ไม่มั่ว ใช้ฟรีเหมือนกัน
🤔
ใช้ตัวไหนตอนไหน?จำง่าย ๆ: เรื่องทั่วไปในโลก → Gemini · เรื่องในเอกสารของเรา → NotebookLM

2เตรียมของ (มีครบแล้วข้ามได้เลย)

บัญชี Google (Gmail)ตัวเดียวใช้ได้ทั้ง Gemini และ NotebookLM — ถ้ายังไม่มี สมัครฟรีที่ accounts.google.com
มือถือ หรือคอมพิวเตอร์ 1 เครื่องเครื่องไหนก็ได้ที่ต่อเน็ตได้

3เปิด Gemini แล้วส่งคำสั่งแรก

1
เปิด gemini.google.com แล้วล็อกอินด้วยบัญชี Googleบนมือถือ: โหลดแอป "Google Gemini" จาก App Store / Play Store ก็ได้ สะดวกกว่า
2
ก๊อปคำสั่งนี้ไปวางในช่องแชท แล้วกดส่ง
สวัสดี ฉันเพิ่งเคยใช้ AI ครั้งแรก งานประจำของฉันคือ [เติมอาชีพของคุณ เช่น ขายของออนไลน์ / พนักงานออฟฟิศ / แม่บ้าน] ช่วยแนะนำ 3 อย่างที่คุณช่วยงานฉันได้ พร้อมตัวอย่างสั้น ๆ ที่ทำให้ดูเลย
เปลี่ยนข้อความใน [วงเล็บ] เป็นของคุณเองก่อนส่ง — นี่คือกติกาเดียวกันทุกพร้อมท์ในบ้านนี้
3
คุยต่อได้เหมือนคุยกับคนไม่ต้องพิมพ์สวย ไม่ต้องกลัวผิด — ถ้าคำตอบยังไม่ถูกใจ บอกมันตรง ๆ ว่า "สั้นกว่านี้" "เป็นกันเองกว่านี้" "ยกตัวอย่างเพิ่ม" มันจะปรับให้ทันที

4เปิด NotebookLM รอไว้

1
เปิด notebooklm.google.com ล็อกอินบัญชีเดิมวันนี้แค่เปิดให้เห็นหน้าตาพอ — คลาส LV.4 เราจะเอาข้อมูลของคุณใส่เข้าไป แล้วให้มันแตกออกเป็นภาพ สไลด์ และคลิป

HARD MODE · สร้างไฟล์เซฟของ AI

คุยกับ AI มานานจนมันรู้จักงานและสไตล์ของคุณแล้วใช่ไหม? อย่าปล่อยให้ความเข้าใจนั้นติดอยู่ในแชทเดียว — แปลงมันเป็นไฟล์ .md แล้วพกข้ามแชท ข้ามเครื่อง หรือข้ามไปใช้อีก AI ได้

💾
ไฟล์ .md คือ Save Game ของการทำงานกับ AI

มันเก็บเป้าหมาย ข้อมูลสำคัญ สิ่งที่ตัดสินใจแล้ว สไตล์ที่ชอบ และงานที่ค้างไว้ เพื่อให้แชทใหม่เริ่มต่อได้โดยไม่ต้องเล่าทุกอย่างใหม่ตั้งแต่ต้น

🪶 เล็กจิ๋วเป็นไฟล์ข้อความล้วน ไม่มีภาพหรือเลย์เอาต์หนัก ๆ โปรเจกต์ยาวมากก็ยังมีขนาดเล็กและส่งต่อสะดวก
👀 คนก็อ่านได้เปิดด้วยแอปข้อความธรรมดาก็เห็นหัวข้อ รายการ และเนื้อหา ไม่ได้ถูกล็อกอยู่ในโปรแกรมใดโปรแกรมหนึ่ง
🤖 AI อ่านง่ายMarkdown มีโครงสร้างเรียบ ๆ เช่น หัวข้อ รายการ และตาราง ทำให้ AI ส่วนใหญ่ที่รับข้อความหรือไฟล์อ่านต่อได้ง่าย
🧳 ย้ายค่ายได้อัปโหลดเข้าแชทใหม่ หรือส่งให้อีก AI ที่รองรับไฟล์ข้อความ เพื่อย้าย Context โดยไม่ต้องเริ่มชีวิตใหม่ทุกครั้ง
แนะนำที่สุด: กลับไปใช้แชทหรือ session ที่คุณคุยเรื่องนี้มานานแล้ว เพราะแชทนั้นมีบริบทจริงอยู่ในมือ ให้มันเป็นคนสรุป Save File ของตัวเอง จะแม่นกว่าการเริ่มเขียนจากศูนย์
เปิดแชทเก่าที่รู้จักคุณดีที่สุดเลือกแชทที่ทำโปรเจกต์เดียวกันมาหลายรอบ หรือคุยจน AI รู้ข้อชอบ ข้อห้าม และสิ่งที่ตัดสินใจไปแล้ว
สั่งให้มันสร้าง Save File เป็น Markdownให้สรุปเฉพาะสิ่งที่จำเป็นต่อการทำงานต่อ ไม่ต้องยกบทสนทนาทั้งหมดมาใส่
ตรวจไฟล์ก่อนพกไปลบข้อมูลลับ แก้เรื่องที่ล้าสมัย และเช็กว่าเป้าหมายล่าสุดกับงานค้างถูกต้อง
ดาวน์โหลดเป็น .mdวางข้อความลงในเครื่องสร้างไฟล์ด้านล่าง แล้วกดดาวน์โหลด ไฟล์นี้คือ Save Slot ที่คุณควบคุมเอง
โหลด Save ในแชทใหม่อัปโหลดไฟล์แล้วบอก AI ให้อ่านเป็นบริบทตั้งต้น จากนั้นถามกลับเพื่อเช็กว่ามันเข้าใจตรงกันก่อนเริ่มงาน
จากบทสนทนาทั้งหมดใน session นี้ ช่วยสร้าง “AI Save File” เป็น Markdown ให้ฉัน เป้าหมายคือใช้ไฟล์นี้โอนบริบทไปยังแชทใหม่ หรือ AI อีกตัว โดยไม่ต้องเล่าใหม่ทั้งหมด จัดหัวข้อดังนี้: # ชื่อโปรเจกต์ ## เป้าหมายหลัก ## ข้อมูลสำคัญที่ต้องรู้ ## สิ่งที่ตัดสินใจและล็อกไว้แล้ว ## สไตล์หรือวิธีทำงานที่ฉันชอบ ## สิ่งที่ห้ามทำหรือข้อควรระวัง ## งานที่ทำเสร็จแล้ว ## งานที่กำลังทำและขั้นตอนถัดไป ## คำสั่งเริ่มต้นสำหรับแชทใหม่ กติกา: - สรุปให้กระชับ แต่ต้องพอทำงานต่อได้จริง - ใช้เฉพาะข้อมูลที่มีอยู่ในบทสนทนานี้ - ไม่ใส่รหัสผ่าน ข้อมูลการเงิน ข้อมูลส่วนตัวอ่อนไหว หรือความลับที่ไม่จำเป็น - ถ้ามีข้อมูลขัดกัน ให้ใช้คำสั่งล่าสุดและระบุว่าข้อมูลเก่าถูกแทนที่แล้ว - ตอบเป็นเนื้อหา Markdown พร้อมบันทึกเป็นไฟล์ได้ทันที - อย่าใส่เครื่องหมาย ``` ครอบเนื้อหา

🛠️ สร้างไฟล์ .md ในหน้านี้

เอาข้อความที่ AI สรุปให้มาวาง ตั้งชื่อ Save Slot แล้วดาวน์โหลดได้เลย ทุกอย่างทำในเครื่องของคุณ

▶ วิธี Load Save ในแชทใหม่

อัปโหลดไฟล์ แล้วพิมพ์ว่า: “อ่านไฟล์นี้เป็น Save Data ของโปรเจกต์เรา สรุปสิ่งที่คุณเข้าใจ 5 ข้อ บอกจุดที่ยังไม่ชัด และอย่าเริ่มทำงานจนกว่าฉันจะยืนยัน” จากนั้นค่อยเริ่มเควสต่อไป

อ่านไฟล์ .md ที่ฉันแนบเป็น Save Data ของโปรเจกต์นี้ ก่อนเริ่มงาน: 1. สรุปสิ่งที่คุณเข้าใจ 5 ข้อ 2. บอกสิ่งที่ถูกล็อกไว้แล้วและห้ามเปลี่ยน 3. บอกงานที่ค้างและขั้นตอนถัดไป 4. ชี้จุดที่ยังไม่ชัดหรืออาจล้าสมัย 5. รอให้ฉันยืนยันก่อนเริ่มทำงาน ถ้าคำสั่งใหม่ของฉันขัดกับไฟล์ ให้ถามว่าต้องการ Override Save เดิมหรือไม่

ดาวน์โหลด Save File สำเร็จแล้ว กดรับ Achievement ได้เลย สถานะจะถูกจำไว้ในเครื่องนี้
