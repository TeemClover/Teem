⚜️ LEGENDARY

GENESIS PROMPT — ไม่ได้สั่งแค่งาน แต่ตั้งวิธีร่วมงาน

Prompt ทั่วไปบอก AI ว่าต้องทำอะไรตอนนี้ — Genesis Prompt บอกว่าตลอด Session นี้ เราจะร่วมงานกันยังไง

ในคลาสนี้เราเรียก Prompt ตั้งต้นที่ใช้กำหนดวิธีทำงานของ AI ทั้ง Session ว่า “Genesis Prompt” เทียบง่าย ๆ คือ Prompt ธรรมดาเหมือนหยิบเครื่องมือหนึ่งชิ้นไปทำงานหนึ่งครั้ง ส่วน Genesis Prompt คือตั้งค่าเวิร์กช็อปทั้งห้องก่อนเริ่มทำงานหลายชิ้นต่อกัน

❌ ไม่มี Genesis Prompt
คุณช่วยคิด Content ให้หน่อย
AIได้เลย นี่คือ 10 ไอเดียทั่วไป…
  • ไม่รู้ว่าแบรนด์เราเป็นยังไง
  • ไม่รู้ว่าคนดูเป็นใคร
  • ไม่รู้ว่าอะไรเคยทำไปแล้ว
  • ต้องอธิบายซ้ำทุกครั้งที่เปิดแชตใหม่
✅ เริ่ม Session ด้วย Genesis Prompt
คุณ · ข้อความแรกGenesis Prompt — บทบาท บริบท เป้าหมาย หลักที่ต้องรักษา วิธีร่วมงาน รูปแบบคำตอบ
AIสรุปความเข้าใจก่อน แล้วถามกลับเฉพาะที่จำเป็น
คุณช่วยคิด Content สัปดาห์หน้า
  • คำสั่งสั้นลง แต่คำตอบตรงขึ้น
  • ไม่ต้องเล่าเรื่องเดิมซ้ำ
  • มันรู้ว่าต้องถามอะไรเมื่อข้อมูลไม่พอ

⚠️ Genesis Prompt ไม่ใช่ความจำถาวร — โดยทั่วไป AI จะใช้บริบทที่อยู่ในบทสนทนาเดียวกัน แต่แชตที่ยาวมากอาจเริ่มหลุดกรอบได้ ถ้าเห็นว่าเริ่มเพี้ยน ให้ทวนกติกาสั้น ๆ อีกครั้ง หรือเปิดแชตใหม่แล้ววาง Genesis Prompt เดิมลงไป

⚒ตีคู่หู AI ของคุณเอง

เลือกแบบที่ใกล้ที่สุด แล้วแก้ให้เป็นเรื่องของคุณ — เติมเฉพาะสิ่งที่คุณรู้ ช่องที่เว้นไว้จะยังเป็น [วงเล็บ] ให้คุยต่อกับ AI ทีหลังได้

ขั้นที่ 1 — เลือกประเภทคู่หู
ขั้นที่ 2 — เติมให้เป็นเรื่องของคุณ
ตั้งค่าละเอียดเพิ่ม
กำลังตีขึ้นรูป — เปลี่ยนตามที่คุณกรอกทันที

วางเป็นข้อความแรกของแชตใหม่ รอให้มันทวนความเข้าใจก่อน แล้วค่อยสั่งงานจริง

3Prompt มี 3 ระดับ

LEVEL 1 · ถามลอย ๆ ช่วยเขียนอีเมลให้หน่อย เร็วดี แต่ AI ต้องเดาเกือบทุกอย่าง — ส่งหาใคร เรื่องอะไร โทนไหน ยาวแค่ไหน
LEVEL 2 · บอกโจทย์ เขียนอีเมลถึงลูกค้าเรื่องส่งงานช้า ให้สุภาพ รับผิดชอบ และเสนอวันใหม่ ภายใน 8 บรรทัด ชัดขึ้นเยอะ เพราะมีบริบท เป้าหมาย และข้อจำกัดครบ — ทุกใบในคลังข้างบนอยู่ระดับนี้
LEVEL 3 · ตั้งกติกาก่อน เริ่ม Session ด้วย Genesis Prompt → แล้วสั่งสั้น ๆ ว่า “ร่างเมลแจ้งลูกค้าเรื่องส่งช้า” สั่งสั้นที่สุด แต่ได้ตรงที่สุด เพราะกรอบการทำงานอยู่ในบทสนทนาแล้ว
Prompt ยาวกว่าไม่ได้แปลว่าดีกว่า — Prompt ที่ดีคือ Prompt ที่ให้ข้อมูลเท่าที่จำเป็นต่อการตัดสินใจ
ทุกใบในคลังนี้เลยเขียนด้วยโครงหกส่วนเดียวกัน เปิดลิ้นชักไหนก็ได้แล้วกด “🔬 ดูโครงสร้าง” เพื่อดูว่าแต่ละส่วนทำหน้าที่อะไร
🧪 Prompt ไม่ใช่เวทมนตร์
  • AI ยังตีความผิดได้ — Prompt ดีช่วยลดการเดา แต่ไม่การันตีว่าถูกทั้งหมด
  • ตรวจชื่อ ตัวเลข วันที่ และเงื่อนไขทุกครั้งก่อนเอาไปใช้จริง
  • อย่าใส่ข้อมูลลับ ข้อมูลลูกค้า หรือข้อมูลส่วนตัวถ้าไม่จำเป็น
  • Genesis Prompt ทำงานในบริบทของ Session ไม่ใช่ความจำถาวรข้ามทุกแชต
🎯 QUEST: สร้างคู่หู AI ประจำงานของคุณ
  1. ใช้ช่องค้นหาด้านบน หา Prompt หนึ่งใบที่เกี่ยวกับงานจริงของคุณวันนี้
  2. เติมข้อมูลให้ครบ แล้วก๊อปไปลองใน AI ที่ใช้อยู่
  3. กลับมาที่ตัวสร้าง Genesis Prompt แล้วตีคู่หูขึ้นมาหนึ่งตัว
  4. เปิดแชตใหม่ วาง Genesis Prompt เป็นข้อความแรก
  5. รอให้มันทวนความเข้าใจ แล้วค่อยสั่งงานจริง 1 งาน
  6. เทียบกับตอนสั่งลอย ๆ ว่าต่างกันตรงไหน
