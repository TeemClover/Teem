บทที่ 6 · SERVE · MAIN COURSE

HTML — ไฟล์มีชีวิต

ใช้ซอสของคุณสร้างไฟล์เดียวที่ คนอื่นเปิด ใช้ และส่งต่อได้ โดยไม่ต้องติดตั้งแอป

⏱ 15–30 นาที🥩 index.html 1 ไฟล์🌐 AI ตัวไหนก็ได้
เป้าหมายของบทนี้

สร้าง index.html 1 ไฟล์ แล้วเปิดด้วยเบราว์เซอร์ให้ได้

ไม่ต้องมีโดเมน ไม่ต้อง Publish และไม่ต้องเป็นนักพัฒนา แค่ทำให้ไฟล์ออกจากแชตมาเปิดใช้จริงก่อน

1

ทำไมต้อง HTML

เพราะไฟล์เดียวเป็นได้มากกว่า “หน้าเว็บไซต์”

📰

สื่อใส่บทความ ภาพ วิดีโอ เสียง และหลายภาษาในหน้าเดียว

🎮

ของที่เล่นได้ใส่ปุ่ม เกม Quiz เครื่องคำนวณ และระบบโต้ตอบ

📱

เปิดได้ทันทีใช้โทรศัพท์หรือคอมโดยไม่ต้องดาวน์โหลดแอปใหม่

♻️

อัปเดตได้เมื่อ Publish แล้ว แก้ไฟล์ใหม่ คนเปิด URL เดิมก็เห็น Version ใหม่

ทุกสิ่งที่คุณเห็นในบ้านนี้ เริ่มจากไฟล์ชื่อ index.html แล้วค่อยเชื่อมต่อจนกลายเป็นบ้านทั้งหลัง

2

ทำตาม 5 ขั้น

สร้างในเครื่องก่อน แล้วค่อยคิดเรื่องอินเทอร์เน็ต

1

เลือก Source และคนอ่าน

ใช้ Source จริง 1 ขวด แล้วกำหนดว่าหน้านี้ทำให้ใครและต้องการให้เขาทำอะไรต่อ

2

สั่งสร้าง Single-file HTML

ใช้ AI ที่คุณมีอยู่ ไม่ต้องเปลี่ยนเครื่องมือเพื่อเรียนบทนี้

ใช้ Source ที่แนบสร้างหน้า HTML ไฟล์เดียวสำหรับ [ผู้อ่าน] เป้าหมายของหน้า: [สิ่งที่ต้องการให้เขาเข้าใจหรือทำต่อ] กติกา: - ส่งโค้ดครบตั้งแต่ ถึง ใน code block เดียว - รวม CSS และ JavaScript ที่จำเป็นไว้ในไฟล์เดียว - Mobile-first ตัวหนังสือหลักไม่น้อยกว่า 16px และปุ่มกดง่าย - ใช้ Source เป็นฐาน ห้ามแต่งข้อเท็จจริงที่ไม่มี - รักษาชื่อ ตัวเลข Key Messages, Tone และ Canon - ถ้าข้อมูลไม่พอให้ถามก่อน - ห้ามใส่ Tracker, API Key หรือส่งข้อมูลออกจากเครื่อง - ใส่คอมเมนต์บอกจุดที่เจ้าของควรแก้ข้อความและลิงก์
3

เซฟชื่อ index.html

คัดลอกโค้ดลง Text Editor แล้วบันทึกนามสกุล .html ไม่ใช่ .txt

4

เปิดและตรวจ

ดับเบิลคลิกไฟล์ เปิดบนคอมและโทรศัพท์ แล้วตรวจชื่อ ตัวเลข ปุ่ม ลิงก์ และข้อมูลที่ AI อาจแต่งเพิ่ม

5

ส่งต่อ

ส่งไฟล์ผ่าน AirDrop, Email, Drive หรือ ZIP ให้คนที่ไว้ใจทดลองเปิดก่อน Publish

🧪

ยังไม่มีไฟล์ให้ลอง?ดาวน์โหลดตัวอย่าง แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย

เชฟขอเบรกก่อนหลุดโลก

สำหรับเชฟมันไม่ต้องยิ่งใหญ่ค่ะ มันเล่นสนุก มันสวย และคนเปิดได้โดยไม่ต้องโหลดแอป แค่นี้ก็เป็นเหตุผลที่ดีพอจะเสิร์ฟแล้ว

⚠ OPTIONAL · HARD MODE · Publish ด้วย GitHub Pages

ข้ามได้ทั้งหมด การอัปโหลดไฟล์ขึ้น GitHub Pages คือการนำเนื้อหาไปไว้บนอินเทอร์เน็ตสาธารณะ คนทั่วโลกอาจเปิด ส่งต่อ หรือบันทึกได้

1

สร้าง Repository

GitHub → New repository → ตั้งชื่อ → เลือก Public สำหรับทางเริ่มง่าย

2

Upload index.html

Add file → Upload files → เลือกไฟล์ → Commit changes

3

เปิด Pages

Settings → Pages → Deploy from a branch → main และ /(root)

4

รับ URL

รอ Build แล้วเปิดลิงก์ลักษณะ username.github.io/repository/

5

อัปเดตที่อยู่เดิม

แก้หรืออัปโหลด index.html ใหม่ แล้ว Commit อีกครั้ง URL เดิมจะเปลี่ยนเป็น Version ใหม่

FINAL QUEST · MAIN COURSE

เช็กก่อนจบบท

ไม่ต้อง Publish ก็ผ่าน ขอให้ไฟล์เปิดใช้จริงในเครื่องก่อน
