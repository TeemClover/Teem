The Route — เส้นทางเดินเรือ

6 เกาะ จากท่าเรือถึงแกรนด์ไลน์

แต่ละเกาะมี "ของที่ต้องมีก่อนขึ้นเกาะ" (สร้างจากเกาะก่อนหน้า) และ "สมบัติที่ได้กลับมา" — ห้ามข้ามเกาะ เรือจะจม

เกาะ 0 — ท่าเรือออกเดินทาง

เสร็จแล้ว ✓

สร้างโครงสร้างพื้นฐานให้ครบก่อนออกทะเล — ข้อนี้คนส่วนใหญ่ข้าม แล้วไปตายกลางทาง เราไม่

สมบัติที่มีแล้ว

  • จักรวาล + กฎเหล็ก 5 ข้อ (บทตลกแบบทำซ้ำได้)
  • YYY Studio OS — วางแผน/คลังฟุต/จับคู่บท/ส่งออก 4 แพลตฟอร์ม
  • Reaction Bank 30 ชิ้น (HIGH VALUE 15)
  • เว็บพอร์ตโฟลิโอ 3 ภาษา + หน้าแผนที่นี้

แปลว่าอะไร

  • ต้นทุนต่อคลิปต่ำกว่าคู่แข่งตั้งแต่วันแรก
  • ถ่าย 1 วัน ได้วัตถุดิบตัดหลายตอน
  • ออกเรือได้ทันที ไม่ต้องรออะไรอีก

เกาะ 1 — เกาะพิสูจน์สูตร

เดือน 1–2 (ก.ค.–ส.ค. 2026)

เป้าเดียว: หา format-market fit — มุกไหน ตลาดไหน แพลตฟอร์มไหน "ติด" ที่สุด ใช้ปริมาณ+ดาต้า ไม่ใช้ความรู้สึก

ต้องทำบนเกาะนี้

  • ลงคลิป 3–4 ตอน/สัปดาห์ × 4 แพลตฟอร์ม (รวม ~40–48 ตอน)
  • สลับ hook เปิด 3 วิ หลายสูตร แล้วเทียบ retention
  • ประชุมดาต้าทุกจันทร์: อะไรเวิร์กทำซ้ำ อะไรแป้กตัดทิ้ง
  • เก็บทุกช็อตเข้าคลัง Studio OS — ยิงคลิปใหม่จากฟุตเก่า

สมบัติที่ได้

  • รู้ "สูตรไวรัล" เฉพาะของช่องเราต่อแต่ละตลาด
  • ฐานผู้ชมกลุ่มแรกที่กลับมาดูซ้ำ
ดูจบ 3 วิแรก ≥ 65%1 คลิปทะลุ 500K วิว10K followers ในแพลตฟอร์มใดแพลตฟอร์มหนึ่งคลังฟุต ≥ 80 ชิ้น

เกาะ 2 — เกาะแฟนด้อม

เดือน 2–4 (ส.ค.–ต.ค. 2026)

เปลี่ยน "คนไถผ่าน" เป็น "แฟน" — คนดูมาเพราะมุก แต่อยู่ต่อเพราะรักตัวละคร และแฟนเท่านั้นที่จ่ายเงิน

ต้องทำบนเกาะนี้

  • ปั้นมุกประจำ/แคตช์เฟรสให้คนเล่นตาม (มีม "ยู จ่ายเงิน")
  • ซีรีส์ตอนต่อ + ความสัมพันธ์ตัวละครค่อยๆ เปิด (lore drop)
  • ตอบคอมเมนต์เป็นเสียงตัวละคร 3 ภาษา — คอมเมนต์คือคอนเทนต์
  • เปิดคอมมูนิตี้: กลุ่มแฟน + ไลฟ์รายสัปดาห์

สมบัติที่ได้

  • แฟนด้อมที่สร้างคอนเทนต์เอง (แฟนอาร์ต/duet) = โฆษณาฟรี
  • อำนาจต่อรองกับสปอนเซอร์ (engagement คือของจริง)
100K followers รวมengagement ≥ 8%แฟนอาร์ต/มีมเกิดเองชิ้นแรกยอดดูจากแฟนเก่า ≥ 30%

เกาะ 3 — เกาะเบรี่แรก 🔥

เดือน 3–6 (ก.ย.–ธ.ค. 2026)

เกาะที่ตัดสินเกมทั้งปี — เปิดเครื่องยนต์รายได้ 3–4 ตัวแรกพร้อมกัน เป้าคือ รายได้แตะหลักแสนบาท/เดือนภายในสิ้นปีนี้ ไม่ใช่แค่คุ้มทุน

ต้องทำบนเกาะนี้

  • Media kit + rate card 3 ภาษา (ใช้เคสคลิปพีคเป็นหลักฐาน)
  • สมัคร creator program ทุกแพลตฟอร์มที่เข้าเกณฑ์
  • ติดตะกร้า affiliate กับของกิน/ของใช้ที่โผล่ในคลิปอยู่แล้ว
  • แพ็กเกจสปอนเซอร์ "1 ดีล ได้ 4 ตลาด 4 ภาษา" — จุดขายที่คู่แข่งไม่มี

สมบัติที่ได้

  • กระแสเงินสดเป็นบวก — ทีมอยู่ได้ด้วยตัวเอง
  • เคสสตัดี้เชิงพาณิชย์สำหรับปิดดีลใหญ่ขึ้น
🔥 รายได้ ≥ 100,000฿/เดือนสปอนเซอร์ ≥ 3 รายaffiliate ≥ 10% ของรายได้ราคาตอนสปอนเซอร์ขึ้น 2 เท่าจากดีลแรก

เกาะ 4 — เกาะ X-Commerce

เดือน 6–12 (ต้นปี 2027)

เปลี่ยนแฟนเป็นลูกค้า — ขายของที่ "คือตัวละคร" ไม่ใช่ของแปะโลโก้ ความขัดแย้งเผ็ด-หวานกลายเป็นสินค้าคู่

ต้องทำบนเกาะนี้

  • สินค้านำร่อง: ซอสเผ็ดสูตรเหยาเหยา × ขนมหวานสูตรยูริ (เซ็ตคู่ "ซื้อทีมไหนก็แพ้ใจอีกทีม")
  • สติกเกอร์ LINE/WeChat 3 ภาษา — ทุนต่ำ ขายได้ทั้ง 3 ตลาด
  • ไลฟ์คอมเมิร์ซฉบับซิตคอม: สงครามเผ็ดหวานเวอร์ชันขายของ
  • Pre-order ก่อนผลิตจริง — ให้แฟนโหวตสินค้า ลดเสี่ยงสต็อก

สมบัติที่ได้

  • ข้อมูลลูกค้าของตัวเอง (ไม่ต้องยืมจมูกแพลตฟอร์มหายใจ)
  • หลักฐานว่า IP ขายของได้จริง → ตั๋วขึ้นเกาะ 5
สินค้ารุ่นแรกขายหมดลูกค้าซื้อซ้ำ ≥ 20%รายได้สินค้า ≥ 25% ของรายได้รวม

เกาะ 5 — แกรนด์ไลน์: IP Licensing

ปี 2027–2028

ขั้นสุดของธุรกิจคาแร็กเตอร์: ตัวละครออกไปทำงานแทนเรา — แบรนด์อื่นจ่ายเงินเพื่อยืมเหยาเหยา ยูริ ยู ไปอยู่บนของของเขา

ต้องทำบนเกาะนี้

  • Character bible + style guide ระดับไลเซนส์ (มีแล้วครึ่งหนึ่งจาก canon)
  • พอร์ตยอดขายสินค้า + เคสสปอนเซอร์ = หลักฐานมูลค่า IP
  • หาพาร์ตเนอร์/เอเจนซี่ไลเซนส์ในไทย จีน ญี่ปุ่น
  • ขยายร่าง IP: เว็บตูน/แอนิเมชันสั้น ให้ตัวละครอยู่เกินตัวนักแสดง

สมบัติที่ได้ = วันพีช

  • รายได้ passive จากไลเซนส์ — เงินเข้าแม้ทีมพักร้อน
  • IP มีมูลค่าประเมินได้ ขาย/ร่วมทุน/ต่อยอดได้ทุกทาง
ดีลไลเซนส์แรกเซ็นสำเร็จรายได้ไม่ต้องถ่ายเพิ่ม ≥ 30%ป๊อปอัพ/คอลแลบแบรนด์ใหญ่ 1 ครั้ง/ปี

ประตูเข้า: ความ exotic ของทีม 3 ภาษาในเมืองเดียว — ไม่มีใครทำแบบนี้เป็นซิตคอม

แพลตฟอร์ม: IG Reels (+ YouTube Shorts เฟส 2) · บทบาทธุรกิจ: ดีลอินเตอร์ การท่องเที่ยว ทำให้ IP ดู world-class เวลาเจรจา

ตัวเลขตลาดเป็นการประมาณระดับขนาด (order of magnitude) ไว้ใช้คุยทิศทาง ไม่ใช่ตัวเลขอ้างอิงวิชาการ — ก่อนทำ pitch deck ให้ดึงตัวเลขปีล่าสุดอีกรอบ

Money Engine — เครื่องยนต์ทำเงิน

9 ท่อรายได้จาก 3 ตัวละคร

หลักการ: ไม่พึ่งท่อไหนเกิน 50% และทุกท่อต้อง "เกิดจากตัวละคร" ไม่ใช่แปะโลโก้ขายของมั่ว — เรียงตามลำดับปลดล็อกจริง

1. ส่วนแบ่งแพลตฟอร์ม / Creator Fund

฿
ปลดล็อก: เกาะ 1ทุกตัวละคร

เงินขนมจากยอดวิว TikTok/FB/IG bonus program — อย่าหวังเป็นรายได้หลัก แต่เปิดให้ครบทุกอันเพราะเป็นเงินฟรีจากงานที่ทำอยู่แล้ว

2. สปอนเซอร์ / Advertorial

฿฿฿
ปลดล็อก: เกาะ 3จุดขาย: 1 ดีล = 4 ตลาด

กระดูกสันหลังรายได้ช่วงปี 1–2 — จุดแข็งที่คู่แข่งไม่มี: แบรนด์จ่ายครั้งเดียวได้คอนเทนต์ 4 ภาษา 4 แพลตฟอร์ม และหมวดสปอนเซอร์ไม่ชนกันเอง: เผ็ด/หรู → เหยาเหยา, หวาน/คาเฟ่/อาร์ต → ยูริ, แอปจ่ายเงิน/ประหยัด/แก็ดเจ็ต → ยู

3. Affiliate / TikTok Shop

฿฿
ปลดล็อก: เกาะ 3ของที่โผล่ในคลิปอยู่แล้ว

ตะกร้าใต้คลิป = ของกินของใช้ที่ตัวละครกินจริงในตอนนั้น ("ซอสที่เหยาเหยาเทหมดขวด" ขายตัวมันเอง) — รายได้ passive ต่อคลิปเก่าไปเรื่อยๆ

4. สินค้าแบรนด์ตัวเอง

฿฿฿
ปลดล็อก: เกาะ 4YY×YR เซ็ตคู่

ซอสเผ็ดสูตรเหยาเหยา × ขนมหวานสูตรยูริ ขายเป็นเซ็ตคู่กัด — แคมเปญ "ยูจ่าย" = โค้ดส่วนลด ให้มุกในจอกลายเป็นกลไกการตลาดนอกจอ Pre-order ก่อนผลิตเสมอ

5. ดิจิทัลกู้ดส์ / สติกเกอร์

฿
ปลดล็อก: เกาะ 2–3ทุนต่ำสุด เริ่มไวสุด

สติกเกอร์ LINE (ตลาดไทย+ญี่ปุ่นใหญ่มาก) + WeChat (จีน) 3 ภาษาจากมุกประจำ — ต้นทุนวาดครั้งเดียว ขายตลอดกาล และเป็นก้าวแรกของ "ตัวละครอยู่เกินตัวนักแสดง"

6. เมมเบอร์ชิป / แฟนคลับ

฿฿
ปลดล็อก: เกาะ 2ขายมุมมองของยู

คอนเทนต์หลังกล้องแบบเสียเงิน: "มุมมองยูฉบับเต็ม" เบื้องหลังที่ยูบ่นได้เต็มที่ + โหวตเมนู/โลเคชันตอนถัดไป — แฟนตัวจริงยอมจ่ายเพื่อใกล้ชิดกว่าเดิม

7. ไลฟ์คอมเมิร์ซ

฿฿฿
ปลดล็อก: เกาะ 4แรงสุดที่ตลาดจีน

สงครามเผ็ด-หวานเวอร์ชันไลฟ์ขายของ — เหยาเหยาเชียร์ทีมเผ็ด ยูริเชียร์ทีมหวาน คนดูโหวตด้วยการกดซื้อ ยูอ่านยอดแบบหน้าซีด — ซิตคอม+การขายในตัวเดียวกัน

8. Character Licensing / คอลแลบ

฿฿฿฿
ปลดล็อก: เกาะ 5วันพีชของจริง

แบรนด์จ่ายเพื่อเอาตัวละครไปอยู่บนแพ็กเกจ/แคมเปญ (เมนู "เผ็ดระดับเหยาเหยา" ในเชนร้านอาหาร, ป๊อปอัพคาเฟ่ธีมเผ็ด×หวาน) — รายได้ที่ไม่ต้องถ่ายเพิ่มแม้แต่เฟรมเดียว

9. B2B: รับสร้าง IP + ระบบ

฿฿
เริ่มได้ทันทีท่อหล่อเลี้ยงระหว่างทาง

หน้า index.html เปิดขายอยู่แล้ว: รับสร้างคาแร็กเตอร์+ระบบโปรดักชันให้แบรนด์ โดยใช้ YYY เป็นเคสโชว์ — เงินสดเข้าเร็ว เลี้ยงทีมช่วงเกาะ 1–2 ที่คอนเทนต์ยังไม่ทำเงิน

Storm Warning — พายุที่รู้ล่วงหน้า

เรือจมได้ 5 แบบ เรากันไว้แล้วทุกแบบ

⛈️ ตัวละครผูกกับนักแสดงคนเดียว

ถ้านักแสดงถอนตัว IP พังทั้งลำ — ทางกัน: สัญญาชัดตั้งแต่วันแรกว่า IP เป็นของทีม + เร่งทำสติกเกอร์/เว็บตูน/แอนิเมชันให้ตัวละคร "มีร่างสอง" ที่ไม่ต้องใช้ตัวคนเร็วที่สุด

⛈️ แพลตฟอร์มเปลี่ยนอัลกอริทึม

ยอดวิวหายข้ามคืนโดยไม่ผิดอะไร — ทางกัน: ยืน 4 แพลตฟอร์มตั้งแต่ต้น (ทำอยู่แล้ว) + รีบเปลี่ยนแฟนเป็น "ช่องทางตรง": กลุ่ม, LINE OA, เมมเบอร์ชิป ที่อัลกอแตะไม่ได้

⛈️ มุกซ้ำจนคนเบื่อ

สูตรเดิมที่เคยเวิร์กจะเสื่อมเสมอ — ทางกัน: ระบบ Tier ของตอน (A/B/C/D) บังคับผสมของใหม่ทุกสัปดาห์ + ดาต้าประชุมจันทร์ชี้จุดเสื่อมก่อนคนดูรู้สึก + lore ตัวละครที่ค่อยๆ เปิดให้มีของให้ติดตามเสมอ

⛈️ ดราม่าข้ามวัฒนธรรม

ช่อง 3 สัญชาติ = พื้นที่ดราม่า 3 เท่า — ทางกัน: กฎเหล็กคอนเทนต์: ไม่แตะการเมือง/ชาติพันธุ์/ศาสนา, มุกทุกตอนผ่านเจ้าของภาษาก่อนโพสต์, มุกทั้งหมดหักมุมเข้าตัวละคร (หัวเราะ "เรา" ไม่ใช่หัวเราะ "เขา")

⛈️ เงินหมดก่อนถึงเกาะ 3

คอนเทนต์ยังไม่ทำเงินใน 6 เดือนแรกแน่นอน — ทางกัน: ต้นทุนต่อคลิปถูกกดด้วยระบบ reuse ของ Studio OS + ท่อ B2B (ท่อ 9) เปิดรับเงินสดตั้งแต่วันแรก + ไม่จ้างเพิ่มจนกว่ารายได้จะครอบคลุมต้นทุน 2 เดือนติด
