# เอกสารสรุป: การเปรียบเทียบต้นทุนโปรดักชั่นภาพยนตร์ไทย vs จีน

เอกสารนี้จัดทำขึ้นเพื่อสรุปขั้นตอนการทำงานและที่มาของข้อมูล สำหรับใช้เป็นข้อมูลอ้างอิงและสอน AI ตัวใหม่ให้สามารถทำงานลักษณะเดียวกันได้ในอนาคต

## 1. เป้าหมาย (Objective)

เป้าหมายหลักคือการเปรียบเทียบต้นทุนการผลิตสื่อ (หนังสั้น/MV) ระหว่างทีมโปรดักชั่นของจีนและไทย เพื่อหาข้อสรุปว่าการถ่ายทำในประเทศใดมีต้นทุนที่ต่ำกว่า และประหยัดกว่ากันประมาณเท่าไหร่ โดยผลลัพธ์สุดท้ายจะถูกนำเสนอในรูปแบบของหน้าเว็บ HTML ที่แสดงข้อมูลเปรียบเทียบแบบสองภาษา (จีน-ไทย) และสองสกุลเงิน (หยวน-บาท)

## 2. แหล่งข้อมูล (Data Sources)

เราใช้ข้อมูลจาก 2 แหล่งหลักในการเปรียบเทียบ:

### 2.1 ข้อมูลฝั่งไทย: คลิปเสียงสนทนากับโปรดิวเซอร์

- **ไฟล์:** `SoiRamkhamhaeng1333.m4a`
- **วิธีการได้มา:** ผู้ใช้ส่งไฟล์คลิปเสียงการพูดคุยโทรศัพท์กับโปรดิวเซอร์หญิงชาวไทยผู้มีประสบการณ์ในวงการโปรดักชั่น
- **การสกัดข้อมูล:** ใช้เครื่องมือ `manus-speech-to-text` เพื่อถอดเสียงบทสนทนาทั้งหมดออกมาเป็นไฟล์ Text (`.txt`)
- **ข้อมูลสำคัญที่ได้ (Key Data Points):**
    - **MV (3-4 นาที):** ราคาเหมาทั้งโปรเจกต์ (รวมทีมงานและ Post-production ไม่รวม CG) อยู่ที่ **2,700,000 บาท**
    - **ซีรีส์/หนังสั้น (ต่อวัน):** ค่าใช้จ่ายทีมงานต่อ 1 คิว (1 วัน) อยู่ที่ประมาณ **200,000 บาท** (ไม่รวมค่าตัวนักแสดง)
    - **ชั่วโมงทำงาน:** ทีมงานไทยทำงานประมาณ **14-16 ชั่วโมงต่อวัน**

> **ข้อความถอดเสียงส่วนสำคัญ:**
> `[28:11.5 - 28:16.5] ถ้าไม่ใช่ CG ส่วนใหญ่จะสตาร์ตอยู่ที่ 2,700,000`
> `[29:04.5 - 29:09.5] มันจะอยู่ที่ประมาณ 2 แสนครับจริงๆ ทั่วหมดทุกอย่างนะครับ`
> `[30:40.5 - 30:43.5] เมืองไทยอาจอยู่ที่ 14-16 ชั่วโมง`

### 2.2 ข้อมูลฝั่งจีน: ตารางงบประมาณ (Excel)

- **ไฟล์:** `预算配置表.xlsx` (Budget Configuration Table)
- **วิธีการได้มา:** ผู้ใช้ส่งไฟล์ Excel ที่เป็นตารางงบประมาณการผลิตหนังสั้นจากทีมงานฝั่งจีน
- **การสกัดข้อมูล:** ใช้ Library `openpyxl` ใน Python เพื่ออ่านข้อมูลจากแต่ละ Cell ในตาราง
- **ข้อมูลสำคัญที่ได้ (Key Data Points):**
    - **งบประมาณรวม:** **247,900 หยวน** สำหรับการถ่ายทำ 4 วัน
    - **รายละเอียดค่าใช้จ่าย:** มีการแจกแจงรายละเอียดค่าตัวทีมงานแต่ละตำแหน่ง (ผู้กำกับ, ตากล้อง, โปรดิวเซอร์, ฯลฯ), ค่าเช่าอุปกรณ์, ค่าสถานที่, ค่าอาหาร, ค่าเดินทาง และค่าใช้จ่ายหลังการถ่ายทำ (Post-production)

## 3. วิธีการดำเนินงาน (Methodology)

ขั้นตอนการทำงานทั้งหมดสามารถสรุปได้ดังนี้:

1.  **วิเคราะห์และรวบรวมข้อมูล:**
    *   ถอดเสียงคลิปเสียงเพื่อหาข้อมูลราคาตลาดของไทย
    *   อ่านไฟล์ Excel เพื่อดึงข้อมูลต้นทุนของจีน
    *   นำข้อมูลจากทั้งสองแหล่งมาจัดโครงสร้างใหม่ในไฟล์ `analysis_notes.md` เพื่อให้ง่ายต่อการเปรียบเทียบ

2.  **กำหนดอัตราแลกเปลี่ยน:**
    *   ใช้อัตราแลกเปลี่ยน ณ เวลาที่ทำงาน คือ **1 หยวน (CNY) ≈ 4.57 บาท (THB)** เพื่อแปลงสกุลเงินให้สามารถเปรียบเทียบกันได้

3.  **สร้างหน้าเว็บ HTML เปรียบเทียบ (`index.html`):**
    *   ใช้ HTML, CSS และ JavaScript ในการสร้างหน้าเว็บ
    *   **โครงสร้างหน้าเว็บ:**
        *   **Header:** แสดงหัวข้อหลักและปุ่มสลับภาษา (จีน/ไทย)
        *   **Summary Cards:** การ์ดสรุปงบประมาณรวมของทั้งสองประเทศและส่วนต่างที่ประหยัดได้
        *   **MV Comparison:** การ์ดเปรียบเทียบราคาเหมาของการทำ MV
        *   **Detailed Breakdown Table:** ตารางเปรียบเทียบค่าใช้จ่ายรายวันของทีมงานแต่ละตำแหน่ง แสดงราคาเป็น หยวน และ บาท พร้อมคำนวณส่วนต่างเป็นเปอร์เซ็นต์
        *   **Daily Cost Table:** ตารางเปรียบเทียบต้นทุนการถ่ายทำต่อวัน, ชั่วโมงทำงาน, และระยะเวลาโปรดักชั่น
        *   **Key Findings:** สรุปจุดเด่นและข้อได้เปรียบของแต่ละประเทศ
        *   **Data Sources:** ระบุที่มาของข้อมูลอย่างชัดเจน
    *   **ฟังก์ชัน JavaScript:** สร้างฟังก์ชันสำหรับสลับภาษา โดยการซ่อน/แสดง element ที่มี class `lang-zh` และ `lang-th`

4.  **Deploy และส่งมอบ:**
    *   Clone Git repository `TeemClover/Teem` จาก GitHub
    *   สร้างโฟลเดอร์ `compare/` ภายใน repo
    *   คัดลอกไฟล์ `index.html` ที่สร้างเสร็จแล้วไปยังโฟลเดอร์ `compare/`
    *   ใช้คำสั่ง `git add`, `git commit`, และ `git push` เพื่ออัปโหลดไฟล์ขึ้นไปยัง `main` branch ของ repository
    *   แจ้งผู้ใช้พร้อมแนบลิงก์ไปยังไฟล์บน GitHub

## 4. ข้อสรุปและผลลัพธ์ (Key Findings)

- **การผลิตในไทยมีต้นทุนที่ต่ำกว่า:** จากการเปรียบเทียบโดยใช้ทีมงานฟรีแลนซ์ในไทย พบว่าสามารถ **ประหยัดต้นทุนได้ประมาณ 29%** เมื่อเทียบกับงบประมาณของจีน
- **ค่าตัวบุคลากร:** ค่าตัวนักแสดงและทีมงานบางตำแหน่งในไทยถูกกว่าจีนอย่างมีนัยสำคัญ (20-56%)
- **ประสิทธิภาพ:** ทีมงานจีนมีกระบวนการทำงานที่เร็วกว่า โดยเฉพาะในส่วนของ Post-production

เอกสารนี้สรุปกระบวนการทั้งหมดที่เกิดขึ้น หวังว่าจะเป็นประโยชน์ในการนำไปพัฒนาต่อยอดและสอน AI รุ่นต่อไป
