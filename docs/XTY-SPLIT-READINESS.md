# XTY แยกไป teambook.me — ตรวจแล้วต้องเตรียมอะไรบ้าง

ตรวจจาก main วันที่ 19 ส.ค. 2026 · `teambook.me` = XTY อย่างเดียว · `myclover.com` = ที่เหลือ

## สรุปสั้น

**ตัวโค้ด XTY พกพาได้อยู่แล้ว** ไม่มีลิงก์คลิกได้สักอันในหน้า XTY ที่ลากผู้เล่นข้ามโดเมน
กลับบ้านเดิม (เช็คทุกหน้าแล้ว) ที่ติดคือเรื่อง **deploy ไม่ใช่เรื่องโค้ด**

## สิ่งที่ต้องมีบน teambook.me ไม่งั้นเกมพัง

XTY เรียกของนอกตัวเองอยู่ 5 อย่าง ถ้าโดเมนใหม่เสิร์ฟแค่โฟลเดอร์ `xty/` ของพวกนี้จะ 404

| ต้องมี | ใช้ทำอะไร | พังยังไงถ้าไม่มี |
| --- | --- | --- |
| `/api/*` | ทั้งเกม | ตั้งตี้ไม่ได้ เข้าตี้ไม่ได้ ไม่มีอะไรทำงานเลย |
| `/core7/js/cards.js`, `/core7/js/art.js` | ปกตี้แบบ FIRST HAND | คลังปกพัง หน้าตั้งตี้/หน้าตี้เออเรอร์ |
| `/core7/js/audio.js` | เสียงพลิกการ์ด | เปิดการ์ดแล้วเงียบ |
| `/core7/assets/card-back.webp`, `myclover-back.webp` | หลังการ์ด · ปกเริ่มต้น | การ์ดคว่ำกับปกตี้ไม่มีภาพ |
| `/profile/`, `/assets/account.js` | โปรไฟล์ · ล็อกอิน | ลิงก์โปรไฟล์ตาย · เซฟข้ามเครื่องไม่ได้ |

## เรื่อง path — ตัดสินใจข้อเดียวที่กำหนดขนาดงาน

ในโค้ด XTY มี path ที่ขึ้นต้นด้วย `/xty/` เขียนตายตัวอยู่ **442 จุด**

- **เก็บ prefix `/xty/` ไว้** (`teambook.me/xty/...`) → **แก้โค้ด 0 บรรทัด** ขึ้นได้เลย
  ถ้าอยากให้ `teambook.me/` เข้าเกมตรง ๆ ใช้ rewrite ที่ระดับ host เอา
- **ย้ายไป root** (`teambook.me/p/?c=12345`) → ต้องไล่แก้ 442 จุด + ทุก URL เก่าที่คนแชร์ไว้ต้องมี redirect

แนะนำ: **เก็บ `/xty/` ไว้ก่อน** แล้วค่อยคิดเรื่องย้าย root เป็นงานแยกตอนที่พร้อมทำ redirect ครบ

## ทางที่ถูกและถูกที่สุดตอนนี้

deploy **repo เดิมทั้งก้อน** ไปที่ teambook.me ด้วย — `/api/`, `/core7/`, `/profile/` จะมีครบเอง
ไม่ต้องย้ายโค้ดสักบรรทัด แล้วค่อยแยกจริงทีหลังเมื่อพร้อม

(การผูกโดเมนกับ deploy อยู่ใน `vercel.json` / หน้า dashboard — เป็นของเจ้าของ ไม่ได้แตะในเอกสารนี้)

## ทำไม XTY ยังลบออกจาก myclover.com ไม่ได้

ของฝั่ง myclover พึ่ง XTY อยู่หลายจุด ถ้าตัดออกดื้อ ๆ พวกนี้พังทันที

- `xircle/` — 5 ไฟล์ (`start/`, `care/party/`, `circle/`, `_shared/state.js`, `_shared/v5.js`) · Xircle สร้างตี้ XTY จริง และแมวขาวคือสัตว์ XTY ที่ขับด้วยคลังความรู้ Xircle
- `profile/index.html` — ตัวเลือก Avatar ใช้ `xty/_shared/card-picker.js`
- `classroom/`, `class/history/`, `first-class/after/after.js`
- `assets/account.js`, `assets/guild-multiplayer-upgrade.js`

แปลว่าช่วงแรกทั้งสองโดเมนต้องใช้โค้ดชุดเดียวกันไปก่อน ยังแยกขาดไม่ได้

## เรื่อง SEO ที่ต้องตัดสินใจ ถ้าจะให้ teambook.me ติดอันดับเอง

หน้า XTY ทุกหน้ามี `canonical` ชี้ `www.myclover.com/xty/...` และ `og:image` 50 จุดชี้ไฟล์บน myclover.com

- **รูปแชร์**: ปล่อยไว้ได้ ข้ามโดเมนก็โหลดขึ้นปกติ แค่แบรนด์ไม่ตรง
- **canonical**: ถ้าไม่แก้ Google จะถือว่า teambook.me เป็นสำเนาของ myclover.com แล้วจัดอันดับให้แค่ myclover.com
  แก้ได้ต้องมีขั้น build ที่ใส่ค่าตามโดเมน (ตอนนี้เป็นค่าคงที่ใน HTML)

**ถ้า teambook.me เป็นแค่ทางเข้าเกม ไม่ได้หวังอันดับ** ปล่อยไว้แบบนี้ถูกแล้ว

## ที่แก้ไปแล้วในรอบนี้

- `xty/about/index.html` canonical ชี้ `xty.myclover.com` ซึ่งเป็นโฮสต์ที่ redirect ทิ้งแล้ว → ชี้ปลายทางจริง
- `xty/_shared/portable.test.mjs` — กันไม่ให้หน้า XTY หน้าไหนเผลอใส่ลิงก์เต็ม URL กลับบ้านเดิม และกัน canonical ชี้โฮสต์ที่ redirect
