# AskSydScience interactive offer

Implementation date: 2026-10-02. Rate card: MC-WEB-2026-10-v1.

## Scope and paths

The user requested `/asksydneyscience/offer`; this implementation intentionally uses `asksydneyscience/offer/index.html`, while the existing demo stays at `/asksydscience/`. No existing demo pages, sitewide scripts, auth, payment, or global routing configuration are changed.

The route contains four static files: index.html, offer.css, offer.mjs, rates.mjs. It references existing public demo assets and fonts instead of copying them. The existing `.vercelignore` excludes this documentation and `tools/asksydscience/` tests.

## Price provenance

These are newly proposed service rates for the requested offer, not a price list previously approved by Teem or a signed Sydney agreement. Status is proposal and must remain visible. No assumption is made about the supplier's VAT registration or other tax treatment. Prices are integer THB service fees excluding applicable taxes and third-party provider charges, to be confirmed in a formal quote before work starts.

`rates.mjs` is the canonical rate source. A is base 19,900; B adds intake 6,000 and Source workflow 4,000 for 29,900; C adds CMS 15,000 for 44,900. Package choices are module presets, not additional charges. Every module has explicit inclusions/exclusions. Extras: same-design page 2,500 (0–8), supplied content upload 600 (0–20), workshop co-design 4,500 (0–1). Care: 0 / 1,500 / 3,500 monthly with stated caps. Budget horizon is a scenario, not a minimum contract term.

Changing a rate requires a new version and updated tests. Share links carry a rate version; stale versions trigger a visible warning and a fresh B preset, never a silent claim that an old quoted amount is honored. URL parameters cannot set unit prices or totals. A client-side calculator is not a contractual security boundary; written acceptance remains required.

## Functionality

- Responsive package cards, checkboxes, bounded quantity controls, monthly plans, budget horizon.
- Itemized totals and selected scope driven by the same calculation.
- 50/30/20 installment schedule on the one-time service fee only; sum preserved in integer THB.
- Estimated working days with explicit full-source/confirmed-slot conditions.
- Copy full scoped summary; clipboard failure opens a selectable modal.
- Copy allowlisted selection URL; text-file download; browser print layout.
- Default B, no care auto-selection. Package changes preserve extras/care; full reset clears them.
- No forms, payments, signatures, user accounts, cookies, localStorage, network analytics, raw transcripts, or private discussion details.
- Noindex/nofollow/noarchive is indexing preference, NOT access control. Repo and page are publicly accessible.
- Selected CMS is a priced future deliverable, not a claim that the existing simulated studio is a real CMS. The existing demo illustrates direction; scope of actual work is defined in this offer.
