## 5. วิธีรัน/ตรวจ (สำหรับ ChatGPT หรือผู้ตรวจ)

```bash
python3 -m http.server 4180 --bind 127.0.0.1     # ที่ root ของ repo แล้วเปิด http://127.0.0.1:4180/homechew/
node --test tests/homechew/                        # ลำดับเรื่อง, rewind, overlap guard, ข้อมูล null, LINE link
HOMECHEW_BASE_URL=http://127.0.0.1:4180/homechew/ \
FRONTDOOR_PLAYWRIGHT=/path/to/playwright-core/index.mjs \
FRONTDOOR_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
HOMECHEW_ALLOW_FONTS=1 HOMECHEW_PROOF_DIR=/tmp/homechew-proof node tests/homechew/page.e2e.mjs
```
ตัวเลือก: `?no3d` บังคับโหมดไม่มี 3D · เปิด "ลดการเคลื่อนไหว" ในระบบ = static mode
ถ้าแก้ keyframe กล้องใน `timeline.js` **ต้องรัน `node --test tests/homechew/`** — overlap guard จะบอกตำแหน่ง scroll ที่วัตถุทับข้อความ

## 6. ยังไม่ได้ทำ / ข้อจำกัดที่ต้องรู้

1. ขวดยังเป็น proxy (ไม่มี GLB/ขนาดจริง) — ด้านหลังเป็นฉลาก "รอยืนยัน"
2. บอร์ดฉลาก v1.2 มีบรรทัด "LOCAL FLAVORS • A BRIGHTER TABLE" (ไม่ใช่สโลแกนที่ล็อก) — ใช้ตามบอร์ดไปก่อน รอเจ้าของยืนยัน
3. ภาพอาหาร/ฉลากทั้งหมดเป็น AI concept; ภาพทะเลบางภาพมีหอยนางรมดิบเป็นพร็อพ (brief v1.0 ห้ามอาหารทะเลดิบ) — ใช้เป็นภาพประกอบใน S4 เท่านั้น
4. คำบรรยายรส (หวาน·เผ็ดกำลังดี / เปรี้ยวจี๊ด / เข้ม·หอม·เผ็ดร้อน) เป็นทิศทางแบรนด์ ยังไม่ใช่ผลชิม
5. คลิป Higgsfield Seedance 2.5 **ยังไม่ได้สร้าง** (ได้รับอนุญาตแล้ว แต่มีค่าใช้จ่าย — ต้องยืนยันงบก่อน) — ที่ว่างที่เหมาะ: วงกลมใน S2 (loop 3–4 วินาที ต่อรส)
6. ราคา ขนาด การเก็บรักษา รอบส่ง = `null` / "รอยืนยัน"
7. โลโก้ SVG เป็น trace ชั่วคราว (A01)
