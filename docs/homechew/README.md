## v1.5 — อัปเกรดรอบ 2026-09-26

**แก้ตามภาพรีวิว 16:22:** ย้ายชื่อเมืองขนาดใหญ่เป็นแถวแยกเหนือภาพและข้อความทั้ง 3 รส จึงไม่ถูกอาหาร/ฉลาก/เนื้อหาทับ เจ้าของยืนยันว่าการเติมผักชีใช้กับ **น้ำจิ้มไก่หาดใหญ่**; ย้ายคำแนะนำไปที่หาดใหญ่และแก้ส่วน “ไอเดียเติมอีกนิด” ให้ตรงกัน

**สีซอสยืนยันโดยเจ้าของ:** น้ำจิ้มไก่ออกสีส้มเหมือนในโมเดล 3D จึงใช้ขวดหาดใหญ่ตรงกลางเป็นสีอ้างอิงในการแก้ภาพจิ้มไก่และจานไก่ เปลี่ยนภาพทุกจุดในหน้าเป็นชุด `hy-*-orange-v15-*` โดยคงสีโมเดลเดิมไว้

**เก็บไว้:** โครงหน้า scroll เดิม, สัญญา “เราคราฟต์ให้ คุณแค่เท”, ซอส 3 รส, ฉลาก v1.2, สีแบรนด์, ทางสั่ง LINE เดิม และข้อมูลสินค้าที่ยังเป็น `null`.

**เปลี่ยน:**

- ใช้รูปทรงภายในขวดเดียวกันทั้งการวาดและคำนวณปริมาตร เพิ่มผิวหน้าซอสแนวนอนจริง ไม่ใช้ผิวด้านหลังขวดแทนผิวซอสอีกต่อไป
- ซอสที่หายจากขวด = ซอสในถ้วย + ซอสระหว่างไหล ถ้วยหนึ่งในฉากใช้ประมาณ **8.58%** ของซอสเริ่มต้น จบแล้วเหลือประมาณ **91.42%** ไม่ใช่ตัวเลขปริมาตรสินค้าจริง
- ถ้วยเริ่มมีซอสเมื่อสายซอสถึงถ้วย หยดท้ายลงถ้วยต่อจนหมด; ย้อน scroll กลับได้โดยไม่สะสมความคลาดเคลื่อน
- First paint เป็นภาพขวดจากฉาก 3D เดียวกัน และหน้าเริ่มในโหมดภาพนิ่งที่อ่านได้ แม้ JavaScript ใช้ไม่ได้; ไม่โหลด Three.js ล่วงหน้าในทุกโหมด
- ภาพเปิดแยก desktop/phone/tablet ให้คมบนจอความละเอียดสูง; ส่วนชุดซอสใช้ภาพขวดครบ 3 ใบแทนการ์ดฉลากแบน
- ภาษาไทยนำบนมือถือ ภาษาญี่ปุ่นย่อเป็นชื่อแบรนด์แนวนอน ปุ่มและชื่อรสจัดพื้นที่ใหม่ พร้อมแก้เส้นขอบที่เคยใช้สี LINE โดยไม่ตั้งใจ
- ปุ่ม LINE ติดจออิงตำแหน่งปุ่มสั่งซื้อจริง ไม่ซ่อนเพียงเพราะเริ่มเห็นส่วนชุดซอส; ปุ่มที่ซ่อนต้องไม่รับโฟกัส
- เล่าแต่ละรสด้วยอาหาร ความหอม และความทรงจำของสถานที่; เมนู “ความพิถีพิถัน” แทน “คนปรุง”; ชุด 3 รสระบุรสละ 1 ขวดและข้อความเริ่มสนทนาทาง LINE
- เพิ่มภาพหมูย่างจิ้มแจ่ว สำรับทะเลสุก และโต๊ะสามมื้อ ดูไฟล์และ prompts ใน [ASSETS_v1.5.md](ASSETS_v1.5.md)

**ข้อจำกัด:** ขวดยังเป็นโมเดลตัวแทน; ภาพใหม่เป็น AI concept; ราคา ขนาด สูตรจริง การเก็บรักษา และรอบส่งยังต้องยืนยันกับร้าน รายงานตรวจรอบนี้อยู่ใน [QA_v1.5.md](QA_v1.5.md) และแยกจากผล v1.4 ด้านล่าง ไม่อ้างคะแนนรีวิวอิสระหรือผลบนเครื่องจริงจากการทดสอบใน Chrome เท่านั้น

FRONTDOOR_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
