# AI ใส่ซอส Workshop 3 ชั่วโมง — การประเมินและคัดรีวิว

## จุดเข้าใช้งาน

- ผู้สอนอ่านและคัดรีวิว: `/course/admin/reviews/`
- หน้าขายหลักสูตรมาตรฐาน: `/course/workshop/`
- ผู้เรียนยืนยันสิทธิ์ใช้ข้อความ: `/course/review-consent/` พร้อมลิงก์เฉพาะที่ผู้สอนสร้าง
- รีวิว First Class เดิม: `/first-class/admin/reviews/` คงข้อมูลและการทำงานเดิม

## แบบประเมินหลังเรียน

ใช้คำถามหลักเดียวกันในแต่ละรุ่น: ความมั่นใจก่อนและหลังเรียน 1–5, หัวข้อที่ได้ประโยชน์,
งานแรกที่จะนำไปใช้, ประโยชน์ต่อการทำงาน 1–10, สิ่งที่อยากให้ปรับ,
ข้อความเล่าถึงคลาส, ชื่อ/หน้าที่ และสิทธิ์ใช้ข้อความ

เก็บรุ่นใน `cohort_id` และรุ่นแบบประเมินใน `form_version` เพื่อแยกผลของแต่ละทีม
หน้าผู้สอนแสดงรุ่นจากข้อมูลที่บันทึกไว้ ส่วนการเปิดแบบประเมินสำหรับรุ่นใหม่ต้องตั้งค่า
เส้นทางและ cohort ของแบบประเมินนั้นก่อน ไม่ส่งผู้เรียนรุ่นใหม่เข้าฟอร์มของรุ่นเดิม

คะแนนประโยชน์เป็นความคิดเห็นของผู้เรียน ไม่ใช่ NPS ส่วนคะแนนความมั่นใจเป็นการประเมิน
ตนเอง ไม่ใช่ผลทดสอบทักษะ เก็บงานจริงจากการติดตามผลประกอบการประเมินการนำไปใช้
โดยไม่รวบรวมไฟล์ลูกค้าหรือข้อมูลส่วนบุคคลที่ไม่จำเป็น

## อ่าน → คัด → ขอสิทธิ์ → เลือกเผยแพร่

1. อ่านคำตอบต้นฉบับและเลือกกรองรุ่นในหน้าผู้สอน
2. กด **คัดไว้** เพื่อจัดรายการภายในได้ทุกคะแนน รวมรีวิวที่เลือกใช้ภายใน
3. รีวิวที่มีข้อความเล่าถึงคลาสสามารถสร้างลิงก์เฉพาะเพื่อให้เจ้าของเลือกสิทธิ์ใหม่ได้
   ผู้สอนคัดลอกข้อความและลิงก์ไปส่งเอง ระบบไม่ส่งข้อความอัตโนมัติ
4. ผู้เรียนเลือกใช้ภายใน / เผยแพร่แบบไม่ระบุชื่อ / เผยแพร่พร้อมชื่อและหน้าที่
   การตัดสินใจนี้ไม่เกี่ยวกับการรับการ์ดหรือสิทธิ์เรียน
5. เมื่อมีข้อความและได้รับอนุญาต ผู้สอนจึงกด **เผยแพร่ข้อความ** ให้หน้าขายดึงไปแสดง
   การคัดไว้หรืออนุญาตเพียงอย่างเดียวไม่ทำให้ข้อความขึ้นหน้าขาย
6. ผู้สอนนำข้อความออกได้ ผู้เรียนเปลี่ยนสิทธิ์ได้ผ่านลิงก์ที่ยังไม่หมดอายุ
   ทุกการเปลี่ยนสิทธิ์นำข้อความออกจากหน้าขายจนผู้สอนเลือกใหม่

ลิงก์สิทธิ์มีอายุ 30 วัน การสร้างลิงก์ใหม่แทนที่ลิงก์เก่า ส่งให้เจ้าของรีวิวเป็นรายบุคคล
ไม่มีการเปลี่ยนคำตอบต้นฉบับหรือสิทธิ์ดั้งเดิมจากหน้าผู้สอน

## ข้อมูลและการเข้าถึง

- `course_reviews` เป็นคำตอบต้นฉบับและหลักฐานการรับการ์ดเดิม
- `course_review_curation` เก็บรายการที่คัด สถานะเผยแพร่ สิทธิ์ที่ยืนยันเพิ่มเติม และเวลาแยกกัน
- API ใหม่ `/api/course-reviews` ใช้ `?admin=1` สำหรับผู้สอนและ `?public=1` สำหรับหน้าขาย
- รหัสผู้ดูแลมาจากการตั้งค่าบนเซิร์ฟเวอร์: `COURSE_REVIEW_ADMIN_KEY`,
  `FIRST_CLASS_ADMIN_KEY` หรือ `XTY_ADMIN_PASSWORD` ตามลำดับ ไม่มีรหัสสำรองในโค้ด
- รหัสเข้าห้องเรียนของนักเรียนไม่ใช่สิทธิ์อ่านรีวิวของทุกคน
- API สาธารณะส่งเฉพาะข้อความที่เลือกและอนุญาต ชื่อ/หน้าที่จะแสดงตามสิทธิ์
  ไม่ส่งคำตอบภายใน คะแนนรวม รหัสผู้เรียน ลิงก์รับการ์ด หรือตัวระบุสำหรับจัดการรีวิว
- ไม่เก็บคำตอบจริง รหัสผู้ดูแล หรือลิงก์เฉพาะบุคคลไว้ใน repository สาธารณะ

## เกณฑ์ตรวจแต่ละรุ่น

ตรวจจำนวนคำตอบกับข้อมูลในฐานข้อมูล แยกการรับการ์ดออกจากการเข้าห้องติดตามผล
อ่านทั้งคนที่ความมั่นใจเพิ่มและไม่เพิ่ม แล้วเลือกงานติดตามที่มีขนาดทำสำเร็จได้จริง
หลักฐานการนำไปใช้จากงานหลังเรียนช่วยยืนยันผลได้มากกว่าคะแนนความพึงพอใจเพียงอย่างเดียว
