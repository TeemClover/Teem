## Visual direction
- Premium tabletop product photography / premium industrial-design campaign render
- Dark graphite / black environment, brushed silver metal, subtle cyan display light
- Realistic physical scale
- TCG tournament / local game-store context
- No fake logos, no extra readable text, no sci-fi holograms
- Keep HALO circular and preserve the tactile outer metal ring as the visual hero
- App / dashboard concepts should look like serious competitive tools, not generic AI chat screens

## New competitive-product concept slots

### 09 — `/calling/assets/player-profile.webp`
**Ratio:** 16:9 or 4:5

CONCEPT UI. Mobile app screen that makes hardware ownership and data ownership clearly separate. Show a player profile, “My HALO”, “Borrowed HALO / Store HALO”, and a simple “Claim Session” flow. The visual message: the physical device can be borrowed, but the match history belongs to the player. Serious, clean, premium UI.

### 10 — `/calling/assets/deck-series.webp`
**Ratio:** 16:9

CONCEPT UI. Competitive Deck Series dashboard. Show one deck family with Version 12 and Version 13, individual win rates and match counts, matchup splits, plus an “All Versions” roll-up. Include a small external deck-link field or link icon, but avoid using real third-party logos unless supplied by the owner. The point is version testing: did this deck change improve results?

### 11 — `/calling/assets/team-dashboard.webp`
**Ratio:** 16:9

CONCEPT UI / competitive war room. Tablet or desktop dashboard for a serious testing team. Show a roster of several players, each player's current deck version, number of matches, matchup coverage matrix, team win rate by deck version and obvious untested matchups. Professional preparation tool for a world-level event, not flashy esports fantasy graphics. Include a subtle permission / shared-with-team cue.

### 12 — `/calling/assets/training-ecosystem.webp`
**Ratio:** 16:9

CONCEPT DIAGRAM. A deck identity / external deck link at the center. One branch goes to HALO paper practice with lighter real-world data (opponent hero, result, first player, duration, life history). Another branch goes to online practice with richer digital match data. Both return to the same Deck Series review. Keep it visually clean and product-oriented, not a technical network diagram.

Player Profile, Borrowed Session, Deck Series / Version, external deck-link workflow, competitive analytics, Team Mode, AI analysis and the smaller personal unit are proposals for discussion, not existing-product claims unless the creator confirms otherwise.
