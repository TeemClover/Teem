ลองเปิด XTY ของจริง ↗
01ไม่เริ่มจาก Prompt

เริ่มจากเป้าหมาย ข้อมูลเดิม ข้อจำกัด และสิ่งที่งานต้องรักษาไว้

02ปรุงเป็น “ซอส”

จัดบริบทให้คนหรือ AI ตัวถัดไปรับงานต่อได้โดยไม่ต้องเดาใหม่

03ส่งต่อจนเป็นของจริง

Source → AI → Output → ตรวจ → ปรุงต่อ จนงานเติบโตเป็นระบบ

สิ่งที่วิชานี้อยากให้คุณเห็น
AI ไม่ได้เก่งขึ้นเพราะเราเจอ “คำสั่งวิเศษ” แต่ผลงานดีขึ้นเมื่อเรา ส่งของที่มันต้องรู้ให้ครบและเป็นโครงสร้าง
