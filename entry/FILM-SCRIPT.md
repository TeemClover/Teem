# บทวิดีโอหน้าแรก · "ใบที่ 4"

ฉบับที่ใช้จริง · เขียน 2026-10-26 · เจ้าของอนุมัติ 2026-10-26 ("ทำเลย") · โค้ด: entry/film.js · ภาพ: entry/media/film/atlas.webp (tools/build-film-atlas.mjs) · ปรับ 2026-10-26: เปลี่ยนเว็บด้วยเส้นกวาดแทนภาพจางซ้อน ช่วงเร่งเป็นแถวเลื่อน (เจ้าของแจ้งว่าภาพซ้อนและตัวอักษรกะพริบ)

## แก่นเรื่อง
โคลเวอร์ 4 แฉก: 3 ใบแรกคือ 3 คำตอบ ใบที่ 4 สีทองคือเว็บของคุณ
แตะครบ 3 ใบ ใบทองจะแยกออกเป็นบานประตู แล้วกลายเป็นเว็บทั้งหน้า
จากนั้นทุกครั้งที่ใบใดใบหนึ่งพลิก เว็บจะแปลงร่างทั้งหน้า

- **ความยาว:** 20 วินาที วนต่อเนื่อง
- **จังหวะ:** 120 BPM คือ 10 ห้อง ห้องละ 2 วินาที
- **ทำด้วยโค้ดทั้งหมด** แบบเดียวกับวิดีโอเปิด /classroom

  - เสียงสังเคราะห์ด้วย WebAudio

- **ทุกรอบไม่ซ้ำ:** แต่ละรอบสุ่มคำตอบชุดใหม่จาก 64 ชุด
  - สุ่มตามลำดับที่กำหนดได้ จึงเทสต์ได้
- **มีจอสองแบบ:** แนวนอน 16:9 สำหรับคอม และแนวตั้ง 9:16 สำหรับมือถือ จัดวางแยกกัน
- **ธีมเดิมของหน้าแรก:**
  - พื้นดำอมเขียว ตัวอักษรครีม
  - ใบเขียว #8fd3a0 และทอง #d9b46a / #f2d79a
  - ฟอนต์ Kanit และ Anuphan
- **เว็บในวิดีโอวาดจากของจริงในหน้านี้:**
  - 4 เทมเพลต (อบอุ่น / หรู / สนุก / มินิมอล)
  - ชื่อร้าน รูป และสีชุดเดียวกับที่คนดูจะได้เมื่อเล่นเอง
  - ไม่วาดเว็บที่ระบบทำไม่ได้
- **เสียงปิดไว้ก่อน** เพราะเบราว์เซอร์บังคับ มีปุ่ม "เปิดเสียง"

## บท (ตัวอย่างรอบแรก: คาเฟ่ · จองคิว · หรู)

### 1 · เมล็ด · 0.0–1.5 วิ
- **ภาพ:**
  - ความมืด มีผงทองลอย
  - จุดแสงกลางจอลากเส้นเป็นก้านและใบโคลเวอร์ 4 ใบ ใช้เวลา 1 วิ
  - ใบ 1–3 เป็นเส้นเขียว ใบที่ 4 เป็นเส้นทอง ทุกใบยังว่าง
  - ป้ายเล็กข้างใบ: ธุรกิจ · อยากได้ · สไตล์ · เว็บของคุณ
- **ข้อความ:** **แตะ 3 ใบ** / ใบที่ 4 จะกลายเป็นเว็บของคุณ
- **เสียง:** เสียงทุ้มฟูขึ้นช้า ๆ และเสียงดีดเบา ๆ ตอนเส้นวาดเสร็จ

### 2 · สามแตะ · 1.5–4.5 วิ
- **ภาพ:**
  - วงนิ้วแตะลงใบ 1, 2, 3 ตรงจังหวะที่ 1.5 / 2.5 / 3.5 วิ
  - แต่ละใบเติมสีเป็นแก้วเขียวมีแสงสะท้อน
  - ในใบเห็นภาพเล็กของคำตอบ: รูปลาเต้ / ปฏิทิน / ตัว Aa สีทอง
  - ป้ายคำตอบเด้งออกมา: ☕ คาเฟ่ → 📅 จองคิว → 💎 หรู
- **ข้อความ:** ป้ายคำตอบอย่างเดียว
- **เสียง:** เสียงแก้วกังวาน 3 โน้ตไล่ขึ้น และเสียงแตะเบา ๆ ทุกครั้ง

### 3 · ใบทอง · 4.5–6.5 วิ (ช็อตเด็ด)
- **ภาพ:**
  - ป้ายคำตอบทั้ง 3 ถูกดูดเข้าใบที่ 4
  - ใบทองลุกเป็นแสง หมุนเข้าหากล้อง
  - ใบแยกตามเส้นกลางใบออกเป็นบานประตูสองบาน (ตรงกับธีม "เปิดประตูบ้าน")
  - ขอบทองกลายเป็นกรอบเบราว์เซอร์
  - ข้างในเว็บ "มอสคาเฟ่" สไตล์หรูประกอบตัวต่อหน้า: รูปเปิดม่าน หัวเรื่องพิมพ์ขึ้น เมนูกับปุ่มเลื่อนเข้า ช่องจองคิวเด้งเข้าที่ทีละช่อง
- **ข้อความ:** **ใบที่ 4 คือเว็บของคุณ**
- **เสียง:** ลมหวือกับประกายไต่ขึ้น แล้ว "ตูม" คอร์ดเต็มวงที่ 6.0 วิ เพลงเริ่มเต้นตรงนี้

### 4 · เปลี่ยนใบเดียว เปลี่ยนทั้งเว็บ · 6.5–14.5 วิ (ช่วงแปลงร่าง)
โคลเวอร์ย่อเป็นแถบเล็กมุมจอ (มือถืออยู่ด้านล่าง) แถบโชว์ 3 คำตอบปัจจุบันและ "ชุดที่ n / 64"
ทุกจังหวะมีใบหนึ่งพลิก แล้วเว็บแปลงร่างทั้งหน้าโดยไม่ตัดภาพ
เว็บใหม่ถูกเผยด้วยเส้นแสงทองที่กวาดจากบนลงล่าง (ไม่ใช้ภาพจางซ้อน: จุดหนึ่งบนจอเห็นเว็บเดียวเสมอ)
ตอนเปลี่ยนจอ เว็บเดิมหรี่ลงทั้งหน้า กรอบเปลี่ยนรูป แล้วเว็บใหม่สว่างขึ้น ไม่มีสองเว็บบนจอพร้อมกัน
แต่ละสไตล์ขยับไม่เหมือนกัน:
- หรูไหลช้า
- สนุกเด้ง
- มินิมอลดีดเข้าที่
- อบอุ่นลอยนุ่ม

| วิ | ใบที่พลิก | เว็บเปลี่ยนเป็น |
|---|---|---|
| 6.5 | สไตล์ → สนุก | สีระเบิดเป็นโทนลูกกวาด ตัวอักษรกลมหนา การ์ดเด้งเอียง มีคอนเฟตตี |
| 7.5 | ธุรกิจ → ร้านออนไลน์ | รูปเป็นไหมพรม ชื่อร้าน "ถักใจ" พิมพ์ทับชื่อเดิม |
| 8.5 | อยากได้ → หน้าร้าน | ตะกร้ากับการ์ดสินค้าไหลเข้ามา |
| 9.5 | สไตล์ → มินิมอล | ทุกอย่างดีดเข้ากริด ขาวดำ เส้นบาง ตัวเลขใหญ่ |
| 10.5 | จอ → มือถือ | กรอบเบราว์เซอร์หดเป็นมือถือ เลย์เอาต์จัดใหม่ทั้งหน้า |
| 11.0 | ธุรกิจ → สตูดิโอ | รูปกลายเป็นแกลเลอรีภาพถ่าย "เฟรมสิบ" |
| 11.5 | อยากได้ → มินิเกม | ของตกลงมาให้เก็บ 1 วิ |
| 12.0 | สไตล์ → อบอุ่น | ลายกระดาษ ลายมือ แสงอุ่น |
| 12.5–14.5 | เร่ง | เว็บทั้งหน้าเลื่อนผ่านเป็นแถว เร็วขึ้นเรื่อย ๆ ทีละชุด (ไม่กะพริบ) ตัวนับวิ่งตามชุดที่อยู่ตรงกลาง แล้วความมืดปิดทับทั้งแถว |

- **ข้อความ:**
  - 6.6–9.4 วิ: **เปลี่ยนใบเดียว** / ภาพ สี ตัวอักษร เลย์เอาต์ เปลี่ยนตามหมด
  - 10.6–12.4 วิ: **ทุกจอ ทุกธุรกิจ** / จองคิว · หน้าร้าน · มินิเกม · แนะนำตัว
- **เสียง:**
  - กลองเบา ๆ ตามจังหวะ
  - แต่ละใบมีเสียงประจำตัว: ธุรกิจ = เคาะไม้ · อยากได้ = กระดิ่ง · สไตล์ = ฟู่
  - แต่ละสไตล์มีเสียงเฉพาะ: สนุก = ป๊อปฟองสบู่ · มินิมอล = ติ๊กเรียบ · อบอุ่น = มาริมบา · หรู = สายทุ้ม
  - ช่วงเร่งมีเสียงไต่ระดับ

### 5 · 64 แบบ · 14.5–17.0 วิ
- **ภาพ:**
  - 14.5 วิ: ดับมืด เงียบครึ่งจังหวะ
  - 15.0 วิ: ซูมออกเห็นกำแพงเว็บจิ๋ว 64 ช่อง ครบทุกชุดจริง
  - แสงทองวิ่งผ่านทีละแถว
  - ทั้ง 64 ช่องพับรวมกลับเป็นใบทองใบเดียว
- **ข้อความ:** **หน้าเดียว 64 แบบ** / นี่แค่ตัวอย่าง · งานจริงออกแบบให้คุณโดยเฉพาะ
- **เสียง:** เงียบ แล้ว "ตูม" ตามด้วยเสียงคอรัสฟุ้ง

### 6 · ตาคุณ · 17.0–20.0 วิ (ปิดและวน)
- **ภาพ:**
  - ใบทองกลับเข้าที่ โคลเวอร์ครบ 4 ใบ ใบ 1–3 ว่างอีกครั้ง
  - ใบที่ 1 เต้นเบา ๆ ชวนแตะ
  - 19.2–20.0 วิ: ใบหุบกลับเป็นจุดแสง ตรงกับภาพวินาทีที่ 0 พอดี จึงวนต่อได้ไม่สะดุด
  - รอบถัดไปสุ่มคำตอบชุดใหม่
- **ข้อความ:**
  - **ตาคุณแล้ว** / แตะ 3 ครั้ง ดูเว็บของคุณประกอบตรงหน้า
  - บรรทัดเล็ก: วิดีโอนี้ทำด้วยโค้ดทั้งหมด · Teem Clover
- **เสียง:** คอร์ดคลี่คลาย มีเสียงแก้วเบา ๆ ที่ใบแรก หางเสียงต่อเข้ารอบใหม่

## ปุ่มบนวิดีโอ
ปุ่มเป็นปุ่มจริงบนหน้าเว็บ ไม่ได้วาดอยู่ในภาพ
- **เริ่มปรุงเว็บของคุณ ↓** พาลงไปที่ 3 ตัวเลือก (แตะใบในวิดีโอก็ไปได้)
- **เปิดเสียง / ปิดเสียง**
- **หยุด / เล่นต่อ**

## คนดูต้องเข้าใจภายใน 6.5 วินาทีแรก
1. ที่นี่ปรุงเว็บได้จากการเลือก 3 อย่าง
2. ผลลัพธ์คือเว็บทั้งหน้า ไม่ใช่รูปเดียว
3. เปลี่ยนอย่างเดียว ทั้งเว็บเปลี่ยนตาม และลองเองได้เลย

## ทำให้หน้าไม่ช้า
- หน้าเปิดมาเห็นภาพนิ่งที่ 1.4 วิทันที (โคลเวอร์พร้อมข้อความ "แตะ 3 ใบ") แล้ววิดีโอเล่นต่อจากจุดนั้น
- คนที่ตั้งค่าลดการเคลื่อนไหวจะเห็นภาพนิ่งกับปุ่ม "ดูวิดีโอ"
- เลื่อนผ่านหรือสลับแท็บ วิดีโอหยุดเอง ประหยัดแบต
- เทสต์อัตโนมัติ:
  - ภาพที่วินาทีสำคัญ
  - รอยต่อตอนวน
  - ปุ่มเสียงและปุ่มหยุด
  - จอมือถือ
  - ภาพนิ่งสำหรับคนที่ลดการเคลื่อนไหว
