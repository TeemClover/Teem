# Shelf changelog

## 2.1.0 — 2026-09-14 · Asia/Bangkok

- เพิ่มซอสองค์กรทั่วไป 8 ฉบับ รุ่น 1.0.0 พร้อมแม่แบบเติมข้อมูล คำสั่ง ตัวอย่างสมมติ เกณฑ์ตรวจ และที่มา
- จัดลำดับ SOURCE → TASTE → COOK → SPLIT → SEASON → SERVE และคู่มือผู้สอน/รุ่นถัดไป โดยระบุส่วนประยุกต์ใหม่เป็น DERIVED
- ขยาย catalog schema รุ่น 1 แบบเพิ่ม field ทางเลือก: collections และ recipe labels; public API ส่งเฉพาะฉลาก ไม่ส่ง path/เนื้อหา/คำสั่งในขวด
- หน้า Shelf จัดชุดและลำดับจาก catalog แสดงการใช้งาน และพับวัตถุดิบ/ผลลัพธ์/บทเรียนไว้ในรายละเอียด
- เพิ่มทางเข้าจาก Classroom, บท 1–6 และ Course พร้อมลิงก์ไปฉลากรายสูตร; ไม่มีการปลดกุญแจจากลิงก์
- เพิ่มตรวจลำดับ เงื่อนไขก่อนใช้ สูตรซ้ำ ลิงก์บทเรียน และการป้องกันเนื้อหาใน public preview
- คง ID/path/เนื้อหา/เวอร์ชันของซอสเดิมทั้ง 3 ฉบับ ไม่เพิ่มสิทธิ์หรือผู้ใช้จริง และยังไม่ขึ้นเว็บจริง

## 2.0.0 — 2026-09-14 · Asia/Bangkok

- เปลี่ยนหน้าเข้าคลังเป็นตู้ซอสที่ล็อกอยู่ พร้อมทางติดต่อทีมและช่องใส่กุญแจ
- เพิ่มกุญแจรายผู้รับ สิทธิ์รายซอส วันหมดอายุ session ฝั่งเซิร์ฟเวอร์ และการเพิกถอน
- เพิ่มหลังบ้านออกกุญแจและสถิติการส่งซอส แยกผู้รับ ซอส วิธี และเวลา
- ปิดทางเข้าไฟล์ดิบผ่าน routing ของเว็บ และส่งเนื้อหาผ่าน API ที่ตรวจสิทธิ์เท่านั้น
- เพิ่มตัวอย่างในเครื่องและการทดสอบสิทธิ์ คำสั่ง SQL และการตอบกลับที่มาถึงหลังออกจากระบบ
- ซอสเดิมยังอยู่ใน repo สาธารณะและประวัติ Git; การล็อกหน้าเว็บไม่ทำให้สำเนาเดิมเป็นความลับ
- ไม่เปลี่ยนเนื้อหา catalog หรือวันยืนยันข้อมูลของซอสเดิม และยังไม่ใช่การขึ้น production

## 1.0.0 — 2026-09-10 · Asia/Bangkok

- สร้าง `/shelf/` เป็นสารบัญซอสที่ค้นหา กรองหมวด อ่าน คัดลอก และดาวน์โหลดได้
- กำหนด `/shelf/source/` เป็นที่เก็บหลักสำหรับซอสใหม่และการอัปเดตต่อไป พร้อมกติกาใน root `AGENTS.md`
- นำเข้าซอสสินค้า/Offer 0.9 โดยไม่เปลี่ยนเนื้อหา และคำถามยืนยัน 0.9.1 ซึ่งเพิ่ม metadata/ลิงก์
- บันทึกหลักการส่งขวดซอส 1.0.0 จากบทสนทนา โดยไม่อ้างว่าเป็นคู่มือภาพสินค้าฉบับเต็ม
- เพิ่ม catalog, แม่แบบ และสคริปต์ตรวจความสอดคล้อง
- เก็บวันที่ต้นฉบับ 2026-09-09 แยกจากวันที่นำเข้าชั้น 2026-09-10
- ไม่อัปโหลดไฟล์เสียงส่วนตัว/ต้นฉบับภาพหรือ PDF ไม่ย้าย Source เดิม และไม่เปลี่ยนระบบอื่น
